以下面的题目为例

[L-小L的游戏2_2026牛客寒假算法基础集训营6](https://ac.nowcoder.com/acm/contest/120566/L)

```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'
const int mod = 1e9 + 7;
const int MOD = 998244353;

const int sz = 100;

struct M {
    array<array<int, sz>, sz> a;

    M operator*(const M &T) {
        M res;
        int r;
        for (int i = 0; i < sz; ++i)
            for (int k = 0; k < sz; ++k) {
                r = a[i][k];
                for (int j = 0; j < sz; ++j)
                    (res.a[i][j] += T.a[k][j] * r) %= MOD;
            }
        return res;
    }

    M() {
        for (int i = 0; i < sz; i++) {
            for (int j = 0; j < sz; j++)
                a[i][j] = 0;
        }
    }
};

M qpow(M a, int n) {
    M res;
    res.a[sz-1][0] = 1;
    while (n) {
        if (n%2) res = a*res;
        a = a*a;
        n /= 2;
    }
    return res;
}

void ap() {
	int m1, m2, n1, n2, z; cin >> m1 >> m2 >> n1 >> n2 >> z;
    int p1, q1; cin >> p1 >> q1;
    int p2 = (1 - p1 + MOD) % MOD, q2 = (1 - q1 + MOD) % MOD;

    M A;
    for (int i = 0; i < sz - 1; i++) A.a[i][i + 1] = 1;
    (A.a[sz - 1][sz - (m1 + n1)] += p1 * q1) %= MOD;
    (A.a[sz - 1][sz - (m1 + n2)] += p1 * q2) %= MOD;
    (A.a[sz - 1][sz - (m2 + n1)] += p2 * q1) %= MOD;
    (A.a[sz - 1][sz - (m2 + n2)] += p2 * q2) %= MOD;

    M B = qpow(A, z - 1);

    int ans = 0;
    for (int i = 0; i < sz; i++) {
        if (i + m1 >= sz) ans = (ans + B.a[i][0] * p1) % MOD;
        if (i + m2 >= sz) ans = (ans + B.a[i][0] * p2) % MOD;
    }

    cout << ans << endl;

	return ;
}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int T = 1;
//	cin >> T;
	while (T--) {
		ap();
	}
    return 0;
}
```

为了彻底搞懂这段代码的原理，我们需要从**数学递推模型**、**滑动窗口表示法**、**矩阵乘法代数展开**以及**代码实现细节**四个层面进行逐层剖析。

### 一、 问题的递推背景

在这道题中，游戏由多轮组成。在**每一整轮**中，小 L 和 fallleaves01 各走一步，总步长 $S$ 只有 4 种可能：

- $S_1 = m_1 + n_1$，对应概率 $P(S_1) = p_1 \cdot q_1$

- $S_2 = m_1 + n_2$，对应概率 $P(S_2) = p_1 \cdot q_2$

- $S_3 = m_2 + n_1$，对应概率 $P(S_3) = p_2 \cdot q_1$

- $S_4 = m_2 + n_2$，对应概率 $P(S_4) = p_2 \cdot q_2$

设 $f(k)$ 为经历若干次**完整轮次**后，累加和恰好等于 $k$ 的概率。那么要到达 $k+1$ 这个点，只能从之前的某个状态 $k+1-S$ 转移过来：

$$f(k+1) = \sum_{S \in \{S_1, S_2, S_3, S_4\}} P(S) \cdot f(k + 1 - S)$$

由于 $m_i \le 50, n_j \le 50$，最大单轮步长 $\max(S) \le 100$。这意味着：**计算最新的状态 $f(k+1)$，只需要用到前面连续 100 个历史状态 $[f(k-99), f(k-98), \dots, f(k)]$。**

### 二、 状态向量的设计（滑动窗口机制）

我们维护一个固定长度为 $\text{sz} = 100$ 的列向量 $\mathbf{V}_k$：

$$\mathbf{V}_k = \begin{bmatrix} f(k - 99) \\ f(k - 98) \\ \vdots \\ f(k - 1) \\ f(k) \end{bmatrix}_{\text{sz} \times 1}$$

向量内部的下标映射规则为：

- 索引 $0$ 存放：$f(k - 99)$

- 索引 $1$ 存放：$f(k - 98)$

- $\dots$

- 索引 $i$ 存放：$f(k - 99 + i)$

- $\dots$

- 索引 $\text{sz}-1$ (即 $99$) 存放：$f(k)$

转移矩阵 $A$ 的任务就是完成一次**状态前移 1 步**：

$$\mathbf{V}_{k+1} = A \cdot \mathbf{V}_k = \begin{bmatrix} f(k - 98) \\ f(k - 97) \\ \vdots \\ f(k) \\ f(k + 1) \end{bmatrix}_{\text{sz} \times 1}$$

观察新向量 $\mathbf{V}_{k+1}$ 的生成过程，它可以拆解为两项任务：

1. **前 99 项的继承与平移**：旧向量中的第 $1 \sim 99$ 项直接搬到新向量的第 $0 \sim 98$ 项。

2. **最后 1 项的递推计算**：利用旧向量中的某些项加权求和，算出 $f(k+1)$ 并填入新向量的第 $99$ 项。

### 三、 代码代码行逐句对应解析

#### 1. 前 99 行的状态平移

```c++
for (int i = 0; i+1 < sz; i++) {
    A.a[i][i+1] = 1;
}
```

- **矩阵结构**：

    在矩阵 $A$ 的第 $0$ 到第 $\text{sz}-2$ 行中，仅让主对角线上方相邻的元素 $A[i][i+1] = 1$，其余全部为 $0$。

    $$A_{\text{前99行}} = \begin{bmatrix} 0 & 1 & 0 & 0 & \dots & 0 \\ 0 & 0 & 1 & 0 & \dots & 0 \\ 0 & 0 & 0 & 1 & \dots & 0 \\ \vdots & \vdots & \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & 0 & 0 & \dots & 1 \end{bmatrix}$$

- **代数展开**：

    根据矩阵乘法规则，新向量的第 $i$ 项为：

    $$(\mathbf{V}_{k+1})_i = \sum_{j=0}^{99} A[i][j] \cdot (\mathbf{V}_k)_j = 1 \cdot (\mathbf{V}_k)_{i+1} = f(k - 99 + (i+1)) = f(k - 98 + i)$$

    这正好完成了数据的自动向前推进。

#### 2. 最后一行计算新状态

```c++
(A.a[sz-1][sz-(m1+n1)] += p1*q1) %= mod;
(A.a[sz-1][sz-(m1+n2)] += p1*q2) %= mod;
(A.a[sz-1][sz-(m2+n1)] += p2*q1) %= mod;
(A.a[sz-1][sz-(m2+n2)] += p2*q2) %= mod;
```

这一部分定义了新状态 $f(k+1)$ 的计算公式：

$$f(k+1) = \sum_{S} P(S) \cdot f(k + 1 - S)$$

**核心坐标推导（为什么列下标是 $\text{sz} - S$？）**：

- 状态 $f(k+1-S)$ 需要从旧向量 $\mathbf{V}_k$ 中取出。

- 在旧向量 $\mathbf{V}_k$ 中，第 $j$ 项存储的是 $f(k - 99 + j)$。

- 我们令这两项相等：

    $$k - 99 + j = k + 1 - S$$

    $$j = 99 + 1 - S = 100 - S = \text{sz} - S$$

- **结论**：转移步长为 $S$ 时，对应的旧状态正好落在旧向量的第 $\text{sz} - S$ 列。因此，我们只需要在矩阵最后一行的第 $\text{sz} - S$ 列填入转移概率 $P(S)$。

**为什么必须用 `+=` 而不是 `=`？**

- 不同的走法可能组合出**相同**的总步长（例如 $m_1+n_2 = m_2+n_1$）。

- 当总步长相同时，它们转移到同一位置，属于互斥事件，概率必须累加合并。

### 四、 转移矩阵 $A$ 的整体全景

以 $S_1 = m_1+n_1, S_2 = m_1+n_2, S_3 = m_2+n_1, S_4 = m_2+n_2$ 为例，构造出的矩阵 $A$（维度 $100 \times 100$）整体形式如下：

$$A = \begin{bmatrix} 0 & 1 & 0 & 0 & \dots & 0 & \dots & 0 \\ 0 & 0 & 1 & 0 & \dots & 0 & \dots & 0 \\ 0 & 0 & 0 & 1 & \dots & 0 & \dots & 0 \\ \vdots & \vdots & \vdots & \vdots & \ddots & \vdots & \dots & \vdots \\ 0 & 0 & 0 & 0 & \dots & 0 & \dots & 1 \\ \dots & P(S_1) & \dots & P(S_2) & \dots & P(S_3) & \dots & P(S_4) \end{bmatrix}$$

通过这种标准的状态移位构造，每一次将矩阵乘以状态向量，就会将整个时间窗向右推进 1 步。计算 $A^{z-1}$ 便可在 $O(100^3 \log z)$ 的对数时间内直达 $z$ 附近的概率分布。
