
**递推类型：**
$$f(n) = \sum_{i=1}^{K} c_i \cdot f(n - i) = c_1 f(n-1) + c_2 f(n-2) + \dots + c_K f(n-K)$$

```c++
const mod = 998244353;
const int sz = 100;

struct M {
    array<array<int, sz>, sz> a;
	
	//计算矩阵相乘 C = A * T
    M operator*(const M &T) {
        M res;
        int r;
        for (int i = 0; i < sz; ++i)
            for (int k = 0; k < sz; ++k) {
                r = a[i][k];
                for (int j = 0; j < sz; ++j)
                    (res.a[i][j] += T.a[k][j] * r) %= mod;
            }
        return res;
    }

    M() {
        for (int i = 0; i < sz; i++) {
            for (int j = 0; j < sz; j++)
                a[i][j] = 0;
        }
    }
};

M qpow(M a, int n) {
    M res;
    res.a[sz - 1][0] = 1;
    while (n) {
        if (n % 2) res = a * res;
        a = a * a;
        n /= 2;
    }
    return res;
}
```

这个模板是一个**针对“常系数线性递推”进行高度定制的矩阵乘法与矩阵快速幂模板**。它相比通用矩阵快速幂模板做了一些特殊的简化与优化。


# 模板详解


### 1. 核心常量与矩阵结构体 `struct M`

```c++
const int mod = 998244353;
const int sz = 100;
```

- **`mod`**：运算模数（常见于算法竞赛的质数模数）。

- **`sz`**：矩阵的固定维度大小（$100 \times 100$）。使用静态定长数组 `std::array` 存储在栈上，避免了 `std::vector` 动态分配内存的开销。

```c++
M() {
    for (int i = 0; i < sz; i++) {
        for (int j = 0; j < sz; j++)
            a[i][j] = 0;
    }
}
```

- **构造函数**：将矩阵所有元素初始化为 **$0$**（即全零矩阵）。

### 2. 矩阵乘法运算符重载 `operator*`

```c++
M operator*(const M &T) {
    M res;
    int r;
    for (int i = 0; i < sz; ++i)
        for (int k = 0; k < sz; ++k) {
            r = a[i][k];
            for (int j = 0; j < sz; ++j)
                (res.a[i][j] += T.a[k][j] * r) %= mod;
        }
    return res;
}
```

这里计算的是矩阵相乘 $C = A \times T$，其中标准数学定义为 $C_{i, j} = \sum_{k} A_{i, k} \cdot T_{k, j}$。

#### 为什么采用 `i - k - j` 循环顺序？

普通的矩阵乘法写法通常是 `i - j - k`，而这里写成了 `i - k - j`：

- **CPU Cache（缓存命中率）极大优化**：

    在 C/C++ 中，二维数组按行优先存储。最内层循环 `j` 遍历时，`T.a[k][j]` 和 `res.a[i][j]` 在内存中都是**连续访问**的。

- **常数提取优化**：

    将 `r = a[i][k]` 提到内层循环外，避免了内层重复寻址，使得编译器能更好地进行向量化和寄存器优化，运行速度比朴素的 `i - j - k` 快数倍。

### 3. 深度定制的快速幂函数 `qpow(M a, int n)`

```c++
M qpow(M a, int n) {
    M res;
    res.a[sz - 1][0] = 1; // <--- 关键特殊点！
    while (n) {
        if (n % 2) res = a * res;
        a = a * a;
        n /= 2;
    }
    return res;
}
```

这是该模板与标准通用快速幂**差异最大**的地方：

#### (1) 标准模板 vs 该模板的 `res` 初始化

- **标准通用快速幂**：将 `res` 初始化为**单位矩阵 $I$**（主对角线为 1，其余为 0），用于计算矩阵的高阶幂 $A^n$（结果仍是 $sz \times sz$ 矩阵）。

- **该模板的做法**：将 `res` 的第 0 列作为**初始状态列向量** $\mathbf{V}_0$，并将 `res.a[sz-1][0]` 设为 1，其余全为 0：

    $$\text{第 0 列：} \mathbf{V}_0 = \begin{bmatrix} f(-(sz-1)) \\ \vdots \\ f(-1) \\ f(0) \end{bmatrix} = \begin{bmatrix} 0 \\ \vdots \\ 0 \\ 1 \end{bmatrix}$$

#### (2) 为什么直接 `res = a * res`？

在线性递推中，我们的最终目标是求 $A^n \mathbf{V}_0$。

- 当二进制位为 1 时，执行 `res = a * res`，本质上是把当前的变换矩阵 $a$ 左乘到累积向量 `res` 上。

- 快速幂结束时，返回矩阵的**第 0 列**直接就是推进了 $n$ 步后的状态向量 $\mathbf{V}_n$：

    $$\mathbf{V}_n = \begin{bmatrix} f(n - (sz - 1)) \\ \vdots \\ f(n - 1) \\ f(n) \end{bmatrix}$$

- **优点**：免去了单独定义向量类以及编写“矩阵 $\times$ 向量”的额外函数，直接一套矩阵乘法复用到最后。

### 4. 复杂度与性能

- **单次乘法时间复杂度**：$O(\text{sz}^3) = 100^3 = 10^6$ 次基本运算。

- **快速幂总时间复杂度**：$O(\text{sz}^3 \log n)$。当 $n = 10^{18}$ 时，$\log_2 n \approx 60$，总运算量约 $6 \times 10^7$ 次，配合 Cache 优化在 1 秒内可轻松通过。

- **空间复杂度**：$O(\text{sz}^2)$，占用内存仅数十 KB。


# 原理详解


**矩阵快速幂**是一种高效计算矩阵高次幂（如 $A^n$）的算法。

如果你直接让矩阵连乘 $n-1$ 次，时间复杂度是 $O(n)$。但利用矩阵快速幂，我们可以将复杂度降到 $O(\log n)$。这在处理指数级递推关系（比如求第 $10^{18}$ 项斐波那契数）时非常有用。

它的核心思想完美结合了两个概念：**整数快速幂**和**矩阵乘法**。

## 1. 核心原理：从整数快速幂说起

理解矩阵快速幂之前，我们先看整数快速幂。比如计算 $3^{13}$：

我们可以把指数 $13$ 拆成二进制：$13 = (1101)_2 = 8 + 4 + 1$。

所以：

$$3^{13} = 3^8 \times 3^4 \times 3^1$$

我们不需要连乘 13 次，只需要不断对自己求平方（$3^1 \to 3^2 \to 3^4 \to 3^8$），并在对应的二进制位为 1 时累乘到答案里。**矩阵快速幂完全同理，只是把底数由“整数”换成了“方阵”。**

## 2. 核心前置条件：矩阵乘法

矩阵快速幂能成立，因为矩阵乘法满足**结合律**：

$$(A \times A) \times A = A \times (A \times A)$$

这意味着我们也可以用 $A^4 = A^2 \times A^2$ 的方式来加速计算。

> ⚠️ **注意：** 只有**方阵**（行数等于列数）才能做快速幂，因为只有方阵才能自己乘以自己，且乘完后规模不变。

## 3. 代码实现 (C++)

在竞赛或算法设计中，我们通常会封装一个 `Matrix` 结构体。以下是完整的 C++ 实现模板：

```c++
#include <iostream>
#include <vector>

using namespace std;

const int MOD = 1e9 + 7; // 通常需要取模防溢出
int N; // 矩阵阶数

struct Matrix {
    vector<vector<long long>> mat;
    Matrix() {
        mat.resize(N, vector<long long>(N, 0));
    }

    // 初始化为单位矩阵 I (相当于整数里的 1)
    void identity() {
        for (int i = 0; i < N; i++) {
            for (int j = 0; j < N; j++) {
                mat[i][j] = (i == j) ? 1 : 0;
            }
        }
    }

    // 重载矩阵乘法
    Matrix operator * (const Matrix& other) const {
        Matrix res;
        for (int i = 0; i < N; i++) {
            for (int k = 0; k < N; k++) { // 优化循环顺序，利用缓存连续性
                for (int j = 0; j < N; j++) {
                    res.mat[i][j] = (res.mat[i][j] + mat[i][k] * other.mat[k][j]) % MOD;
                }
            }
        }
        return res;
    }
};

// 矩阵快速幂 A^n
Matrix matrixPower(Matrix A, long long n) {
    Matrix res;
    res.identity(); // 答案初始化为单位矩阵

    while (n > 0) {
        if (n & 1) res = res * A; // 如果当前二进制位为 1，累乘到答案中
        A = A * A;                // 底数自乘平方
        n >>= 1;                  // 指数右移一位
    }
    return res;
}
```

## 4. 经典应用：加速递推关系

矩阵快速幂最强的地方在于**将线性递推关系转化为矩阵乘法**。

以**斐波那契数列** $F_n = F_{n-1} + F_{n-2}$ 为例，我们可以构建如下矩阵方程：

$$\begin{bmatrix} F_n \\ F_{n-1} \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix} \begin{bmatrix} F_{n-1} \\ F_{n-2} \end{bmatrix}$$

以此类推，如果要求第 $n$ 项：

$$\begin{bmatrix} F_n \\ F_{n-1} \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^{n-1} \begin{bmatrix} F_1 \\ F_0 \end{bmatrix}$$

只要用矩阵快速幂求出 $\begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^{n-1}$，就能在 $O(2^3 \log n)$ 的时间内算出极大的斐波那契数。

### 总结

- **时间复杂度：** $O(K^3 \log n)$，其中 $K$ 是矩阵的阶数（通常很小，如 $2 \sim 100$），$n$ 是幂次。

- **核心工具：** 二进制拆分指数、矩阵乘法结合律、单位矩阵（作为乘法单位元）。
