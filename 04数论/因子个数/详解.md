
时间复杂度`O(m logm)`
```c++
vector<int> d(m + 1);
for (int i = 1; i <= m; i++) {
	for (int j = i; j <= m; j += i) {
		d[j]++;
	}
}
```

关注内层循环的实际执行次数：

- 当 $i = 2$ 时，内层步长为 $2$，循环执行 $\lfloor \frac{m}{2} \rfloor$ 次；
    
- 当 $i = 3$ 时，内层步长为 $3$，循环执行 $\lfloor \frac{m}{3} \rfloor$ 次；
    
- $\dots$
    
- 当 $i = k$ 时，内层步长为 $k$，循环执行 $\lfloor \frac{m}{k} \rfloor$ 次；
    
- 直到 $i = m$ 时，循环执行 $\lfloor \frac{m}{m} \rfloor = 1$ 次。
    

将外层从 $i = 2$ 到 $m$ 的所有内层循环执行次数累加：

$$T(m) = \sum_{i=2}^{m} \left\lfloor \frac{m}{i} \right\rfloor \le m \sum_{i=2}^{m} \frac{1}{i}$$


括号中的级数是经典的**调和级数（Harmonic Series）**：

$$\sum_{i=1}^{m} \frac{1}{i} = \ln m + \gamma + \mathcal{O}\left(\frac{1}{m}\right) = \Theta(\log m)$$

其中 $\gamma \approx 0.5772$ 为欧拉-马歇罗尼常数。

因此：

$$T(m) \approx m \cdot (\ln m - 1) = \Theta(m \ln m) = \mathcal{O}(m \log m)$$
