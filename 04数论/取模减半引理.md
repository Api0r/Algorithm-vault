**取模减半引理**（Modulo Halving Lemma）是数论与算法分析中的一个基础引理，常用于证明欧几里得算法（辗转相除法）的时间复杂度为 $O(\log(\min(a, b)))$。

### 引理表述

对于任意正整数 $a$ 和 $b$，若 $a \ge b$，则：

$$a \bmod b < \frac{a}{2}$$

即：**对较小的数取模后，结果至少会比原来的大数减半。**


### 数学证明

根据 $b$ 与 $\frac{a}{2}$ 的大小关系，分两种情况讨论：

1. **情况一：$b \le \frac{a}{2}$**

    - 由取模性质可知，余数一定严格小于除数：

        $$a \bmod b < b$$

    - 因为 $b \le \frac{a}{2}$，所以：

        $$a \bmod b < \frac{a}{2}$$

2. **情况二：$b > \frac{a}{2}$**

    - 此时商必为 $1$（因为 $2b > a$ 且 $a \ge b$），因此：

        $$a \bmod b = a - b$$

    - 两边代入 $b > \frac{a}{2}$：

        $$a - b < a - \frac{a}{2} = \frac{a}{2}$$

    - 故同样有：

        $$a \bmod b < \frac{a}{2}$$

综合上述两种情况，引理得证。


### 核心应用：欧几里得算法的复杂度分析

欧几里得算法计算 $\gcd(a, b)$ 的迭代过程为：

$$(a, b) \to (b, a \bmod b)$$

每经过 **两轮** 迭代：

1. 第一轮：$(a, b) \to (b, a \bmod b)$，令 $a' = b, b' = a \bmod b$

2. 第二轮：$(a', b') \to (b', a' \bmod b') = (a \bmod b, b \bmod (a \bmod b))$

由引理可知：

$$a' \bmod b' < b' = a \bmod b < \frac{a}{2}$$

因此，**每执行 2 次取模运算，第一个操作数至少减半**。数值大小为 $N$ 时，至多进行 $2 \log_2 N$ 次取模操作，从而严格证明了欧几里得算法的时间复杂度为 $O(\log N)$。
