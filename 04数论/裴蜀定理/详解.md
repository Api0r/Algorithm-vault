
**裴蜀定理**（Bézout's identity，又称贝祖定理）是初等数论中的一条基本定理，建立了整数的**线性组合**与**最大公约数**之间的等价关系。

  

## 1. 定理内容

设 $a_1, a_2, \ldots, a_n$ 为不全为零的整数，其最大公约数为 $g = \gcd(a_1, a_2, \ldots, a_n)$。

  

### 核心结论

1. **存在性**：必存在一组整数 $x_1, x_2, \ldots, x_n \in \mathbb{Z}$，使得：
    
      
    
    $$a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = g$$
    
2. **充分必要条件**：对于任意整数 $C$，线性方程：
    
      
    
    $$a_1 x_1 + a_2 x_2 + \cdots + a_n x_n = C$$
    
    存在整数解 $(x_1, x_2, \ldots, x_n)$ 的**充要条件**是：
    
      
    
    $$g \mid C \quad (\text{即 } C \text{ 能被 } g \text{ 整除})$$
    
3. **最小正整数性**：形如 $a_1 x_1 + \cdots + a_n x_n$（其中 $x_i \in \mathbb{Z}$）的集合中，所能凑出的**最小正整数就是 $\gcd(a_1, \ldots, a_n)$**。
    
      
    

> **特例（互质判定）**：
> 
>   
> 
> $a, b$ 互质（即 $\gcd(a, b) = 1$）当且仅当存在整数 $x, y$ 使得 $ax + by = 1$。
> 
>   

## 2. 构造与求解：扩展欧几里得算法 (exgcd)

对于二元形式 $ax + by = \gcd(a, b)$，通常使用扩展欧几里得算法在 $\mathcal{O}(\log(\min(a, b)))$ 时间内递归构造特解。

  

### 递推推导

设欧几里得算法单步为 $a = q \cdot b + r$，其中 $r = a \bmod b$。

  

假设已知子问题 $b \cdot x_1 + (a \bmod b) \cdot y_1 = \gcd(b, a \bmod b) = \gcd(a, b)$ 的解 $(x_1, y_1)$，则：

  

$$b x_1 + (a - \lfloor a / b \rfloor b) y_1 = \gcd(a, b)$$

整理同类项可得：

  

$$a y_1 + b (x_1 - \lfloor a / b \rfloor y_1) = \gcd(a, b)$$

由此得到解的递推关系：

  

$$\begin{cases} x = y_1 \\ y = x_1 - \lfloor a / b \rfloor y_1 \end{cases}$$

递归基底为 $b = 0$ 时，$\gcd(a, 0) = a$，对应一组特解 $x = 1, y = 0$。

  

### 通解表示

若求得一组特解 $(x_0, y_0)$ 满足 $ax_0 + by_0 = c$（其中 $g \mid c$），则该方程的全部整数解为：

  

$$\begin{cases} x = x_0 + k \cdot \dfrac{b}{\gcd(a, b)} \\ y = y_0 - k \cdot \dfrac{a}{\gcd(a, b)} \end{cases} \quad (k \in \mathbb{Z})$$

## 3. C++ 标准实现

```c++
#include <iostream>
#include <tuple>

// 返回值: tuple<g, x, y> 满足 a*x + b*y = g = gcd(a, b)
template <typename T = long long>
std::tuple<T, T, T> exgcd(T a, T b) {
    if (b == 0) {
        return {a, 1, 0};
    }
    auto [g, x1, y1] = exgcd(b, a % b);
    T x = y1;
    T y = x1 - (a / b) * y1;
    return {g, x, y};
}

// 求解 ax + by = c 的一组特解及最小非负 x 解
template <typename T = long long>
bool solve_linear_diophantine(T a, T b, T c, T &x, T &y, T &g) {
    std::tie(g, x, y) = exgcd(a, b);
    if (c % g != 0) return false; // 无整数解
    
    T scale = c / g;
    x *= scale;
    y *= scale;

    // 将 x 调整到 [0, b / g - 1] 范围内的最小非负整数
    T mod = std::abs(b / g);
    x = (x % mod + mod) % mod;
    y = (c - a * x) / b;
    return true;
}
```

```c++
/*
裴蜀定理：整数 a_1...a_k 的所有线性组合恰为 gcd(a_1,...,a_k) 的倍数。
用途：判断方程 sum a_i * x_i = target 是否有整数解。
*/

inline int gcdAll(const vector<int>& a) {
    int res = 0;
    for (int val : a) res = gcd(res, val);
    return res >= 0 ? res : -res;
}

inline bool ask(const vector<int>& coe, int t) {
    int d = gcdAll(coe);
    return d == 0 ? t == 0 : t % d == 0;
}
```

## 4. 典型应用场景

- **乘法逆元**：当 $\gcd(a, m) = 1$ 时，求解同余方程 $ax \equiv 1 \pmod m$ 等价于解不定方程 $ax + my = 1$，求出的 $x \bmod m$ 即为 $a$ 模 $m$ 下的逆元。
    
      
    
- **线性同余方程组（中国剩余定理 / EXCRT）**：在模数不互质的情况下，合并同余方程 $x \equiv r_1 \pmod{m_1}$ 和 $x \equiv r_2 \pmod{m_2}$ 本质上是利用裴蜀定理求解 $m_1 k_1 - m_2 k_2 = r_2 - r_1$。
    
      
    
- **步长格点与可达性判定**：如上面赛车反弹题目或“容量分别为 $A$ 和 $B$ 的水壶能否量出 $C$ 升水”（倒水问题），能否达到目标状态完全取决于 $C$ 是否为 $\gcd(A, B)$ 的整数倍。
