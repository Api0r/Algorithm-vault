
# 一个数 $n$ 模一个比它小的数，能得到的最大余数是 $\lfloor \frac{n-1}{2} \rfloor$


要理解为什么一个数 $n$ 模一个比它小的数，能得到的最大余数是 $\lfloor \frac{n-1}{2} \rfloor$，我们可以从**余数的定义**和**几何直观**两个角度来拆解。

假设我们用 $n$ 去模一个正整数 $m$（其中 $1 \le m \le n$），得到的商是 $q$，余数是 $r$。

那么有公式：

$$n = q \times m + r \quad (0 \le r < m)$$

我们想要让余数 $r$ 尽可能地大。

### 1. 为什么商 $q$ 必须等于 1？

根据公式 $r = n - q \times m$，为了让 $r$ 最大，我们在减去 $q \times m$ 时，减去的量越小越好。

- 如果商 $q \ge 2$，那么 $n$ 至少要减去 $2m$，剩下的余数 $r$ 就会被严重压缩。
    
- 因此，要拿到最大的余数，**商 $q$ 必须刚好等于 1**。
    

当 $q = 1$ 时，公式简化为：

$$n = 1 \times m + r \implies r = n - m$$

这时候，为了让余数 $r$ 尽量大，我们就需要让除数 $m$ 尽量小。

### 2. 除数 $m$ 的下界约束

虽然我们希望 $m$ 越小越好，但别忘了余数的一个铁律：**余数必须严格小于除数**（$r < m$）。

既然 $r = n - m$，代入 $r < m$ 中：

$$n - m < m$$

$$n < 2m$$

$$m > \frac{n}{2}$$

因为 $m$ 必须是整数，所以 $m$ 能够取到的**最小整数值**就是比 $\frac{n}{2}$ 大的最小整数：

- 如果 $n$ 是奇数，$m_{min} = \frac{n+1}{2}$
    
- 如果 $n$ 是偶数，$m_{min} = \frac{n}{2} + 1$
    

统一写成向下取整的形式，就是：

$$m_{min} = \lfloor \frac{n}{2} \rfloor + 1$$

### 3. 计算最大余数

既然找到了能让 $q=1$ 的最小除数 $m_{min}$，我们直接用 $r = n - m_{min}$ 就能算出最大余数：

$$r_{max} = n - \left( \lfloor \frac{n}{2} \rfloor + 1 \right)$$

我们可以分奇偶性代入验证：

- **当 $n$ 为奇数时：**
    
    $$\lfloor \frac{n}{2} \rfloor = \frac{n-1}{2}$$
    
    $$r_{max} = n - (\frac{n-1}{2} + 1) = n - \frac{n+1}{2} = \frac{n-1}{2}$$
    
    由于 $n$ 是奇数，$\frac{n-1}{2}$ 本身就是整数，它也等于 $\lfloor \frac{n-1}{2} \rfloor$。
    
- **当 $n$ 为偶数时：**
    
    $$\lfloor \frac{n}{2} \rfloor = \frac{n}{2}$$
    
    $$r_{max} = n - (\frac{n}{2} + 1) = \frac{n}{2} - 1 = \frac{n-2}{2}$$
    
    此时我们看一下目标表达式 $\lfloor \frac{n-1}{2} \rfloor$，因为 $n$ 是偶数，$n-1$ 是奇数，所以 $\lfloor \frac{n-1}{2} \rfloor = \frac{n-2}{2}$。两边完全相等。
    

因此，无论 $n$ 是奇数还是偶数，最大余数都可以完美地统一表示为：

$$r_{max} = \lfloor \frac{n-1}{2} \rfloor$$

### 4. 直观实例

我们可以拿具体的数字来过一遍这个逻辑，就会非常清晰：

|**n 的值**|**寻找 m 的过程**|**最大余数 rmax​**|**对应公式 ⌊2n−1​⌋**|
|---|---|---|---|
|**$n = 11$** (奇数)|半数是 5.5。我们选 $m = 6$。<br><br>  <br><br>$11 \div 6 = 1 \dots 5$|**5**|$\lfloor \frac{10}{2} \rfloor = 5$|
|**$n = 12$** (偶数)|半数是 6。为了不整除，必须选 $m = 7$。<br><br>  <br><br>$12 \div 7 = 1 \dots 5$|**5**|$\lfloor \frac{11}{2} \rfloor = 5$|

**总结：** 模运算要留下最大的余数，本质上就是找一个刚好过半的数 $m$，让 $n$ 只能装下 $1$ 个 $m$，而剩下的那“一小半”就是能榨出来的最大余数。

```c++
void ap() {
	int n; cin >> n;

        cout << 0 << endl;

    }
    
    cout << __lg(n + 1) << endl;
    
    
	return ;
}
```

```c++
void ap() {
	int n; cin >> n;
    
    if (n == 0) {
        cout << 0 << endl;
        return;
    }
    
    int ans =  0;
    while (n) {
        ans++;
        n = n % (n / 2 + 1);
    }
    
    cout << ans << endl;
    
    
	return ;
}
```
