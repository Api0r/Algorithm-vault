# 1.组合数学

[B-小L的彩球_2026牛客寒假算法基础集训营6](https://ac.nowcoder.com/acm/contest/120566/B)

```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'

/*
用途：自动取模整数。直接写 MInt<P>，P=0 时先 MInt<0>::setMod(p)。
接口：pow(n)、inv()、四则运算、输入输出；默认 Z 为模 998244353。
约定：inv()/除法要求模数为质数；动态模数需满足 1 < p < 2^31。
性能：内部值固定为 i32，故在 #define int long long 下也不会把大数组翻倍。
*/
using i32 = int32_t;
constexpr i32 mod = 998244353;

template <class T> T mypow(T a, int n) {
    assert(n >= 0);
    T r = T(1);
    while (n) {
        if (n & 1) r *= a;
        a *= a;
        n >>= 1;
    }
    return r;
}

template <i32 P> struct MInt {
    static_assert(P >= 0);

    i32 x = 0;
    inline static i32 md = P ? P : mod;

    MInt() = default;
    MInt(int v) : x(norm(v)) {}

    static i32 askMod() {
        return P ? P : md;
    }

    static void setMod(i32 v) {
        static_assert(P == 0, "Only MInt<0> supports a dynamic modulus.");
        assert(v > 1);
        md = v;
    }

    static i32 norm(int v) {
        v %= askMod();
        if (v < 0) v += askMod();
        return static_cast<i32>(v);
    }

    i32 val() const {
        return x;
    }

    explicit operator i32() const {
        return x;
    }

    bool ask0() const {
        return x == 0;
    }

    MInt pow(int n) const {
        return mypow(*this, n);
    }

    MInt inv() const {
        assert(x);
        return pow(askMod() - 2);
    }

    MInt operator-() const {
        return MInt(x ? askMod() - x : 0);
    }

    MInt& operator+=(MInt a) {
        i32 p = askMod();
        if (x >= p - a.x) x -= p - a.x;
        else x += a.x;
        return *this;
    }

    MInt& operator-=(MInt a) {
        x -= a.x;
        if (x < 0) x += askMod();
        return *this;
    }

    MInt& operator*=(MInt a) {
        x = static_cast<i32>(static_cast<int>(x) * a.x % askMod());
        return *this;
    }

    MInt& operator/=(MInt a) {
        return *this *= a.inv();
    }

    MInt& operator++() {
        return *this += 1;
    }

    MInt operator++(i32) {
        MInt a = *this;
        ++*this;
        return a;
    }

    MInt& operator--() {
        return *this -= 1;
    }

    MInt operator--(i32) {
        MInt a = *this;
        --*this;
        return a;
    }

    friend MInt operator+(MInt a, MInt b) {
        return a += b;
    }

    friend MInt operator-(MInt a, MInt b) {
        return a -= b;
    }

    friend MInt operator*(MInt a, MInt b) {
        return a *= b;
    }

    friend MInt operator/(MInt a, MInt b) {
        return a /= b;
    }

    friend bool operator==(MInt a, MInt b) {
        return a.x == b.x;
    }

    friend bool operator!=(MInt a, MInt b) {
        return a.x != b.x;
    }

    friend istream& operator>>(istream& is, MInt& a) {
        int x;
        is >> x;
        a = MInt(x);
        return is;
    }

    friend ostream& operator<<(ostream& os, const MInt& a) {
        return os << a.x;
    }
};

template <i32 V, i32 P> const MInt<P> IV = MInt<P>(V).inv();

using Z = MInt<mod>;

/*
用途：阶乘、逆阶乘与 C(n,k)、A(n,k)。
用法：Comb<Z> c(n)；Z 可为任意 MInt<P>。
前提：模数为质数，且查询 n < mod；首次扩展 O(n)，之后 O(1)。
*/
template <class Z> struct Comb {
    int n = 0;
    vector<Z> f{Z(1)}, g{Z(1)};

    Comb() = default;
    explicit Comb(int m) {
        init(m);
    }

    void init(int m) {
        assert(m >= 0 && m < Z::askMod());
        if (m <= n) return;
        f.resize(m + 1);
        g.resize(m + 1);
        for (int i = n + 1; i <= m; ++i) f[i] = f[i - 1] * i;
        g[m] = f[m].inv();
        for (int i = m; i > n; --i) g[i - 1] = g[i] * i;
        n = m;
    }

    Z fac(int x) {
        assert(x >= 0);
        if (x > n) init(x);
        return f[x];
    }

    Z ifac(int x) {
        assert(x >= 0);
        if (x > n) init(x);
        return g[x];
    }

    Z C(int x, int k) {
        if (x < 0 || k < 0 || k > x) return Z(0);
        return fac(x) * ifac(k) * ifac(x - k);
    }

    Z A(int x, int k) {
        if (x < 0 || k < 0 || k > x) return Z(0);
        return fac(x) * ifac(x - k);
    }
};

Comb<Z> comb(1000005);

void ap() {
    int n, x, t;
    cin >> n >> x >> t;
    int y = n - x;

    if (t == 0) {
        if (x == 0 || x == n) cout << 1 << endl;
        else cout << 0 << endl;
        return;
    }

    if (x == 0 || y == 0) {
        cout << 0 << endl;
        return;
    }

    Z ans = comb.C(x - 1, (t + 2) / 2 - 1) * comb.C(y - 1, (t + 1) / 2 - 1)
          + comb.C(x - 1, (t + 1) / 2 - 1) * comb.C(y - 1, (t + 2) / 2 - 1);

    cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    cin >> T;
    while (T--) {
        ap();
    }
    return 0;
}
```

这个题目看似是“分球到左右两个盒子”和“相邻球连线”的物理模型，实际上是一个非常标准的**01序列与连续段划分**的组合数学模型。

### 第一步：物理模型 $\rightarrow$ 01 序列模型

原题中的规则可以逐一翻译成序列语言：

- **球的放置**：

    - $1 \sim n$ 号球按顺序排成一排。

    - 将放入**左盒**的球记为数字 `0`。

    - 将放入**右盒**的球记为数字 `1`。

- **球的数量约束**：

    - 左盒有 $x$ 个球 $\iff$ 序列中有 **$x$ 个 `0`**。

    - 右盒有 $n-x$ 个球 $\iff$ 序列中有 **$y = n-x$ 个 `1`**。

- **露在外面连线的物理含义**：

    - 相邻两个球连线露在外面 $\iff$ 这两个球一个在左盒、一个在右盒 $\iff$ 序列中相邻两个字符**不相同**（发生了 `01` 或 `10` 的字符切换）。

    - 露在外面的线一共有 $t$ 条 $\iff$ 序列中相邻字符**发生切换的次数恰好为 $t$ 次**。

> **转化后的等价问题：**
>
>
>
> 构造一个长度为 $n$ 的 01 字符串，其中包含 $x$ 个 `0` 和 $n-x$ 个 `1`，且相邻字符不同的位置恰好有 $t$ 处，求合法的字符串总数。
>
>

### 第二步：字符切换 $\rightarrow$ 连续同字符段（Run）

在 01 字符串中，每次字符切换都意味着“前一个同字符段结束，后一个新字符段开始”：

- **切换次数与总段数的关系**：

    - 如果 $t = 0$ 次切换：整个字符串只有 $1$ 段（如 `0000` 或 `1111`）。

    - 如果 $t = 1$ 次切换：整个字符串分为 $2$ 段（如 `00|111` 或 `1|000`）。

    - 产生 $t$ 次切换 $\iff$ 整个字符串被切分成了 **$m = t + 1$ 个连续段**。

- **段的交替特性**：

    连续段必然是 `0` 段和 `1` 段交替出现的（不可能有两个 `0` 段相邻，否则它们会合并为一段）。

    因此：

    - 若以 `0` 开头，段的结构为：`0段, 1段, 0段, 1段, ...`

    - 若以 `1` 开头，段的结构为：`1段, 0段, 1段, 0段, ...`

### 第三步：段数分配 $\rightarrow$ 隔板法计数

总共有 $t + 1$ 段，我们分别看以 `0` 开头和以 `1` 开头时，`0` 段和 `1` 段各有多少个：

#### 1. 若以 `0` 开头

- `0` 段在第 $1, 3, 5, \dots$ 奇数个位置，数量为向上取整：$c_0 = \lceil \frac{t+1}{2} \rceil = \lfloor \frac{t+2}{2} \rfloor$

- `1` 段在第 $2, 4, 6, \dots$ 偶数个位置，数量为向下取整：$c_1 = \lfloor \frac{t+1}{2} \rfloor$

**求方案数（隔板法）：**

- 将 $x$ 个 `0` 切分成 $c_0$ 个非空段：在 $x-1$ 个空隙中插入 $c_0-1$ 个隔板，方案数为 $\binom{x-1}{c_0-1} = \binom{x-1}{\lfloor \frac{t+2}{2} \rfloor - 1}$

- 将 $y$ 个 `1` 切分成 $c_1$ 个非空段：在 $y-1$ 个空隙中插入 $c_1-1$ 个隔板，方案数为 $\binom{y-1}{c_1-1} = \binom{y-1}{\lfloor \frac{t+1}{2} \rfloor - 1}$

- 两者独立，根据乘法原理相乘：

    $$\text{方案数}_0 = \binom{x-1}{\lfloor \frac{t+2}{2} \rfloor - 1} \times \binom{n-x-1}{\lfloor \frac{t+1}{2} \rfloor - 1}$$

#### 2. 若以 `1` 开头

同理，只需将 `0` 和 `1` 的角色互换：

- `1` 段有 $c_1 = \lfloor \frac{t+2}{2} \rfloor$ 个

- `0` 段有 $c_0 = \lfloor \frac{t+1}{2} \rfloor$ 个

- 两者相乘得到方案数：

    $$\text{方案数}_1 = \binom{x-1}{\lfloor \frac{t+1}{2} \rfloor - 1} \times \binom{n-x-1}{\lfloor \frac{t+2}{2} \rfloor - 1}$$

### 模型映射全景表

|**题目原始描述**|**01 序列模型**|**连续段与隔板模型**|
|---|---|---|
|第 $i$ 个球放左盒/右盒|字符串第 $i$ 位是 `0` 或 `1`|元素归属|
|左盒 $x$ 个，右盒 $n-x$ 个|串中有 $x$ 个 `0`，有 $n-x$ 个 `1`|两类待切分元素的总数|
|相邻两球跨盒，连线露在外面|相邻字符不同（`01` 或 `10`）|产生一次分段切割|
|露在外面的线恰有 $t$ 条|字符切换恰好 $t$ 次|整个序列切成 $t + 1$ 个连续非空段|
|求总放球方案数|满足条件的合法 01 串总数|$\text{方案数}_0 + \text{方案数}_1$|
