
显然，完全平方数的因子个数为奇数
下面从质因数分解的角度看

# 定理：正整数的因数个数为奇数，当且仅当其质因数分解中所有质因子的指数均为偶数

设正整数 $x > 1$ 的唯一质因数分解（标准素因数分解式）为：

$$x = \prod_{k=1}^{m} p_k^{d_k} = p_1^{d_1} p_2^{d_2} \cdots p_m^{d_m}$$

其中 $p_1 < p_2 < \dots < p_m$ 为互异的素数，指数 $d_k \in \mathbb{N}^+$。记 $d(x)$ 为 $x$ 的正因数个数。

# 一、 因数构造与因数个数公式

根据算术基本定理，$x$ 的任意正因数 $y$ 的素因子必属于素数集 $\{p_1, p_2, \dots, p_m\}$，且可唯一表示为：

$$y = \prod_{k=1}^{m} p_k^{c_k}, \quad \text{其中 } c_k \in \{0, 1, 2, \dots, d_k\}$$

对每一个固定的素因子 $p_k$，其指数 $c_k$ 的可能取值个数为：

$$\vert{}\{0, 1, 2, \dots, d_k\}\vert{} = d_k + 1$$

由于每个素因子 $p_k$ 的指数 $c_k$ 的选取在集合论意义下是相互独立的，由组合数学的乘法原理，正因数总数等于所有素因子可选指数状态的笛卡尔积大小：

$$d(x) = \prod_{k=1}^{m} (d_k + 1) = (d_1 + 1)(d_2 + 1)\cdots(d_m + 1)$$

# 二、 核心推导：质因子指数全为偶数的充要性

设整数环在模 2 意义下的同余系统 $\mathbb{Z}_2$，考察因数个数 $d(x)$ 的奇偶性。

# 1. 充分性（所有指数为偶数 $\implies d(x)$ 为奇数）

若对于所有的素因子 $p_k$（$1 \le k \le m$），其对应的指数 $d_k$ 均为偶数，即：

$$\forall k \in \{1, 2, \dots, m\}, \quad d_k \equiv 0 \pmod 2$$

则有：

$$d_k + 1 \equiv 0 + 1 \equiv 1 \pmod 2$$

代入因数个数公式的模 2 乘积：

$$d(x) = \prod_{k=1}^{m} (d_k + 1) \equiv \prod_{k=1}^{m} 1 \equiv 1 \pmod 2$$

即 $d(x)$ 必为奇数。

## 2. 必要性（$d(x)$ 为奇数 $\implies$ 所有指数必须均为偶数）

若 $d(x)$ 为奇数，即：

$$\prod_{k=1}^{m} (d_k + 1) \equiv 1 \pmod 2$$

在整环中，模 2 乘法满足零因子性质：**若干整数之积为奇数（模 2 为 1），当且仅当其中每一个乘数本身均为奇数**。

反证法：

假设存在某个素因子 $p_j$（$1 \le j \le m$），其指数 $d_j$ 为奇数，即 $d_j \equiv 1 \pmod 2$。

则对应项：

$$d_j + 1 \equiv 1 + 1 \equiv 0 \pmod 2$$

此时乘积中出现偶数因子：

$$d(x) = (d_j + 1) \cdot \prod_{k \neq j} (d_k + 1) \equiv 0 \cdot \prod_{k \neq j} (d_k + 1) \equiv 0 \pmod 2$$

这与 $d(x)$ 为奇数的题设产生直接矛盾。

因此，假设不成立，不能存在任何奇数指数。即必须满足：

$$\forall k \in \{1, 2, \dots, m\}, \quad d_k + 1 \equiv 1 \pmod 2 \iff d_k \equiv 0 \pmod 2$$

# 三、 结论

综合上述推导：

$$\prod_{k=1}^{m} (d_k + 1) \equiv 1 \pmod 2 \iff \forall k \in [1, m], \ d_k \equiv 0 \pmod 2$$

从质因数分解的角度，正整数 $x$ 拥有奇数个因数的**充要条件**是：其分解式中**每一个质因子的指数 $d_k$ 都必须是偶数**。
