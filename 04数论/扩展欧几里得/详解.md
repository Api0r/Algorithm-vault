
**扩展欧几里得算法**（Extended Euclidean Algorithm，常简称为 **exgcd**）是欧几里得算法（辗转相除法）的扩充，用于在求出整数 $a, b$ 的最大公约数 $\gcd(a, b)$ 的同时，求出一组整数解 $(x, y)$ 满足裴蜀等式：

  

$$a x + b y = \gcd(a, b)$$

## 1. 递归推导机制

欧几里得算法的核心等式为：

  

$$\gcd(a, b) = \gcd(b, a \bmod b)$$

设在下一层递归中，已知满足子问题的特解 $(x_1, y_1)$：

  

$$b x_1 + (a \bmod b) y_1 = \gcd(b, a \bmod b) = \gcd(a, b)$$

利用带余除法将余数展开为 $a \bmod b = a - \left\lfloor \dfrac{a}{b} \right\rfloor b$：

  

$$\begin{aligned} & b x_1 + \left(a - \left\lfloor \frac{a}{b} \right\rfloor b\right) y_1 = \gcd(a, b) \\ \implies & a y_1 + b \left(x_1 - \left\lfloor \frac{a}{b} \right\rfloor y_1\right) = \gcd(a, b) \end{aligned}$$

对比目标形式 $a x + b y = \gcd(a, b)$，可直接对应出系数转移方程：

  

$$\begin{cases} x = y_1 \\ y = x_1 - \left\lfloor \dfrac{a}{b} \right\rfloor y_1 \end{cases}$$

递归出口为 $b = 0$ 时，$\gcd(a, 0) = a$，方程为 $a x + 0 y = a$，此时直接取特解：

  

$$\begin{cases} x = 1 \\ y = 0 \end{cases}$$

## 2. 通用不定方程的求解

对于一般形式的线性丢番图方程：

  

$$a x + b y = c$$

### 求解步骤

1. **无解判定**：调用 exgcd 求得 $g = \gcd(a, b)$ 和 $a x_0 + b y_0 = g$ 的特解 $(x_0, y_0)$。若 $g \nmid c$，方程**无整数解**。
    
      
    
2. **倍率放大**：两边同时乘以 $\dfrac{c}{g}$，得到方程的一组特解：
    
      
    
    $$\begin{cases} x_c = x_0 \cdot \dfrac{c}{g} \\ y_c = y_0 \cdot \dfrac{c}{g} \end{cases}$$
    
3. **通解生成**：
    
      
    
    $$\begin{cases} x = x_c + k \cdot \dfrac{b}{g} \\ y = y_c - k \cdot \dfrac{a}{g} \end{cases} \quad (k \in \mathbb{Z})$$
    

### 最小非负整数解转化

若需要求使得 $x$ 最小的非负整数解，令模数步长 $M = \left\vert{}\dfrac{b}{g}\right\vert{}$：

  

$$x_{\min} = (x_c \bmod M + M) \bmod M$$

再将 $x_{\min}$ 代入原方程求出对应的 $y$：

  

$$y = \frac{c - a \cdot x_{\min}}{b}$$

## 3. 标准现代 C++ 实现

C++

```
#include <iostream>
#include <tuple>
#include <cmath>

// 递归形式 exgcd
// 返回 tuple: {g, x, y} 满足 a*x + b*y = g = gcd(a, b)
template <typename T = long long>
std::tuple<T, T, T> exgcd(T a, T b) {
    if (b == 0) {
        return {a, 1, 0};
    }
    auto [g, x1, y1] = exgcd(b, a % b);
    T x = y1;
    T y = x1 - (a / b) * y1;
    return {g, x, y};
}

// 非递归迭代形式（省去函数递归栈开销）
template <typename T = long long>
std::tuple<T, T, T> exgcd_iter(T a, T b) {
    T x0 = 1, y0 = 0;
    T x1 = 0, y1 = 1;
    while (b != 0) {
        T q = a / b;
        T r = a % b;
        a = b;
        b = r;
        
        T next_x = x0 - q * x1;
        x0 = x1;
        x1 = next_x;

        T next_y = y0 - q * y1;
        y0 = y1;
        y1 = next_y;
    }
    return {a, x0, y0};
}

// 求解 ax + by = c 的最小非负 x 解
template <typename T = long long>
bool solve_diophantine(T a, T b, T c, T &min_x, T &corresp_y, T &g) {
    auto [gcd_val, x0, y0] = exgcd(a, b);
    g = gcd_val;
    if (c % g != 0) {
        return false; // 无解
    }

    T scale = c / g;
    T step = std::abs(b / g);

    // 计算最小非负 x
    min_x = (x0 % step * (scale % step)) % step;
    min_x = (min_x + step) % step;
    corresp_y = (c - a * min_x) / b;
    return true;
}
```

## 4. 典型核心应用

1. **求乘法逆元**：
    
    同余方程 $a x \equiv 1 \pmod m$ 展开即为：
    
      
    
    $$a x + m y = 1$$
    
    当且仅当 $\gcd(a, m) = 1$ 时存在解，解出的 $x$ 在模 $m$ 意义下的最小非负值即为 $a^{-1} \pmod m$。此方法**不要求模数 $m$ 为质数**（区别于费马小定理）。
    
      
    
2. **同余方程转化**：
    
    方程 $a x \equiv b \pmod m$ 转化为不定方程 $a x - m y = b$，直接套用线性丢番图求解模板。
    
      
    
3. **中国剩余定理扩展 (EXCRT)**：
    
    用于处理模数不互质的一元同余方程组合并：通过解 $k_1 m_1 - k_2 m_2 = r_2 - r_1$ 求出通解系数。
