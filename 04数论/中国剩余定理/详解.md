
**中国剩余定理**（Chinese Remainder Theorem, 简称 **CRT**）源自《孙子算经》中的“物不知数”问题，用于求解一元线性同余方程组。

  

## 1. 经典 CRT（模数两两互质）

### 问题形式

给定一组同余方程：

  

$$\begin{cases} x \equiv a_1 \pmod{m_1} \\ x \equiv a_2 \pmod{m_2} \\ \quad \vdots \\ x \equiv a_k \pmod{m_k} \end{cases}$$

**核心前提条件**：模数 $m_1, m_2, \ldots, m_k$ **两两互质**，即 $\forall i \ne j, \gcd(m_i, m_j) = 1$。

  

### 构造性解法与推导

1. **计算总模数**：
    
      
    
    $$M = \prod_{i=1}^k m_i = m_1 \cdot m_2 \cdots m_k$$
    
2. **分离变量（构造基底）**：
    
    对于每个方程 $i$，令：
    
      
    
    $$M_i = \frac{M}{m_i} = \prod_{j \ne i} m_j$$
    
    因为模数两两互质，必有 $\gcd(M_i, m_i) = 1$。
    
      
    
3. **求逆元**：
    
    由裴蜀定理与扩展欧几里得算法，存在整数 $t_i$ 满足：
    
      
    
    $$M_i \cdot t_i \equiv 1 \pmod{m_i}$$
    
    即 $t_i$ 是 $M_i$ 模 $m_i$ 的乘法逆元。
    
      
    
4. **正交性质分析**：
    
    考察项 $e_i = M_i \cdot t_i$ 在模不同 $m_j$ 下的取值：
    
      
    - 当 $j = i$ 时： $e_i = M_i t_i \equiv 1 \pmod{m_i}$
        
          
        
    - 当 $j \ne i$ 时：因为 $m_j \mid M_i$，所以 $e_i \equiv 0 \pmod{m_j}$
        
          
        
5. **通解与唯一最小非负解**：
    
    将各项加权累加即可同时满足所有同余条件：
    
      
    
    $$x = \sum_{i=1}^k a_i M_i t_i \pmod M$$
    
    方程在模 $M$ 意义下有**唯一解**，全部整数解为 $x + kM$ ($k \in \mathbb{Z}$)。
    
      
    

## 2. 扩展中国剩余定理 (EXCRT，模数不互质)

当模数 $m_i$ **不保证两两互质**时，经典 CRT 的逆元可能不存在。此时通过**两两方程合并**的方式求解。

  

### 合并两方程推导

假设已有前若干个方程合并出的解为 $x$，模数为 $M$（即 $x \equiv \text{ans} \pmod M$）。现在加入新方程：

  

$$\begin{cases} x \equiv a_1 \pmod{m_1} \\ x \equiv a_2 \pmod{m_2} \end{cases}$$

将其转化为不定方程形式：

  

$$x = k_1 m_1 + a_1 = k_2 m_2 + a_2$$

移项整理得：

  

$$k_1 m_1 - k_2 m_2 = a_2 - a_1$$

设 $g = \gcd(m_1, m_2)$：

  

- **无解判定**：若 $g \nmid (a_2 - a_1)$，则方程组**无整数解**。
    
      
    
- **解出特解**：用扩展欧几里得算法解 $m_1 p + m_2 q = g$，则：
    
      
    
    $$k_1 = p \cdot \frac{a_2 - a_1}{g}$$
    
- **合并模数**：
    
      
    
    $$k_1 \equiv k_1 \pmod{\frac{m_2}{g}}$$
    
    将最小非负 $k_1$ 代回原式可得新解 $x' = a_1 + k_1 m_1$，新模数为：
    
      
    
    $$M_{\text{new}} = \operatorname{lcm}(m_1, m_2) = \frac{m_1 m_2}{g}$$
    
    两个方程成功合并为一个等价方程：
    
      
    
    $$x \equiv x' \pmod{M_{\text{new}}}$$
    

重复合并 $k-1$ 次，即可求出整个方程组的解。

  

## 3. C++ 标准实现 (EXCRT 模板)

EXCRT 向下兼容普通 CRT，是竞赛和实际工程中最常用的通用模板（通过 `__int128` 防止中间乘法溢出）：


```c++
#include <iostream>
#include <vector>
#include <tuple>

using namespace std;

// 扩展欧几里得: 返回 gcd(a, b) 并求出 a*x + b*y = gcd(a, b) 的特解
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    long long g = exgcd(b, a % b, y, x);
    y -= (a / b) * x;
    return g;
}

// 求解 x = a_i (mod m_i)
// 返回值: 最小非负解 x；若无解返回 -1
long long excrt(const vector<long long>& a, const vector<long long>& m) {
    int n = a.size();
    long long x = 0;
    long long M = 1; // 当前合并后的模数

    for (int i = 0; i < n; ++i) {
        long long cur_a = a[i];
        long long cur_m = m[i];

        // 方程: M * k1 + cur_m * k2 = cur_a - x
        long long p, q;
        long long g = exgcd(M, cur_m, p, q);
        long long diff = cur_a - x;

        if (diff % g != 0) {
            return -1; // 无解
        }

        // 计算 k1，防止溢出使用 __int128
        long long mod_step = cur_m / g;
        long long k1 = static_cast<long long>(
            (__int128(p) * (diff / g) % mod_step + mod_step) % mod_step
        );

        // 更新 x 和总模数 M
        x += k1 * M;
        M = M / g * cur_m;
        x = (x % M + M) % M;
    }

    return x;
}
```

## 4. 经典模型与算法差异对比

|**特性**|**经典 CRT**|**扩展 CRT (EXCRT)**|
|---|---|---|
|**模数限制**|必须两两互质 ($\gcd(m_i, m_j) = 1$)|任意正整数，无互质限制|
|**计算流程**|批处理：预计算 $M$ 后求各分量逆元并累加|增量式：依次将两个同余方程合并为一个|
|**无解判定**|互质条件下必定有解|过程中若 $\gcd(M, m_i) \nmid (a_i - x)$ 则无解|
|**核心底层**|模逆元 / 扩展欧几里得|线性丢番图方程 / 扩展欧几里得|
