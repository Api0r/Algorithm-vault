## 构造函数

**以这个为例**

```c++
    BIT() = default;
    explicit BIT(int n) {
        init(n);
    }
```

这两段代码定义了结构体的两个**构造函数（Constructor）**，分别负责对象的“默认无参初始化”和“带大小的有参初始化”。

### 1. `BIT() = default;`（默认构造函数）

```c++
BIT() = default;
```

- **语法含义**：`= default` 是 C++11 引入的语法，表示显式要求编译器自动生成一个**标准的默认无参构造函数**。

- **为什么需要显式写出？**

    - 在 C++ 中，如果你**没有写任何构造函数**，编译器会自动为你生成一个无参构造函数。

    - 但是，一旦你写了带参数的构造函数（即下方的 `BIT(int n)`），**编译器就会立刻取消自动生成无参构造函数**。

    - 此时必须补上 `= default;`，否则写 `BIT<int> tr;` 这种无参初始化的代码就会**直接编译报错**。

- **触发场景**：

    ```c++
    BIT<int> tr;           // 正确：调用默认构造函数，内部 n = 0, bit 为空
    vector<BIT<int>> trs;  // 正确：容器扩容时需要无参构造
    ```

### 2. `explicit BIT(int n) { init(n); }`（有参构造函数）

```c++
explicit BIT(int n) {
    init(n);
}
```

- **语法含义**：接收一个整数 `n`，并在对象创建时直接调用 `init(n)` 函数，一次性完成大小设置与 `vector` 的内存分配清零。

- **关键字 `explicit` 的作用（禁止隐式类型转换）**：

    `explicit` 专门用来防止单个参数的构造函数引发“意外的隐式转换”。

    - **如果不加 `explicit`**：

        编译器允许把单个整数隐式“变成”一个树状数组对象。

        ```c++
        void solve(BIT<int> tr) { ... }

        // 假设某处手误传了个整数：
        solve(10); // 危险！隐式将 int 10 构造成了一个大小为 10 的 BIT 对象并传进去，不会报错
        BIT<int> tr = 10; // 危险！语义怪异但能编译通过
        ```

    - **加上 `explicit` 之后**：

        只能显式调用构造函数，上述写法会直接被编译器拦截报错，避免因类型误传引发隐蔽 Bug。

        ```c++
        BIT<int> tr(10);   // 正确：显式构造
        BIT<int> tr{10};   // 正确：C++11 列表初始化显式构造
        BIT<int> tr = 10;  // 编译错误！禁止隐式转换
        ```

### 3. 两者对比总结

|**构造函数写法**|**调用示例**|**内部状态**|**典型使用场景**|
|---|---|---|---|
|**`BIT() = default;`**|`BIT<int> tr;`|`n = 0`, `bit` 为空|全局变量声明、多组测试数据前先占位后续再 `init(n)`|
|**`explicit BIT(int n)`**|`BIT<int> tr(n);`|`n = n`, `bit` 预分配 $n+1$ 个零|已知 $n$ 的大小，一步完成定义与初始化|
