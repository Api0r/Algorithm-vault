## 成员函数

**以这个为例**

```c++
    template <class A>
    void build(const A &a) {
        fill(bit.begin(), bit.end(), T{});
        for (int i = 1; i <= n; ++i) {
            bit[i] += a[i];
            int j = i + (i & -i);
            if (j <= n) bit[j] += bit[i];
        }
    }
```

这段代码实现了树状数组的 **$O(n)$ 线性建树算法**。

它利用了树状数组的**树形包含关系**，避免了重复调用 $n$ 次单点修改（每次 $O(\log n)$，总耗时 $O(n \log n)$），只需单次遍历即可将普通数组构造成树状数组。

### 1. 语法逐行拆解

```c++
template <class A>
void build(const A &a) {
```

- **成员函数模板 `template <class A>`**：允许参数 `a` 是任意支持下标访问 `[]` 的容器或类型（例如 `std::vector<int>`、原生数组 `int a[]`、`std::array` 等），增加了泛用性。

- **`const A &a`**：使用**常量引用传递**，避免拷贝大数组的开销。

- **注意**：由于函数内直接访问 `a[i]` 且 $i$ 从 $1$ 开始，传入的数组 $a$ **必须是 1-indexed**（有效数据存在 $a[1 \dots n]$）。

```c++
    fill(bit.begin(), bit.end(), T{});
```

- 将内部的 `bit` 数组所有元素重置为泛型的默认零值 `T{}`（如 `int` 类型的 `0`）。

```c++
    for (int i = 1; i <= n; ++i) {
        bit[i] += a[i];
        int j = i + (i & -i);
        if (j <= n) bit[j] += bit[i];
    }
```

- 循环遍历 $1$ 到 $n$ 的每个位置：

    1. **`bit[i] += a[i]`**：首先将位置 $i$ 的原值累加到 `bit[i]`。

    2. **`int j = i + (i & -i)`**：计算节点 $i$ 在树状数组中的**直接父亲节点下标**（$i + \text{lowbit}(i)$）。

    3. **`if (j <= n) bit[j] += bit[i]`**：如果父节点在有效范围内，直接把当前节点维护的全部区间和（`bit[i]`）累加给父亲节点 `bit[j]`。

### 2. 为什么这样递推是对的？（核心数学原理）

树状数组本质上是一个有向森林/树形结构。每个节点 $i$ 维护区间 $(i - \text{lowbit}(i), i]$ 的和。

- 在遍历到位置 $i$ 时，由于 $i$ 之前的所有子节点 $k < i$ 已经全部遍历完成，**子节点维护的和已经被逐级累加到了 `bit[i]` 中**。

- 加上自身的单点值 `a[i]` 后，`bit[i]` 此时存储的就是**完整的区间和**。

- 节点 $i$ 的管辖区间完全被其直接父节点 $j = i + \text{lowbit}(i)$ 所包含。因此，只要把 `bit[i]` 的总和直接加给 `bit[j]`，父节点就能接收到该子树下的所有数据，信息不会遗漏也不会重复。

### 3. 图解推导示例（$n = 4$）

假设原数组 $a = [0, 1, 2, 3, 4]$（有效下标 $1 \sim 4$）：

|**步骤 i**|**原值累加 bit[i] += a[i]**|**父亲节点 j=i+lowbit(i)**|**传递更新 bit[j] += bit[i]**|**此时 bit 状态**|
|---|---|---|---|---|
|**$i = 1$**|`bit[1] = 1`|$j = 1 + 1 = 2$|`bit[2] += bit[1]` (`bit[2] = 1`)|`[-, 1, 1, 0, 0]`|
|**$i = 2$**|`bit[2] += 2` $\rightarrow$ `3`|$j = 2 + 2 = 4$|`bit[4] += bit[2]` (`bit[4] = 3`)|`[-, 1, 3, 0, 3]`|
|**$i = 3$**|`bit[3] = 3`|$j = 3 + 1 = 4$|`bit[4] += bit[3]` (`bit[4] = 6`)|`[-, 1, 3, 3, 6]`|
|**$i = 4$**|`bit[4] += 4` $\rightarrow$ `10`|$j = 4 + 4 = 8 > 4$|超出范围，不传递|`[-, 1, 3, 3, 10]`|

建树结束，`bit` 正确记录了各区间和：

- `bit[1] = a[1] = 1`

- `bit[2] = a[1] + a[2] = 3`

- `bit[3] = a[3] = 3`

- `bit[4] = a[1] + a[2] + a[3] + a[4] = 10`

### 4. 复杂度对比

- **传统建树（$n$ 次 `modify`）**：每个点向上更新到根节点，总时间为 $\sum_{i=1}^n O(\log n) = \mathbf{O(n \log n)}$。

- **线性建树（`build`）**：每个点仅向直接父节点传递一次，循环仅执行 $n$ 次，总时间为 $\mathbf{O(n)}$。
