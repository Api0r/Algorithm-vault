
哥德巴赫猜想（Goldbach's Conjecture）是数论中最古老且最著名的未解难题之一，由德国数学家克里斯蒂安·哥德巴赫（Christian Goldbach）于 1742 年提出。

简单来说，它的核心内容可以总结为一句话：

> **“任何大于 2 的偶数，都可以表示为两个素数（质数）之和。”**

## 表达形式与分类

哥德巴赫猜想通常分为两个主要版本：

### 1. 强哥德巴赫猜想（二素数猜想 / 偶数哥德巴赫猜想）

- **内容**：每一个大于 2 的偶数都可以写成两个素数之和。
    
- **示例**：
    
    - $4 = 2 + 2$
        
    - $6 = 3 + 3$
        
    - $8 = 3 + 5$
        
    - $10 = 3 + 7 = 5 + 5$
        
    - $100 = 3 + 97 = 11 + 89 = \dots$
        
- **现状**：**尚未证明**，是目前数论界重点攻克的难题。
    

### 2. 弱哥德巴赫猜想（三素数猜想 / 奇数哥德巴赫猜想）

- **内容**：每一个大于 5 的奇数都可以写成三个素数之和。
    
- **示例**：
    
    - $7 = 2 + 2 + 3$
        
    - $9 = 3 + 3 + 3$
        
    - $11 = 3 + 3 + 5$
        
- **现状**：**已解决**。2013 年，秘鲁数学家哈洛德·赫尔夫戈特（Harald Helfgott）彻底证明了弱哥德巴赫猜想。
    

## 主要研究进展（从“a + b”到陈氏定理）

数学家们在攻克强哥德巴赫猜想时，普遍采用“筛法”，尝试证明“每一个充分大的偶数都可以表示为一个素数因子不超过 $a$ 个的数，与一个素数因子不超过 $b$ 个的数之和”，简称 **$a + b$**。

哥德巴赫猜想的终极目标，就是证明 **$1 + 1$**。

|**年份**|**数学家**|**取得的突破成果 (a+b)**|**简要说明**|
|---|---|---|---|
|**1920**|布朗（V. Brun）|$9 + 9$|开创了现代筛法|
|**1938**|布赫夕塔布（A. Buchstab）|$5 + 5$|进一步优化筛法|
|**1956**|维诺格拉多夫（I. Vinogradov）|$3 + 3$|推进了分析数论方法|
|**1962**|潘承洞|$1 + 5$|中国数学家在此领域的重大突破|
|**1965**|布赫夕塔布 / 邦别里（E. Bombieri）|$1 + 3$|距离 $1+1$ 越来越近|
|**1966/1973**|**陈景润**|**$1 + 2$**|**“陈氏定理”**：任何充分大的偶数都可以表示为一个素数，加上一个素数或两个素数的乘积|

> **注**：陈景润证明的 $1 + 2$ 是至今为止人类在该问题上取得的**最高成就**。

## 计算机验证现状

虽然数学上的严格证明尚未完成，但借助计算机，研究人员已经对极大规模的数值进行了验证：

- 目前通过计算机验证，强哥德巴赫猜想在 **$4 \times 10^{18}$** 以内的一切偶数均成立。

```c++
bool is_prime(int n) {
    if (n <= 1) return false;
    if (n == 2) return true;
    if (n % 2 == 0) return false;
    for (int i = 3; i * i <= n; i += 2) {
        if (n % i == 0) return false;
    }
    return true;
}

void ap() {
	int n; cin >> n;
    
    if (n == 1) {
        cout << -1 << endl;
        return;
    }
    
    //偶数 = 质数 + 质数
    //奇数 = 3 + 偶数
    if (is_prime(n)) {
        cout << 1 << endl;
        return;
    }
    
    if (n % 2 == 0) {
        cout << 2 << endl;
        return;
    }
    
    if (is_prime(n - 2)) {
        cout << 2 << endl;
        return;
    }
    
    cout << 3 << endl;
    
    
	return ;
}
```

### 1. 如果 $N$ 本身就是质数 $\implies$ 答案是 $1$

直接选一个长度为 $N$ 的区间，一次吹灭。

### 2. 如果 $N$ 是偶数 $\implies$ 答案是 $2$（基于强哥德巴赫猜想）

- 根据**强哥德巴赫猜想**，任何大于 2 的偶数都可以表示为 **2 个质数之和**。
    
- 对于 $N = 2$，它本身是质数，答案是 $1$。
    
- 对于 $N > 2$ 的偶数（如 $4, 6, 8, \dots$），由于已被验证在 $4 \times 10^{18}$ 范围内完全成立（本题 $N \le 10^9$），它**一定能拆成 2 个质数之和**。
    
- 所以：**所有 $>2$ 的偶数，答案都是 $2$**！
    

### 3. 如果 $N$ 是奇数 $\implies$ 答案是 $2$ 或 $3$

- **情况 A：如果 $N - 2$ 是质数 $\implies$ 答案是 $2$**
    
    就像你上个问题探讨的那样，因为 $2$ 是偶质数，如果 $N - 2$ 是质数，那么 $N = 2 + (N - 2)$，可以用 **2 次**完成（例如 $N = 7 = 2 + 5$）。
    
- **情况 B：如果 $N - 2$ 是合数 $\implies$ 答案是 $3$**
    
    如果 $N-2$ 不是质数，根据**弱哥德巴赫猜想（已在 2013 年被证明成立）**，任何大于 5 的奇数都可以表示为 **3 个质数之和**（例如 $N = 11 = 3 + 3 + 5$）。
    
    因此，剩下的奇数**最多只需要 3 次**。
