
**杜教筛**（Du's Sieve）是一种用于在**亚线性时间**内求积性函数前缀和的算法。

对于一个积性函数 $f$，我们希望在极快的时间（通常是 $O(n^{2/3})$）内求出它的前缀和：

$$S(n) = \sum_{i=1}^n f(i)$$

当 $n \le 10^9$ 或 $10^{11}$ 时，常规的 $O(n)$ 线性筛（欧拉筛）会超时或超内存，这时杜教筛就派上用场了。

## 核心推导与原理

杜教筛的核心思想是利用**狄利克雷卷积**（Dirichlet Convolution）引入一个辅助函数 $g$，通过构造关系来消去大项，利用整除分块进行递归求解。

设另有一积性函数 $g$，记他们的狄利克雷卷积为 $h = f * g$，即 $h(n) = \sum_{d\vert{}n} g(d) f(\frac{n}{d})$。

我们来求卷积的前缀和：

$$\sum_{i=1}^n (f * g)(i) = \sum_{i=1}^n \sum_{d\vert{}i} g(d)f\left(\frac{i}{d}\right)$$

交换求和顺序，改写为枚举 $d$：

$$\sum_{i=1}^n (f * g)(i) = \sum_{d=1}^n g(d) \sum_{i=1}^{\lfloor \frac{n}{d} \rfloor} f(i) = \sum_{d=1}^n g(d) S\left(\lfloor \frac{n}{d} \rfloor\right)$$

将右边式子的第一项（$d=1$ 时的项）提出来：

$$\sum_{i=1}^n (f * g)(i) = g(1)S(n) + \sum_{d=2}^n g(d) S\left(\lfloor \frac{n}{d} \rfloor\right)$$

移项，得到**杜教筛的核心递推公式**：

$$g(1)S(n) = \sum_{i=1}^n (f * g)(i) - \sum_{d=2}^n g(d) S\left(\lfloor \frac{n}{d} \rfloor\right)$$

> **使用前提：**
> 
> 1. 可以快速（$O(1)$ 或 $O(\log n)$）求出 $h = f*g$ 的前缀和。
>     
> 2. 可以快速求出 $g$ 的任意区间和（以便对第二项进行**整除分块**）。
>     

## 常见构造与应用

为了求 $f$ 的前缀和，我们需要精心选择 $g$：

|**目标函数 f(n)**|**辅助函数 g(n)**|**卷积 h=f∗g**|**递推关系式**|
|---|---|---|---|
|**莫比乌斯函数** $\mu(n)$|$I(n) = 1$|$\epsilon(n) = [n=1]$|$S(n) = 1 - \sum_{d=2}^n S\left(\lfloor \frac{n}{d} \rfloor\right)$|
|**欧拉函数** $\varphi(n)$|$I(n) = 1$|$\text{id}(n) = n$|$S(n) = \frac{n(n+1)}{2} - \sum_{d=2}^n S\left(\lfloor \frac{n}{d} \rfloor\right)$|

## 算法优化与复杂度

如果我们直接使用上面的公式进行记忆化递归（使用 `map` 或 `unordered_map`）：

- 直接递归的时间复杂度为 $O(n^{3/4})$。
    

### 黄金优化：预处理线性筛

在实际应用中，我们会先用**线性筛**预处理出前 $k$ 个元素的 $S(i)$（通常取 $k = n^{2/3}$）。

对于大于 $k$ 的部分，再使用杜教筛递归计算并用哈希表记忆化。

- 此时，总时间复杂度可以优化至：
    
    $$\mathcal{O}(n^{2/3})$$
    
- 空间复杂度通常也为 $O(n^{2/3})$（取决于预处理的数组大小）。
    

## C++ 模板实现（以 $\mu$ 和 $\varphi$ 为例）

以下是通用的杜教筛 C++ 实现模板。为了避免 `std::unordered_map` 被卡或常数过大，可以使用手写哈希表或 `std::map`（在数据范围 $10^9$ 内 `map` 的常数完全可以接受）。


```c++
#include <iostream>
#include <vector>
#include <unordered_map>

using namespace std;

typedef long long ll;

const int MAXN = 2000000; // 预处理大小，一般取 N^(2/3)

bool vis[MAXN + 5];
int primes[MAXN + 5], cnt;
int mu[MAXN + 5];
ll phi[MAXN + 5];

ll sum_mu[MAXN + 5];
ll sum_phi[MAXN + 5];

// 记忆化哈希表
unordered_map<int, ll> ans_mu;
unordered_map<int, ll> ans_phi;

// 1. 线性筛预处理
void sieve() {
    mu[1] = 1;
    phi[1] = 1;
    for (int i = 2; i <= MAXN; ++i) {
        if (!vis[i]) {
            primes[++cnt] = i;
            mu[i] = -1;
            phi[i] = i - 1;
        }
        for (int j = 1; j <= cnt && i * primes[j] <= MAXN; ++j) {
            vis[i * primes[j]] = true;
            if (i % primes[j] == 0) {
                mu[i * primes[j]] = 0;
                phi[i * primes[j]] = phi[i] * primes[j];
                break;
            } else {
                mu[i * primes[j]] = -mu[i];
                phi[i * primes[j]] = phi[i] * (primes[j] - 1);
            }
        }
    }
    // 求前缀和
    for (int i = 1; i <= MAXN; ++i) {
        sum_mu[i] = sum_mu[i - 1] + mu[i];
        sum_phi[i] = sum_phi[i - 1] + phi[i];
    }
}

// 2. 杜教筛求 mu 的前缀和
ll get_sum_mu(int n) {
    if (n <= MAXN) return sum_mu[n];
    if (ans_mu.count(n)) return ans_mu[n];
    
    ll ans = 1; // \sum_{i=1}^n \epsilon(i) = 1
    // 整除分块
    for (int l = 2, r; l <= n; l = r + 1) {
        r = n / (n / l);
        ans -= (r - l + 1) * get_sum_mu(n / l);
    }
    return ans_mu[n] = ans;
}

// 3. 杜教筛求 phi 的前缀和
ll get_sum_phi(int n) {
    if (n <= MAXN) return sum_phi[n];
    if (ans_phi.count(n)) return ans_phi[n];
    
    // \sum_{i=1}^n id(i) = n * (n + 1) / 2
    ll ans = (ll)n * (n + 1) / 2; 
    // 整除分块
    for (int l = 2, r; l <= n; l = r + 1) {
        r = n / (n / l);
        ans -= (r - l + 1) * get_sum_phi(n / l);
    }
    return ans_phi[n] = ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    sieve();
    
    int n;
    if (cin >> n) {
        cout << "Phi sum: " << get_sum_phi(n) << "\n";
        cout << "Mu sum: " << get_sum_mu(n) << "\n";
    }
    return 0;
}
```
