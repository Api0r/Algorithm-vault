
处理**数组/字符串在「特定偏移量」或「环形结构」下的对称取值**，核心在于**两步拆解法**：先在局部（相对坐标）算好位置，再映射到全局（绝对坐标）。

  

### 一、 核心数学公式：两步拆解法

无论题目怎么变，先不要一步到位写出复杂的模运算，按照以下两步推导：

  

1. **第 1 步：确定局部相对索引（以 0 为起点）**
    
      
    - 左端点 / 第 $i$ 个元素：$i$
        
          
        
    - 右端点 / 与 $i$ 对称的元素：$n - 1 - i$
        
          
        
    - 对应中点偏移（对半切）：$i + n / 2$
        
          
        
2. **第 2 步：叠加全局起点并取模**
    
      
    - 设有起始偏移量 $\text{offset}$（例如循环移位数 $\text{rot}$、滑动窗口左端点 $L$）
        
          
        
    - 最终下标公式：$\mathbf{(\text{offset} + \text{局部索引}) \pmod n}$
        
          
        

### 二、 常见场景速查表

| **目标场景**                   | **相对坐标对 (A,B)**       | **最终带偏移的下标写法**                                                |
| -------------------------- | --------------------- | ------------------------------------------------------------- |
| **回文对称** (首尾向中间)           | $i$ 与 $n - 1 - i$     | `left = (rot + i) % n`<br><br>`right = (rot + n - 1 - i) % n` |
| **前后两半对应** (左半对右半)         | $i$ 与 $i + n / 2$     | `p1 = (rot + i) % n`<br><br>`p2 = (rot + i + n / 2) % n`      |
| **以 $c$ 为中心扩散** (奇数回文)     | $c - i$ 与 $c + i$     | `left = (c - i + n) % n`<br><br>`right = (c + i) % n`         |
| **以 $c, c+1$ 之间扩散** (偶数回文) | $c - i$ 与 $c + 1 + i$ | `left = (c - i + n) % n`<br><br>`right = (c + 1 + i) % n`     |

### 三、 避坑三大铁律

**1. 负数取模陷阱（向左扩散/反向索引）**

  

- C++ 中的 `%` 是**取余**而非数学上的**取模**（例如 `-1 % 5 = -1`，会导致数组越界）。
    
      
    
- 只要局部索引可能出现减法，必须**先加 $n$ 再取模**：
    
      
    
    $$\text{index} = (x \pmod n + n) \pmod n \quad \text{或} \quad (x + n) \pmod n \quad (\text{当 } -n < x)$$
    

**2. 拼接字符串（`s + s`）与取模（`% n`）的选型**

  

- **优先用取模 `% n`**：空间复杂度 $O(1)$，不需要额外内存拷贝，且逻辑清晰。
    
      
    
- **用 `s + s` 拼接时**：只有当你的访问范围严格保证在 $[0, 2n-1]$ 内时才安全，且循环变量必须严格以原串长度 $n$ 限制边界，否则极易越界。
    
      
    

**3. 循环范围的设定**

  

- **对称比较只需遍历一半**：`for (int i = 0; i < n / 2; i++)`。
    
      
    
- 不论 $n$ 是奇数还是偶数：
    
      
    - $n$ 为偶数时：遍历刚好覆盖所有配对。
        
          
        
    - $n$ 为奇数时：正中间的字符 `i = n / 2` 与自身对称，回文检测无需参与比较，`i < n / 2` 自然跳过它。



[4021. 得到旋转回文字符串的最少操作次数 I - 力扣（LeetCode）](https://leetcode.cn/problems/minimum-operations-to-make-a-rotated-palindrome-i/description/)

这里的`i`就看成是偏移量

如果不按取模写，而是拼接的形式，`s += s`
那么则可以按照双指针while循环的写法

```c++
int minOperations(string s) {
    int n = s.size();
    int ans = INT_MAX;
    for (int i = 0; i < n; i++) {
        int cnt = i;
        for (int j = 0; j < n / 2; j++) {
            int d = abs(s[(i + j) % n] - s[(i + n - j - 1) % n]);
            cnt += min(d, 26 - d);

            if (cnt >= ans) break;
        }

        ans = min(ans, cnt);
    }

    return ans;
}
```
