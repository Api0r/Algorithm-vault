# 1e9范围，只筛到31622，然后用试除法

$\sqrt{10^9} \approx 31622$

```c++
// 欧拉筛，得到 limit 以内的所有质数
//31622

//我们需要看1e9范围内的质数，可以只筛 根号1e9 内的质数，然后用试除法
vector<int> sieve_primes(int limit) {
    vector<bool> is_prime(limit + 1, true);
    vector<int> primes;
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i <= limit; ++i) {
        if (is_prime[i]) primes.push_back(i);
        for (int p : primes) {
            if (1LL * i * p > limit) break;
            is_prime[i * p] = false;
            if (i % p == 0) break;
        }
    }
    return primes;
}

// 利用质数表判断 n 是否为质数（n <= 1e9 足够）
bool is_prime(int n, const vector<int>& primes) {
    if (n < 2) return false;
    for (int p : primes) {
        if (1LL * p * p > n) break;
        if (n % p == 0) return false;
    }
    return true;
}
```

在这个代码中，利用筛好的质数表（`primes`）来判断一个很大的数 $n$ 是否为质数，其核心原理是**基于数论的试除法优化**。

我们不需要把 $n$ 拿去和 $1 \sim n-1$ 的所有数都除一遍，只需要用**小于等于 $\sqrt{n}$ 的质数**去试除就可以了。

以下是这一步能够正确且高效运行的底层逻辑：

### 1. 为什么只需要检查到 $\sqrt{n}$ 就可以停止？

假设 $n$ 是一个合数，那么它一定可以分解为两个大于 1 的正整数的乘积：

$$n = a \times b$$

这时候， $a$ 和 $b$ 不可能同时大于 $\sqrt{n}$。因为如果 $a > \sqrt{n}$ 且 $b > \sqrt{n}$，那么它们的乘积 $a \times b$ 就会大于 $\sqrt{n} \times \sqrt{n} = n$，这与 $n = a \times b$ 矛盾。

因此，**如果 $n$ 是合数，它必定包含一个小于等于 $\sqrt{n}$ 的因数**。如果我们在 $2 \sim \sqrt{n}$ 的范围内找不到任何能整除 $n$ 的数，那么 $n$ 就绝对是一个质数。

### 2. 为什么只需要用“质数”去试除，而不用管合数？

根据**算术基本定理（唯一分解定理）**，任何一个大于 1 的合数都可以唯一地分解为若干个质数的乘积。

也就是说，如果一个合数 $x$ 能整除 $n$，那么 $x$ 的那些质因子也必然能整除 $n$。

> **举个例子**：如果 $n$ 能被 $6$ 整除，那它一定能被 $6$ 的质因子 $2$ 和 $3$ 整除。

既然如此，我们与其去用 $6、8、9$ 这些合数去试除 $n$，不如**直接用质数去试除**。如果 $n$ 连这中间所有的质数都除不尽，它就更不可能除得尽任何合数了。

### 3. 这样做的效率有多高？

假设我们要判断 $n = 10^9$ 左右的数是不是质数：

- **普通做法**：从 $2$ 一直循环到 $\sqrt{10^9} \approx 31622$，大约需要循环 **$31622$ 次**。
    
- **利用质数表做法**：在 $31622$ 以内，总共只有 **$3401$ 个质数**。也就是说，这个 `for` 循环最多只会执行 $3401$ 次。



# bitset优化空间

```c++
// 1. 编译期常量，1e8 规模
constexpr int MX = 1e8; 

// 2. 使用 bitset 替代 vector，默认全为 0（在我们的逻辑里代表是质数）
// 1e9 位的 bitset 仅占用约 119MB 内存，完美通过 256MB 限制
bitset<MX> isPrime; 
vector<int> primes;

void init() {
    // 0 和 1 不是质数，在我们的反转逻辑里，1 代表“不是质数（合数）”
    isPrime[0] = isPrime[1] = 1; 

    for (int i = 2; i < MX; i++) {
        // !isPrime[i] 为 true，说明它是 0，代表“是质数”
        if (!isPrime[i]) primes.push_back(i);

        for (int j = 0, t; j < primes.size() && (t = primes[j] * i) < MX; j++) {
            isPrime[t] = 1; // 标记为 1，代表“不是质数（合数）”
            
            if (i % primes[j] == 0) break;
        }
    }
}
```
