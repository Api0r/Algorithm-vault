
**环形/循环结构**相关的**取模运算**有高度通用的规律。主要分为以下四大经典场景：

  
### 一、 核心法则：模数必须等于「元素总个数」

在数学与计算机中，$X \pmod M$ 的结果区间为 $[0, M - 1]$。

- 环上元素总数是多少，模数就定为多少。
    
- **例**：$0 \sim 9$ 共有 $10$ 个数 $\to$ 模数是 $10$；钟表 $12$ 个刻度 $\to$ 模数是 $12$；$26$ 个英文字母 $\to$ 模数是 $26$。



### 二、 场景分类与通用公式

#### 1. 基础 0-indexed 环（范围：$0 \sim M-1$）

这是最标准、最直接的循环模型。


|**操作**|**通用公式**|**原理说明**|
|---|---|---|
|**前进 $k$ 步**（顺时针）|`(cur + k) % M`|直接相加并取模，保证不溢出上界。|
|**后退 $k$ 步**（逆时针）|`(cur - k % M + M) % M`|加上 $M$ 消除 C++ 负数取模产生的负余数。|
|**后退 1 步简化写法**|`(cur + M - 1) % M`|因为 $-1 \equiv + (M-1) \pmod M$ 恒成立。|

> **提示**：若步数 $k$ 可能大于 $M$，建议先将 $k$ 缩至 $0 \le k < M$，即 `k %= M`。
> 
>   

#### 2. 1-indexed 环（范围：$1 \sim M$）

常见于“月份 $1 \sim 12$”、“星期 $1 \sim 7$”、“数组下标以 1 开始的环形问题”。

  

- **难点**：直接对 $M$ 取模会产生 $0$，无法自然得到数字 $M$。
    
      
    
- **通用策略**：**先减 1 转为 0-indexed，取模计算后再加 1 还原。**
    
      
    

|**操作**|**统一变换公式**|**简化展开式**|
|---|---|---|
|**前进 $k$ 步**|`((cur - 1 + k) % M) + 1`|`(cur + k - 1) % M + 1`|
|**后退 $k$ 步**|`((cur - 1 - k % M + M) % M) + 1`|`(cur - k % M + M - 1) % M + 1`|
|**后退 1 步**|`((cur - 1 - 1 + M) % M) + 1`|`(cur + M - 2) % M + 1`|

#### 3. 任意连续区间环（范围：$L \sim R$）

元素范围为 $[L, R]$，总长度 $len = R - L + 1$。

  

- **通用套路**：以左端点 $L$ 为基准对齐到 $0$。
    
      
$$\text{Next} = \left( (cur - L + \text{offset}) \pmod{len} + len \right) \pmod{len} + L$$

- **字符环形位移示例**（大写字母 `'A' \sim 'Z'`，向后移 $k$ 位）：
    
      

    ```c++
    char next_char = (c - 'A' + k) % 26 + 'A';
    ```

#### 4. 环上两点的最短距离计算

在长度为 $M$（$0 \sim M-1$）的环上，计算点 $A$ 到点 $B$ 的距离：

  

- **单向（顺时针）距离**：
    
      
    
    $$\text{dist}_{A \to B} = (B - A + M) \pmod M$$
    
- **双向最短距离**（可顺可逆）：
    
      
    
    $$\text{diff} = \vert{}A - B\vert{}$$
    
    $$\text{min\_dist} = \min(\text{diff},\ M - \text{diff})$$
    

### 三、 避坑速记口诀

1. **看端点**：$0$ 开头直接模，$1$ 开头“先减一再加一”。
    
      
    
2. **算模数**：数个数，不是看最大值（$0 \sim 9$ 模 $10$，$0 \sim n-1$ 模 $n$）。
    
      
    
3. **防负数**：写减法必补模（`+ M` 后再 `% M`）。

```c++
void ap() {
	int n, d; cin >> n >> d;
    string s; cin >> s;
    
    int cur = d;
    int ans = 0;
    for (char c : s) {
        if (c == '+') cur = (cur + 1) % 10;
        else cur = (cur + 9) % 10;
        
        if (cur == d) {
            ans++;
        }
    }
    
    cout << cur << ' ' << ans;
    
	return ;
}
```
