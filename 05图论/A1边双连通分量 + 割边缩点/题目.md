# 1.

[F-Kaky 的缤纷路径_牛客小白月赛137](https://ac.nowcoder.com/acm/contest/139936/F)

**对于边双中的任意两点，一定存在两条不相交的路径连接这两个点（路径上可以有公共点，但是没有公共边）。**

边双缩点，每个点的点权就是这个块的size，如果点权`>= 3` 那么任意从这个块中连出去的节点都符合，因为边双连通分量内任意两点，总可以跑完块内的所有点并且走出去

边双连通分量内的点显然也可以

最坏的情况就是缩点之后的点权小于3的点，再坏一点的情况就是两个目标点在两个相邻的点权小于3的块内
即假设任意相邻的点权小于3的两个块都符合了，那么就符合，否则只要有一个不符合，则false

    vector<int> w(cnt + 1);
    for (int i = 1; i <= n; i++) {
        w[edcc.col[i]]++;
    }
    
    //点权小于3的点
    vector<int> e;
    for (int i = 1; i <= cnt; i++) if (w[i] < 3) {
        e.push_back(i);

        int x = edcc.col[u], y = edcc.col[v];
