一个看起来类似，但是实际上考点完全不一样的题目

[操作机器人 - 题目 - QOJ.ac](https://qoj.ac/contest/3766/problem/17343/statement/zh_cn)

题意：
- 在平面直角坐标系上有一个机器人，其初始时位于(0,0)， 你需要让它到达(x,y)。
- 有一个只包含012的长度为n的操作串，0表示向右移动 一步，1表示向上移动一步。
- 你需要将操作串中的所有2替换为0或1，机器人会按照替 换后的操作串循环移动。
- 求字典序最小的替换方式，使得机器人能够到达(x,y)。
- `1 ≤n≤106，0≤x,y≤1018，∑n≤106`


**题解:**
- 因为每执行一次操作，横纵坐标中的一个一定会增加1，所 以只有前`x+y`次执行操作是有效的。
- 设 `s=⌊x+y / n ⌋`，`k = (x+y) mod n`，则前 `k` 次操作会被执行` s +1` 次，后`n−k`次操作会被执行`s`次。
- 枚举前k次操作中0的数量，容易计算出后n−k次操作中 0 的数量，每段操作中都把0排到尽可能靠前的位置，取字 典序最小的解即可。

```c++
#include <bits/stdc++.h>  
using namespace std;  
#define int long long
#define endl '\n'

void ap() {
    int n, x, y; cin >> n >> x >> y;
    string s; cin >> s;

    int k = (x + y) / n, r = (x + y) % n;

    int pre0 = 0, pre1 = 0, pre2 = 0;
    int suf0 = 0, suf1 = 0, suf2 = 0;
    for (int i = 0; i < r; i++) {
        if (s[i] == '0') pre0++;
        else if (s[i] == '1') pre1++;
        else pre2++;
    }

    for (int i = r; i < n; i++) {
        if (s[i] == '0') suf0++;
        else if (s[i] == '1') suf1++;
        else suf2++;
    }

    string best_t = "";

    // 枚举前缀把 i 个 '2' 替换为 '0'
    for (int i = 0; i <= pre2; i++) {
        int x1 = (pre0 + i) * (k + 1);
        int y1 = (pre1 + pre2 - i) * (k + 1);

        if (x1 > x || y1 > y) continue;

        int needx = x - x1 - suf0 * k;
        int needy = y - y1 - suf1 * k;

        if (k == 0) {
            // k == 0 时，后半段不执行，为了字典序最小，后半段的 '2' 全部填 '0'
            if (needx == 0 && needy == 0) {
                needx = suf2;
                needy = 0;
            } else {
                continue;
            }
        } else {
            if (needx < 0 || needy < 0) continue;
            if (needx % k != 0 || needy % k != 0) continue;

            needx /= k;
            needy /= k;
        }

        if (needx + needy == suf2) {
            string t = "";
            int cnt = 0;
            // 构造前缀
            for (int j = 0; j < r; j++) {
                if (s[j] != '2') {
                    t += s[j];
                    continue;
                }
                if (cnt < i) {
                    t += '0';
                    cnt++;
                } else {
                    t += '1';
                }
            }

            cnt = 0;
            // 构造后缀
            for (int j = r; j < n; j++) {
                if (s[j] != '2') {
                    t += s[j];
                    continue;
                }
                if (cnt < needx) {
                    t += '0';
                    cnt++;
                } else {
                    t += '1';
                }
            }

            // 更新字典序最小的字符串，不能直接 break！
            if (best_t == "" || t < best_t) {
                best_t = t;
            }
        }
    }

    if (best_t == "") {
        cout << -1 << endl;
        return;
    }

    cout << best_t << endl;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T = 1;
    cin >> T;
    while (T--) {
        ap();
    } 
    return 0;
}
```
