# 2.

[P7687 [CEOI 2005] Critical Network Lines - 洛谷](https://www.luogu.com.cn/problem/P7687#ide)

边双连通中，只删去任意一条边，任意两点依旧连通
因此，答案边必须是割边

统计子树中A类的数量cnta，以及B类的数量cntb
如果子树y中任意一个为0或者全满，则说明边`(x, y)` 为答案边

dfs自然的可以自底向上地统计好子树中的cnt信息
