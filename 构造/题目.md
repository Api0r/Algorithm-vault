## 题目大意

给定正整数 $p$ ($2 \le p \le 10^9$)，要求构造三个正整数 $x_1, x_2, q$，使得：
1. $1 \le x_1 < q$ 且 $1 \le x_2 < p$；
2. $x_1^2 \equiv p \pmod q$；
3. $x_2^2 \equiv q \pmod p$；
4. $1 \le q \le 10^{12}$。

## 注意到


$$
\begin{aligned}
(p + q) \bmod q &= p \bmod q \\
(p + q) \bmod p &= q \bmod p
\end{aligned}
$$



## 核心公式与性质推导


直接设：
$$
x_1 = x_2 \quad \text{且} \quad x_1^2 = p + q
$$

此时验证两个同余条件：
1. **对于 $x_1^2 \equiv p \pmod q$**：
   $$x_1^2 \bmod q = (p + q) \bmod q = p \bmod q$$
2. **对于 $x_2^2 \equiv q \pmod p$**：
   $$q \bmod p = (x_1^2 - p) \bmod p = x_1^2 \bmod p \stackrel{x_1=x_2}{=} x_2^2 \bmod p$$

可以看到，两个同余方程同时被完美满足！

接下来只需导出 $q = x_1^2 - p$，并选取一个足够大的 $x_1$（即 $x_1 = \lfloor\sqrt{p}\rfloor + 2$）来同时满足大小约束：
- $1 \le x_1 < q$
- $1 \le x_2 < p$

## 边界条件与参数确定

为使构造的 $(x_1, x_2, q)$ 满足范围限制：

1. **满足 $1 \le x_1 < q$**：
   $$
   q - x_1 = x_1^2 - x_1 - p > 0 \implies x_1(x_1 - 1) > p
   $$
   只需要取 **$x_1 = \lfloor\sqrt{p}\rfloor + 2$** 即可保证 $x_1(x_1 - 1) > p$。

2. **满足 $1 \le x_2 < p$**：
   由于 $x_1 = \lfloor\sqrt{p}\rfloor + 2 < p$ （对任意 $p \ge 2$ 均成立），故 $x_2 = x_1 \bmod p = x_1$。

3. **满足 $q \le 10^{12}$**：
   因为 $p \le 10^9$，此时 $x_1 \approx 31624$，$q = x_1^2 - p \approx 10^9 \le 10^{12}$，完全符合要求。

---

## 最终通用构造公式

对**任意** $p \ge 2$：

$$
\begin{aligned}
x_1 &= \lfloor\sqrt{p}\rfloor + 2 \\
q &= x_1^2 - p \\
x_2 &= x_1 \bmod p
\end{aligned}
$$

## 代码实现 (C++)

```cpp
#include <iostream>
#include <cmath>

using namespace std;

void solve() {
    long long p;
    cin >> p;
    
    long long x1 = sqrt(p) + 2;
    long long q = x1 * x1 - p;
    long long x2 = x1 % p;
    
    cout << x1 << " " << x2 << " " << q << "\n";
}

int main() {
    // 优化 I/O
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int T;
    cin >> T;
    while (T--) {
        solve();
    }
    
    return 0;
}
```
