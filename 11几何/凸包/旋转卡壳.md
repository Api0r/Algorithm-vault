# 旋转卡壳

旋转卡壳（Rotating Calipers）是一种利用凸多边形的凸性与单调性，在线性时间 $O(n)$ 内遍历多边形所有**对踵点对（Antipodal Pairs）**的高效计算几何技巧。

它最初由 Michael Shamos 于 1978 年提出，用于求解平面点集的直径（最远点对），后被拓展至最小面积外接矩形、凸包间距离、凸多边形宽与直径等一系列经典几何问题。


## 1. 核心思想与几何直觉

想象用一把游标卡尺（Calipers）夹住一个凸多边形：

1. 卡尺的两条平行钳口紧贴多边形的外侧，使得整个多边形都夹在平行线之间。

2. 缓慢旋转卡尺，保持平行线始终与多边形外切（至少各贴住多边形的一个顶点）。

3. 当旋转使得其中一条平行线与多边形的一条**边重合**时，另一条平行线所接触的点，就是该边方向上距离最远的顶点。这两者（边与点，或点与点）就构成了一组**对踵（Antipodal）元素**。

4. 随着卡尺绕多边形旋转整整一圈（ $360^\circ$），所有方向上的极限特征点都会被遍历一遍。


## 2. 为什么旋转卡壳是线性的？

朴素枚举对踵点对需要比较每条边到所有顶点的距离，复杂度为 $O(n^2)$。旋转卡壳能降至 $O(n)$ 的数学基础在于**单峰性与单调性**：

- **单峰性（Unimodality）**：

    若固定一条底边 $p_i p_{i+1}$，点 $p_j$ 沿着凸包逆时针移动时，点到该直线的距离（对应三角形面积 $\triangle p_i p_{i+1} p_j$）呈现严格的**先增后减**趋势。

- **单调性（Monotonicity）**：

    当底边 $p_i p_{i+1}$ 逆时针转向下一条边 $p_{i+1} p_{i+2}$ 时，使得面积达到最大的对踵点 $p_k$ **同样只会逆时针单调向前移动**，绝对不会回退。

- **双指针均摊 $O(n)$**：

    利用该单调性，我们可以用一个指针 $k$ 追踪最远点。外层循环遍历每条边（共 $n$ 步），内层指针 $k$ 在整个算法过程中累计旋转不超过 $2n$ 次。因此，均摊时间复杂度为严格的 $O(n)$。


## 3. 常见应用场景与指针模型

根据卡尺的夹角与约束方式，旋转卡壳衍生出几种经典的双指针/多指针模型：

| **经典问题** | **维护的指针/特征** | **求解策略** |
| --- | --- | --- |
| **点集直径（最远点对）** | 1 条底边 + 1 个对踵最高点 | 遍历每条边，找面积最大的顶点，更新顶点与底端两点距离。 |
| **凸多边形宽度（最小厚度）** | 1 条底边 + 1 个对踵最高点 | 遍历每条边，计算对应最远顶点到底边所在直线的垂线距离，取最小值。 |
| **最小面积/周长外接矩形** | 1 条底边 + 1 个对踵最高点 + 2 个极左/极右侧点 | 同时维护 4 个方向的切线（平行与垂直）。外层转动底边，双指针/三指针分别同步推进最高点与左右极点。 |
| **两凸包最小/最大距离** | 两个独立凸包上的切点/切边 | 维护两凸包的反向平行切线，利用双指针同步逆时针旋转寻找投影重叠与最近特征。 |
| **凸多边形最大内接三角形/四边形** | 3 或 4 个顶点 | 采用多指针同时在多边形上逆时针爬升，寻找面积极大化配置。 |


## 4. 算法模板框架（双指针求对踵点）

在代数实现中，我们无需真正计算角度或三角函数，而是利用**二维向量叉积**直接比较三角形的有向面积：

$$\operatorname{Cross}(A, B, C) = (B_x - A_x)(C_y - A_y) - (B_y - A_y)(C_x - A_x)$$

对于边 $(p_i, p_{i+1})$，当比较下一个候选点 $p_{k+1}$ 与当前点 $p_k$ 时：

- 若 $\operatorname{Cross}(p_i, p_{i+1}, p_{k+1}) > \operatorname{Cross}(p_i, p_{i+1}, p_k)$，说明三角形面积继续增大，指针向前推进：`k = (k + 1) % n`。

- 否则， $p_k$ 即为当前底边方向上的极值对踵点。

```text
初始化指针 k = 1;
for i 从 0 到 n - 1:
    令 next_i = (i + 1) % n;
    while 面积(p[i], p[next_i], p[(k + 1) % n]) > 面积(p[i], p[next_i], p[k]):
        k = (k + 1) % n;
    // 此时 (p[i], p[next_i]) 与 p[k] 构成对踵结构
    利用 p[i], p[next_i], p[k] 更新目标问题的答案（如距离、宽度、矩形投影等）
```
