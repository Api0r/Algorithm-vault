# Manacher 模板及详解

```c++
struct Manacher {
    string ss;
    vector<int> p;
    int n = 0, mx = 0;

    void build(const string& str) {
        n = str.size() * 2 + 1;
        ss.resize(n);
        for (int i = 0, j = 0; i < n; ++i) {
            ss[i] = (i & 1) == 0 ? '#' : str[j++];
        }

        p.assign(n, 0);
        mx = 0;

        for (int i = 0, c = 0, r = 0; i < n; ++i) {
            int len = (r > i) ? min(p[2 * c - i], r - i) : 1;
            while (i + len < n && i - len >= 0 && ss[i + len] == ss[i - len]) {
                len++;
            }
            if (i + len > r) {
                r = i + len;
                c = i;
            }
            p[i] = len;
            mx = max(mx, len);
        }
    }

    // 最长回文子串长度
    int askMax() const {
        return mx - 1;
    }

    // 原串 [l, r] 是否为回文（0-based 闭区间）
    bool isPal(int l, int r) const {
        int mid = l + r + 1;
        return p[mid] - 1 >= (r - l + 1);
    }
};
```

这份模板是求解**最长回文子串**与**任意区间回文判定**的标准 Manacher（马拉车）算法。它的核心思想是通过**插入占位符统一奇偶长度**，并利用**已匹配回文的对称性**将朴素的 $O(N^2)$ 暴力中心扩展优化至严格 $O(N)$。

## 核心成员变量

- **`ss`**：插入分隔符 `#` 后的扩展字符串。长度必定为奇数（$2 \times \vert str\vert + 1$）。
- **`p[i]`**：以 `ss[i]` 为中心的回文**半径**（包含中心字符本身）。
- **`n`**：`ss` 的长度。
- **`mx`**：算法运行过程中记录到的最大回文半径 $\max(p[i])$。

## 函数逐行拆解

### 1. 预处理：`build` 中的字符串变换

```c++
n = str.size() * 2 + 1;
ss.resize(n);
for (int i = 0, j = 0; i < n; ++i) {
    ss[i] = (i & 1) == 0 ? '#' : str[j++];
}
```

- **作用**：在字符两端及每两个字符之间插入 `#`。
- **目的**：将奇回文（如 `aba` $\to$ `#a#b#a#`）与偶回文（如 `abba` $\to$ `#a#b#b#a#`）统一转换为奇数长度，所有回文中心都落在一个确定的下标上。

### 2. 核心加速机制：对称性与右边界递推

```c++
for (int i = 0, c = 0, r = 0; i < n; ++i) {
    int len = (r > i) ? min(p[2 * c - i], r - i) : 1;
```

- **变量含义**：
    - `c`（Center）：已探索到的、向右延伸最远的回文串中心。
    - `r`（Right）：以 `c` 为中心的回文串的**最右边界后一位**（开区间右端点 $c + p[c]$）。

- **关键转移 `min(p[2 * c - i], r - i)`**：
    - $i' = 2 \times c - i$ 是 $i$ 关于中心 $c$ 的**对称点**。
    - 若 $i < r$：说明 $i$ 落在以 $c$ 为中心的回文覆盖范围内。根据对称性，$i$ 处的回文半径**至少**等于对称点 $i'$ 的半径 $p[i']$。
    - 但对称性只在边界 $r$ 内部成立，超出 $r$ 的部分无法保证，因此初始可信半径取 $\min(p[i'], r - i)$。
    - 若 $i \ge r$：无法利用历史信息，半径从 $1$ 开始试探。

### 3. 暴力外扩与右边界更新

```c++
    while (i + len < n && i - len >= 0 && ss[i + len] == ss[i - len]) {
        len++;
    }
    if (i + len > r) {
        r = i + len;
        c = i;
    }
    p[i] = len;
    mx = max(mx, len);
}
```

- **扩展**：从已知长度 `len` 开始继续向两侧匹配。未加哨兵字符时，需要双向边界判断 `i + len < n && i - len >= 0`。
- **更新**：如果新回文串的右端点超越了当前最右界 $r$，就将 $r$ 推进到 $i + len$，并更新中心 $c = i$。$r$ 单调递增，保证了算法总时间复杂度为 $O(N)$。

## 查询接口与数学映射

### 1. `askMax()`：最长回文子串长度

```c++
int askMax() const {
    return mx - 1;
}
```

- **性质**：在加 `#` 后的字符串中，以任意字符为中心的回文串，其包含的 `#` 数量刚好比原字符多 $1$。
- 因此，在扩展串中半径为 $p[i]$ 的回文串，对应原串的实际回文长度就是 $p[i] - 1$。

### 2. `isPal(l, r)`：$O(1)$ 判断原串闭区间 $[l, r]$ 是否为回文

```c++
bool isPal(int l, int r) const {
    int mid = l + r + 1;
    return p[mid] - 1 >= (r - l + 1);
}
```

- **映射原理**：
    - 原串字符 $s[k]$ 在扩展串 `ss` 中的下标为 $2k + 1$。
    - 区间 $[l, r]$ 的两端在 `ss` 中对应 $2l + 1$ 和 $2r + 1$。
    - 该区间的中心在 `ss` 中的下标为 $\frac{(2l + 1) + (2r + 1)}{2} = l + r + 1$。
    - 无论是奇长度还是偶长度子串，$mid = l + r + 1$ 始终精确指向扩展串的对应回文中心。

- **判定**：若该中心能延伸出的最大原串回文长度（$p[mid] - 1$）大于等于目标区间长度 $r - l + 1$，则该子区间必定完全回文。
