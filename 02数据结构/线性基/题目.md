## 一、构造转化

[B-Bitwise Maximization_2026牛客暑期多校训练营2](https://ac.nowcoder.com/acm/contest/133877/B)

> **trick：** 按位想得到最大，但是发现最高位的数字可能会牵连到后面的位，使得按位操作失效。

- 由于数字整体性，无法直接单独按位看
- **数字整体异或最大** → **线性基 求异或最大值**

既想单独按位看，但是又需要数字整体性，这时我们不妨想想转化，想想异或线性基问题。


```c++
#include <bits/stdc++.h>  
using namespace std;  
#define int long long
#define endl '\n'
const int mod = 1e9 + 7;
const int MOD = 998244353;

vector<int> basis;

bool insert(int x) {
    for (int i = 29; i >= 0; i--) {
        if (x >> i == 1) {
            if (basis[i] == 0) {
                basis[i] = x;
                return true;
            }
            x ^= basis[i];
        }
    }
    return false;
}

void ap() {
	int n; cin >> n; 
    vector<int> a(n);
    int sum = 0;
    for (int & i : a) cin >> i, sum ^= i;
    
    basis.assign(30, 0);
    
    for (int x : a) {
        insert(x & (~sum)); // 对 sum 按位取反，只保留 0 对应的位
    }
    
    int ans = 0;
    for (int i = 29; i >= 0; i--) {
        ans = max(ans, (ans ^ basis[i]));
    }
    
    cout << sum + 2 * ans << endl;
    
    
	return ;
}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int T = 1;
	cin >> T;
	while (T--) {
		ap();
	} 
    return 0;
}
```

### 题目大意与背景

在这道题目中，你有 `n` 个非负整数 `a_1, a_2, ..., a_n`，以及两个初始为空的多重集合（Multi-set，即可以包含重复元素的高级集合，记为 `S_1` 和 `S_2`）。

你需要把这 `n` 个数中的**每一个数**都分配到 `S_1` 或 `S_2` 中（即对于每个数 `a_i`，要么放入 `S_1`，要么放入 `S_2`）。

**得分计算规则：**

1. 一个多重集合的 XOR（异或）值等于集合内所有元素的异或和（若集合为空，则异或和为 `0`）。
2. 最终得分为这两个集合的异或和**相加**之和，即：

    $$\text{Score} = \text{XOR}(S_1) + \text{XOR}(S_2)$$

**目标：** 求出选择分配方案后，能够获得的**最大得分**。

---

### 数学逻辑分析

假设所有输入的 `n` 个元素的总异或和为 `X = a_1 ^ a_2 ^ ... ^ a_n`。

如果你把集合拆分为 `S_1` 和 `S_2`，并设 `S_1` 中所有元素的异或和为 `A = XOR(S_1)`，那么根据异或的性质（`x ^ x = 0`），`S_2` 中元素的异或和 `B = XOR(S_2)` 一定等于 `A ^ X`。

因此，你的目标是选择一个子集 `S_1`，使其异或和为 `A`，使得下式最大化：

$$\text{Score} = A + (A \oplus X)$$

---

### 关键转化：逐位分析（Bitwise Analysis）

我们按二进制位（从高位第 29 位到低位第 0 位）来观察 `A` 和 `A ^ X` 的加法。

对于某一位 `k`（对应数值 `2^k`），查看 `X` 在这一位上的值 `X_k`：

1. **情况 1：`X_k = 1`**
   
   - 说明在这一位上，`A` 和 `A ^ X` 一定是一个为 `1`，另一个为 `0`（因为异或结果为 `1` 意味着两数在此位不同）。
   - 不管你如何选择 `A`，这一位在 `A + (A ^ X)` 中**必定恰好贡献一个 `2^k`**。
   - 因此，对于 `X` 中为 `1` 的那些二进制位，其贡献是**固定的**，我们无法改变它，也无需去专门凑这一位。

2. **情况 2：`X_k = 0`**
   
   - 说明在这一位上，`A` 和 `A ^ X` 的值完全相同（要么同为 `1`，要么同为 `0`）。
   - 如果我们能选择一个 `A`，使得 `A` 的第 `k` 位为 `1`，那么 `A ^ X` 的第 `k` 位也必定为 `1`。
   - 这样，这一位就能贡献 `2^k + 2^k = 2 * 2^k` 的分数！
   - 如果 `A` 的第 `k` 位为 `0`，这一位的贡献就是 `0`。
   - 因此，我们的目标转化为：**尽可能让所有 `X_k = 0` 的二进制位在 `A` 中都变成 `1`**。

---

### 解题步骤与算法设计

根据上述分析，原问题可以优雅地转化为**线性基（Linear Basis）**求解最大异或和问题：

1. **计算总异或和 `X`：**
   
   遍历数组算出 `X = a_1 ^ a_2 ^ ... ^ a_n`。

2. **改造数组元素（屏蔽无用位）：**
   
   对于每个 `a_i`，我们只关心 `X_k = 0` 的那些二进制位。因此，我们可以将 `a_i` 中 `X_k = 1` 的位清零（或者说保留 `X_k = 0` 的位）。
   
   计算掩码 `mask = ~X`（对 `X` 按位取反，只保留 `0` 对应的位）。
   
   令 `a_i' = a_i & mask`。

3. **构建线性基（Linear Basis）：**
   
   用所有改造后的 `a_i'` 构建一个二进制线性基。

4. **贪心求解最佳 `A`：**
   
   利用线性基，求出用 `a_i'` 能够组合出的**最大异或和** `A'`。
   
   此时，`A'` 包含了我们在所有 `X_k = 0` 的位置上能凑出的最多 `1`。

5. **计算最终得分：**
   
   知道了能够让哪些 `X_k = 0` 的位变成 `1` 后，真实最佳的 `A` 可以在这些位置上取 `A'`，而在 `X_k = 1` 的位置上无论取 `0` 还是 `1` 都不影响总和。
   
   因此，最终的最大得分为：
   
   $$\text{Score} = X + 2 \times A'$$
   
   > **原理：** `X` 包含了所有 `X_k = 1` 位的贡献各 `1` 次；而 `2 * A'` 包含了所有 `X_k = 0` 位在 `A` 和 `B` 中同时为 `1` 带来的各 `2` 次贡献。

---

### 复杂度分析

- **时间复杂度：**
  - 计算 `X`：`O(n)`
  - 线性基插入：每个数最多插入 `30` 位，插入复杂度 `O(log(maxA))`。
  - 对于单个测试用例复杂度为 `O(n * log(maxA))`，在 `sum n <= 5 * 10^5` 的限制下可以非常高效地通过。

- **空间复杂度：** `O(n + log(maxA))`，用于存储数组和线性基（大小不超过 `30` 的数组）。
