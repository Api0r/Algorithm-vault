这份代码是一个高度工程化的 **一维树状数组（Binary Indexed Tree / Fenwick Tree）** 模板，封装了初始化、线性建树、单点/区间修改、前缀/区间查询以及倍增查找第 $k$ 大等常用功能。

### 1. 核心原理与结构成员

树状数组利用二进制的最低有效位（`lowbit(x) = x & -x`）来维护长度为 `lowbit(x)` 的区间和：

- 每个节点 `bit[x]` 维护原数组在区间 `(x - lowbit(x), x]` 的和。

- 内部使用 `1-based indexing`（下标从 $1$ 到 $n$），因此大小分配为 `n + 1`。

### 2. 各成员函数逐行详解

**初始化与构造**

```c++
void init(int _n) {
    n = _n;
    bit.assign(n + 1, T{});
}
```

- 重设树状数组大小，并用泛型默认值 `T{}`（如 `0`）填充。

**$O(n)$ 线性建树**

```c++
template <class A>
void build(const A &a) {
    fill(bit.begin(), bit.end(), T{});
    for (int i = 1; i <= n; ++i) {
        bit[i] += a[i];
        int j = i + (i & -i);
        if (j <= n) bit[j] += bit[i];
    }
}
```

- **传统建树：** 调用 $n$ 次 `modify`，复杂度为 $O(n \log n)$。

- **线性优化：** 树状数组本质是一棵树，节点 $i$ 的直接父亲即为 $j = i + \text{lowbit}(i)$。自底向上遍历时，将当前节点的和直接累加给直接父亲节点，即可在 $O(n)$ 时间内完成建树。

**单点修改 `modify` 与 前缀和查询 `ask`**

```c++
void modify(int x, const T &v) {
    assert(1 <= x && x <= n);
    for (; x <= n; x += x & -x) bit[x] += v;
}

T ask(int x) const {
    x = min(x, n);
    T res{};
    for (; x > 0; x -= x & -x) res += bit[x];
    return res;
}
```

- `modify(x, v)`：将位置 $x$ 增加 $v$。自底向上沿树链更新所有包含 $x$ 的区间，步进方式为 $x \leftarrow x + \text{lowbit}(x)$，时间复杂度 $O(\log n)$。

- `ask(x)`：查询前缀和 $\sum_{i=1}^x a_i$。自顶向下拆解区间，步进方式为 $x \leftarrow x - \text{lowbit}(x)$，时间复杂度 $O(\log n)$。

**区间操作：差分修改与区间求和**

```c++
void update(int l, int r, const T &v) {
    if (l > r) return;
    assert(1 <= l && r <= n);
    modify(l, v);
    if (r < n) modify(r + 1, -v);
}

T ask(int l, int r) const {
    if (l > r) return T{};
    assert(1 <= l && r <= n);
    return ask(r) - ask(l - 1);
}
```

- `ask(l, r)`：常规树状数组用法，利用前缀和差分计算区间和：$\text{Sum}(l, r) = \text{ask}(r) - \text{ask}(l - 1)$。

- `update(l, r, v)`：**差分数组用法**。在差分语义下，对区间 $[l, r]$ 加上 $v$ 等价于 `d[l] += v` 且 `d[r + 1] -= v`。此时调用 `ask(p)` 得到的将是**单点 $p$ 的实际值**，不可与前缀和语义混用。

**倍增查询第 $k$ 小/大位置 `askKth`**

```c++
int askKth(const T &k) const {
    if (!(k > T{})) return 1;
    int pos = 0;
    T pre{};
    int stp = 1;
    while ((stp << 1) <= n) stp <<= 1;
    for (; stp; stp >>= 1) {
        int nxt = pos + stp;
        if (nxt <= n && pre + bit[nxt] < k) {
            pre += bit[nxt];
            pos = nxt;
        }
    }
    return pos + 1;
}
```

该函数用于在**权值全部非负**（即前缀和单调不降）时，找出最小的下标 $p$，使得 $\sum_{i=1}^p a_i \ge k$。

- **原理：** 若使用“二分 + `ask`”，复杂度为 $O(\log^2 n)$。这里利用二进制提升（倍增）思想，直接在树状数组结构上跳跃：

    1. `stp` 初始化为小于等于 $n$ 的最大 2 的次幂（最高二进制位）。

    2. 尝试从 `pos` 向右跳跃 `stp` 步到达 `nxt = pos + stp`。由于 `pos` 一定是 $stp$ 的倍数，节点 `bit[nxt]` 恰好完整覆盖了区间 `(pos, nxt]` 的和。

    3. 如果累加后仍严格小于 $k$，说明目标位置在更右侧，执行 `pos = nxt` 并累加和；否则不跳。

    4. 最终 `pos` 会停在满足“前缀和 $< k$”的最大位置，因此 `pos + 1` 即为所求的最小下标。

- **复杂度：** 仅需 $O(\log n)$，常数极小。如果整个数组的总和仍小于 $k$，最终会返回 $n + 1$。

# 树状数组 - 做区间修改和区间查询

要实现**区间增加**与**区间查询**，需要利用差分原理，同时维护两个树状数组。

### 数学原理

设原序列为 $A_i$，其差分数组为 $D_i = A_i - A_{i-1}$（约定 $A_0 = 0$）。

1. **单点值与差分关系**：

    $$A_i = \sum_{j=1}^i D_j$$

2. **前缀和推导**：

    $$\sum_{i=1}^p A_i = \sum_{i=1}^p \sum_{j=1}^i D_j = \sum_{i=1}^p (p - i + 1) \cdot D_i = (p + 1)\sum_{i=1}^p D_i - \sum_{i=1}^p (i \cdot D_i)$$

因此只需维护两个树状数组：

- **`bit1`** 维护 $D_i$

- **`bit2`** 维护 $i \cdot D_i$

### 改造实现

其实只需要理解记忆上述公式，套用基础的BIT模板即可

基于现有的 `BIT` 模板，封装一个支持区间加与区间查询的结构体：

```c++
template <class T>
struct BIT {
    int n = 0;
    vector<T> bit;

    BIT() = default;
    explicit BIT(int n) {
        init(n);
    }

    void init(int _n) {
        n = _n;
        bit.assign(n + 1, T{});
    }

    template <class A>
    void build(const A &a) {
        fill(bit.begin(), bit.end(), T{});
        for (int i = 1; i <= n; ++i) {
            bit[i] += a[i];
            int j = i + (i & -i);
            if (j <= n) bit[j] += bit[i];
        }
    }

    //将位置 x 增加 v
    void modify(int x, const T &v) {
        assert(1 <= x && x <= n);
        for (; x <= n; x += x & -x) bit[x] += v;
    }

    void update(int l, int r, const T &v) {
        if (l > r) return;
        assert(1 <= l && r <= n);
        modify(l, v);
        if (r < n) modify(r + 1, -v);
    }

    //查询前缀和 [1, x]
    T ask(int x) const {
        x = min(x, n);
        T res{};
        for (; x > 0; x -= x & -x) res += bit[x];
        return res;
    }

    T ask(int l, int r) const {
        if (l > r) return T{};
        assert(1 <= l && r <= n);
        return ask(r) - ask(l - 1);
    }

    int askKth(const T &k) const {
        if (!(k > T{})) return 1;
        int pos = 0;
        T pre{};
        int stp = 1;
        while ((stp << 1) <= n) stp <<= 1;
        for (; stp; stp >>= 1) {
            int nxt = pos + stp;
            if (nxt <= n && pre + bit[nxt] < k) {
                pre += bit[nxt];
                pos = nxt;
            }
        }
        return pos + 1;
    }
};

template <class T = long long>
struct RangeBIT {
    int n = 0;
    BIT<T> b1, b2; // b1 维护 D[i], b2 维护 i * D[i]

    RangeBIT() = default;
    explicit RangeBIT(int n) { init(n); }

    void init(int _n) {
        n = _n;
        b1.init(n);
        b2.init(n);
    }

    // 建树：传入 1-indexed 数组 a
    template <class A>
    void build(const A &a) {
        init(n);
        for (int i = 1; i <= n; ++i) {
            T diff = a[i] - a[i - 1];
            b1.modify(i, diff);
            b2.modify(i, diff * i);
        }
    }

    // 区间增加：[l, r] 增加 v
    void range_add(int l, int r, const T &v) {
        if (l > r) return;
        assert(1 <= l && r <= n);

        // 维护 b1: D[l] += v, D[r+1] -= v
        b1.modify(l, v);
        if (r + 1 <= n) b1.modify(r + 1, -v);

        // 维护 b2: (l * D[l]) += l * v, ((r+1) * D[r+1]) -= (r+1) * v
        b2.modify(l, v * l);
        if (r + 1 <= n) b2.modify(r + 1, -v * (r + 1));
    }

    // 查询前缀和：[1, p]
    T ask_prefix(int p) const {
        if (p <= 0) return T{};
        p = std::min(p, n);
        return b1.ask(p) * (p + 1) - b2.ask(p);
    }

    // 区间查询：[l, r] 的区间和
    T ask(int l, int r) const {
        if (l > r) return T{};
        assert(1 <= l && r <= n);
        return ask_prefix(r) - ask_prefix(l - 1);
    }
};
```

### 使用示例

```c++
int main() {
    int n = 5;
    RangeBIT<long long> tree(n);

    // 区间 [2, 4] 全部加上 3
    tree.range_add(2, 4, 3);

    // 查询区间 [1, 3] 的和 -> 6 (0 + 3 + 3)
    long long ans = tree.ask(1, 3);

    // 查询区间 [2, 4] 的和 -> 9 (3 + 3 + 3)
    long long ans2 = tree.ask(2, 4);

    return 0;
}
```
