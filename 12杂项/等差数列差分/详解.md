
`[1, n]` 范围
每次操作：`[1, r]` 范围上依次加上首项为s，末项为e，公差为d的数列

最终得到`[1, n]` 范围上每个数字的值

```c++
vector<int> a(n + 2);

void set(int l, int r, int s, int e, int d) {
	a[l] += s;
	a[l + 1] += d - s;
	a[r + 1] -= d + e;
	s[r + 2] += e;
}

void build() {
	for (int i = 1; i <= n; i++) {
		a[i] += a[i - 1];
	}
	
	for (int i = 1; i <= n; i++) {
		a[i] += a[i - 1];
	}
}

```
