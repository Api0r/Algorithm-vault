# 2. 相对运动 + 环形朝向

和循环位移关系不大，但是寻找对应关系的方法类似

https://codeforces.com/gym/105911/problem/K

- 一个不动，剩下的都顺时针转90，相对来讲，只有这个逆时针转90，而其他都不动
- 要使所有都朝向0，可以先让所有的都朝向同一个方向，再通过操作二使所有的都指向0

- 那么我们可以枚举操作一的共同朝向，在这之后的操作二其实就固定了
- 问题在于，我们枚举的操作一的方向是相对的，即枚举共同朝向1时，最终操作一结束的实际朝向并非是1

- 注意到，枚举朝向1时，已经朝向1的不会按自己的鼻子(不会 - 自己不动，其他全动)
- 即抛开相对运动来看，初始时朝向1的一直在转动，且转的次数就是操作一的次数
- 假设枚举相对朝向为`i`， 操作一的次数为`t`
- 则操作一结束后实际的朝向为`(i + t) % 4`

- 最后进行操作二，需要操作`4 - (i + t) % 4` 次
- 枚举取最大即可

补充：
- 初始位于`j` ，要逆时针转到`i` 需要的次数为`(j - i + 4) % 4`
- 这个可以枚举看规律，手动画表数据很小，画的图很类似循环位移

```c++
#include <bits/stdc++.h>  
using namespace std;  
#define int long long
#define endl '\n'
const int mod = 1e9 + 7;
const int MOD = 998244353;

void ap() {
	int n; cin >> n;
    vector<int> a(n);
    for (int & i : a) cin >> i;

    vector<int> cnt(4);
    for (int & x : a) cnt[x]++;

    int ans = 1e18;
    for (int i = 0; i < 4; i++) {//chaoxinag
        int t = 0;
        for (int j = 0; j < 4; j++) {
            t += cnt[j] * ((j - i + 4) % 4);
        }

        ans = min(ans, (4 - (t + i) % 4) % 4 + t);
    }

    cout << ans << endl;


	return ;
}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int T = 1;
//	cin >> T;
	while (T--) {
		ap();
	} 
    return 0;
}
```
