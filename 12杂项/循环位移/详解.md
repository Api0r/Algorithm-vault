
# 位移量


## 公式

下面的公式表示`bi`在循环位移的重复拼接中，属于p这种循环位移的形式

$$p = (b_i' - i) \bmod k \quad (\text{映射到 } [0, k-1])$$

拼接序列很长的时候会出现负数的情况，可以照着下面的形式写
`((b[i] - i) % k + k) % k`



## 详解

$a$ 是序列 $[1, 2, \dots, k]$ 的某种循环位移。设位移量为 $p$ ($0 \le p < k$)，则：

$$a = [p+1, p+2, \dots, k, 1, 2, \dots, p]$$

将 $a$ 无限重复并截取前 $n$ 个得到原始序列 $b$。即对于任意 $1$-indexed 的位置 $i$ ($1 \le i \le n$)：

$$b_i = ((i - 1 + p) \bmod k) + 1$$


1. 当 $1 \le b_i' \le k$ 时：
    
    $$(i - 1 + p) \equiv b_i' - 1 \pmod k$$
    
    化简得到：
    
    $$p \equiv (b_i' - i) \pmod k$$
    

因为 $0 \le p < k$，所以在模 $k$ 意义下，每个合法的位置 $i$ 唯一确定了一个候选的偏移量 $p$：

$$p = (b_i' - i) \bmod k \quad (\text{映射到 } [0, k-1])$$

也就是说：**每一个 $1 \le b_i' \le k$ 的位置 $i$，都对应且仅对应一个能让它保持“无需修改”的位移量 $p$**。
