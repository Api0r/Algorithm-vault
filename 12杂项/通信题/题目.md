加密出来的01串长度只能为1或2，相邻相同合并后容易看出就是01交替的串
由此，要从长度的角度去思考如何构造
- 如果长度为1表示0(或1)，长度为2表示1(或0)
- 则解密时只需要看01交替连续串的长度即可知道这一小段指的是什么
- 规定第一个为p的第一个字符即可

- 令长度为2表示数量更多的那个
- 假设01数量分别为`x, y`其中数量少的是x
- 则`x + y = n`, 加密需要`2 * x + y = (x + y) + x = n + x`
- `x <= n / 2`, `n + x <= n + n / 2`

void ap2() {
    int m; cin >> m;
    string s; cin >> s;

    string ans;
    char c = s[0];
    char mn, mx;
    if (s[0] == s[1]) {
        mn = c;
        mx = (c == '1' ? '0' : '1');
    } else {
        mx = c;
        mn = (c == '1' ? '0' : '1');
