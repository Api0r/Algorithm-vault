# 2. 猜数 + 二进制角度看

https://codeforces.com/gym/106589/problem/L


> **题目大意**
> $n$ 个样品中，恰一个合格样品，一个污染样品。每次可以放若干个样品，当且仅当有合格样品，没有污染样品，输出 $YES$，否则输出 $NO$。最多 $29$ 次找出合格样品和污染样品。
> 
> $n \le 1000$。

---

将每个样品的编号写成二进制。对于二进制每一位，该位是 $1$ 的样品放在一起检测一次，该位是 $0$ 的样品放在一起检测一次，共 $20$ 次询问。

对于某一位的询问，若 $1$ 的样品返回 $YES$ 或者 $0$ 的样品返回 $YES$，则找到了合格样品所在的集合。若都返回 $NO$，则能说明污染样品和合格样品在该位是同 $1$ 或者同 $0$ 的。并且前 $20$ 次询问后，一定会找到合格样品的所在集合（因为不可能 $10$ 位二进制都相同）。

在合格的集合中，用二分法定位出合格样品，共需 $9$ 次询问。然后根据上面的二进制位是否相同，确定出污染样品的编号。

tips:
- 设好的为`a` ， 坏的为`b`

- 对于二进制的每一位，对这个二进制位进行分类，将1放到一个集合，将0放到另一个集合
- 查询，如果集合1是 `YES` 则说明该二进制位上，a为1， b为0
-           如果集合0是 `YES` 则说明该二进制位上，a为0， b为1
-           otherwise，都是`NO`, 只能说明该二进制位上，ab都为0 或 都为1
- 将这些信息存储在一个长度为10的数组中

这样查询最多20次之后，我们知道什么：
- 确定的位，ab在这些位上确定，且相反
- 不确定的位，ab在这些位上不确定，但是在这些位上相同(都为0 或 都为1)
- 如果a确定了，那么b也是确定的

剩下9次查询，只需查询出a即可
- 对于每个不确定的位，只要保证不包含b，则只需将这一位都为1的加到集合中查询即可
- 不包含b，只需要在确定的位中任选一个将b卡掉即可(如果所有位都不确定，则a = b，矛盾)
- 暴力枚举即可(10 * 1000)


```c++
#include <bits/stdc++.h>  
using namespace std;  
#define int long long
// #define endl '\n'
const int mod = 1e9 + 7;
const int MOD = 998244353;

void ap() {
	int n; cin >> n;

    int h = 0;
    while (1LL << (h + 1) <= n) h++;

    vector<int> ans(h + 1, -1);

    for (int i = 0; i <= h; i++) {
        vector<int> s, t;
        for (int x = 1; x <= n; x++) {
            if (x & (1LL << i)) s.push_back(x);
            else t.push_back(x); 
        }

        cout << "? ";
        cout << s.size() << ' ';
        for (int & y : s) cout << y << ' ';
        cout << std::endl;

        string res; cin >> res;
        if (res == "YES") {
            ans[i] = 1;
        }

        cout << "? ";                                                              
        cout << t.size() << ' ';
        for (int & y : t) cout << y << ' ';
        cout << std::endl;

        cin >> res;
        if (res == "YES") {
            ans[i] = 0;
        }

    }

    int pos = 0;
    int a = 0, b = 0;
    for (int i = 0; i <= h; i++) {
        if (ans[i] != -1) {
            pos = i;
            
            if (ans[i] & 1) {
                a |= (1LL << i);
            } else {
                b |= (1LL << i);
            }
        }
    }

    for (int i = 0; i <= h; i++) {
        if (ans[i] == -1) {

            vector<int> s;
            for (int x = 1; x <= n; x++) {
                if (ans[pos] == ((x >> pos) & 1) && (x & (1LL << i))) {
                    s.push_back(x);
                }
            }

            if (!s.size()) continue;

            cout << "? ";
            cout << s.size() << ' ';
            for (int & y : s) cout << y << ' ';
            cout << std::endl;

            string res; cin >> res;
            if (res == "YES") {
                ans[i] = 1;
                a |= (1LL << i);
                b |= (1LL << i);
            } else {
                ans[i] = 0;
            }
        }
    }

    cout << "! " << a << ' ' << b << std::endl;


	return ;
}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int T = 1;
//	cin >> T;
	while (T--) {
		ap();
	} 
    return 0;
}
```
