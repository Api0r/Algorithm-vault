
# 1. 异或 - 不进位加法


https://codeforces.com/contest/2260/problem/C

设每次操作使 $x$ 减少 $1$、 $y$ 增加 $1$，操作 $k$ 次后得到的新数值为 $x' = x - k$， $y' = y + k$。

在所有操作中， $x' + y' = x + y = S$ 始终保持不变，且满足 $0 \le x' \le x$。

根据异或与加法的性质：

$$x' + y' = (x' \oplus y') + 2(x' \text{ AND } y')$$

由于 $x', y' \ge 0$，因此 $x' \text{ AND } y' \ge 0$，可得：

$$x' \oplus y' \le x' + y' = S$$

当且仅当 $x' \text{ AND } y' = 0$ 时， $x' \oplus y'$ 达到最大可能值 $S$。这等价于 $x'$ 是 $S$ 的一个二进制子集（submask）。

因为 $x' = 0$ 恒为 $S$ 的子集且 $0 \le x$，所以最大异或和始终为 $S = x + y$。

为了最小化操作次数 $k = x - x'$，我们需要在满足 $x' \subseteq S$ 且 $x' \le x$ 的前提下**最大化** $x'$：

- 从高位向低位遍历每一位 $i$：
    
    - 若 $S$ 该位为 $1$ 且 $x$ 该位为 $1$： $x'$ 该位取 $1$；
        
    - 若 $S$ 该位为 $1$ 且 $x$ 该位为 $0$： $x'$ 该位取 $0$；
        
    - 若 $S$ 该位为 $0$ 且 $x$ 该位为 $0$： $x'$ 该位取 $0$；
        
    - 若 $S$ 该位为 $0$ 且 $x$ 该位为 $1$： $x'$ 该位只能取 $0$。此时 $x'$ 在该位严格小于 $x$，后续所有更低位不再受 $x' \le x$ 的约束，直接贪心取 $S$ 对应的所有位即可。


## $x + y = (x \oplus y)$ 时满足的性质


有恒等式 $x + y = (x \oplus y) + 2(x \text{ AND } y)$

需要满足上面的式子则需
$$x \text{ AND } y = 0$$

这表明 $x$ 和 $y$ 在二进制的所有位上**没有任何共同为 1 的位**（即加法完全无进位）。

显然，最大的答案始终为`x + y`，还需要解决最小操作次数的问题
注意到，当最终的`x = x’` 时，操作次数为`x - x'`，需要使其最小，则需`x'` 最大
同时需要满足`x - x' >= 0` 
因此我们可以从高位到低位，如果这个bit位上没有0，则说明`x' 和y'` 上的这个bit位都没有0，
如果这个bit位为1，则说明`x' 和 y'` 有且仅有一个在此bit位上为1
为了使`x'` 最大，我们从高到低位，在满足`x - x' >= 0` 的条件下，能加则加

```c++
#include <bits/stdc++.h>  
using namespace std;  
#define int long long
#define endl '\n'
const int mod = 1e9 + 7;
const int MOD = 998244353;

void ap() {
	int x, y; cin >> x >> y;

    if (x == 0) {
        cout << y << ' ' << 0 << endl;
        return;
    }

    int mx = x + y;
    int t = 0;
    for (int i = 30; i >= 0; i--) {
        int bit = 1 << i;
		
		//注意这里的优先级
        if ((mx & bit) == 0) continue;

        if (t + bit <= x) {
            t += bit;
        }
    }

    cout << mx << ' ' << x - t << endl;


	return ;
}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int T = 1;
	cin >> T;
	while (T--) {
		ap();
	} 
    return 0;
}
```


# 2. OR

https://codeforces.com/contest/2261/problem/B

`x 的最高二进制位 为k` 则 `k = 31 - __builtin_clz(x)`

`Denote msb(x) as the position of the most significant bit of x, where the 0-th bit is the least significant bit.`

- `msb(mx) != msb(mn)` 那么总可以让与`mx`相邻的那个数变为`2 ^ k - 1` ，最终答案为`2 ^ (k + 1) - 1`
- `msb(mx) == msb(mn)` 则无法使低`k`位全变成1，转而看向`k - 1`位上`bit` 是否相同
- 如果相同，则说明任何一个数在这个位上都相同。如果这一个位是1不用操作就已经是最优的，如果这一位是0，会发现无法操作使其变为1
- 找到第一个不相同的bit位，同理在这个位上利用上面的操作

```c++
#include <bits/stdc++.h>  
using namespace std;  
#define int long long
#define endl '\n'
const int mod = 1e9 + 7;
const int MOD = 998244353;

void ap() {
	int n; cin >> n;
    vector<int> a(n);
    for (int & i : a) cin >> i;

    int mn = 1e9, mx = 0;
    for (int x : a) {
        mn = min(mn, x);
        mx = max(mx, x);
    }

    if (mx == mn) {
        cout << mx << endl;
    } else {
        cout << (((1<<(32-__builtin_clz(mx^mn)))-1)|mx) << endl;
    }

	return ;
}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int T = 1;
	cin >> T;
	while (T--) {
		ap();
	} 
    return 0;
}
```
