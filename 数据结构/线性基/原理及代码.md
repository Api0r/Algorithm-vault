# 线性基原理

> 只对**非负数**进行讨论。线性基常指的是**异或空间线性基**，向量空间线性基是下期的内容。

---

## 核心思想

一堆数字能得到的**非 0 异或和的结果**，能被**元素个数尽量少的集合**，不多不少的全部得到。

那么就说，这个元素个数尽量少的集合，是这一堆数字的**异或空间线性基**。

> 注意：只关心去重的**非 0 异或和**能否全部得到，并不关心每种异或和的个数。

---

## 构建基础

如下几个结论是构建异或空间线性基的基础：

1. 一堆数字中，任意的 `a` 和 `b`，用 `a ^ b` 的结果替代 `a`、`b` 中的一个数字，不会影响非 0 异或和的组成。
2. 一堆数字中，任意的 `a` 和 `b`，如果有 `a ^ b == 0`，那么舍弃掉 `a`、`b` 其中一个数字，不会影响非 0 异或和的组成。
3. 一堆数字能否异或出 `0`，在求出异或空间线性基之后，需要被**单独标记**。


```c++
#include <bits/stdc++.h>  
using namespace std;  
#define int long long
#define endl '\n'
const int mod = 1e9 + 7;
const int MOD = 998244353;

vector<int> basis;

int BIT = 64;


bool insert(int x) {
    for (int i = BIT; i >= 0; i--) {
        if (x >> i == 1) {
            if (basis[i] == 0) {
                basis[i] = x;
                return true;
            }

            x ^= basis[i];
        }
    }
    return false;
}

int max_xor() {
    int ans = 0;
    for (int i = BIT; i >= 0; i--) {//这里一定要从高位开始遍历，不可以直接用加强for循环
        ans = max(ans, ans ^ basis[i]);
    }
    return ans;
}

void ap() {
	int n; cin >> n;
    vector<int> a(n);
    for (int & i : a) cin >> i;

    basis.assign(51, 0);
    BIT = 50;

    for (int & x : a) {
        insert(x);//如果插入false，说明有0
    }

    cout << max_xor() << endl;
    
	return ;
}
```
