
# 解决的问题

### 1. 瓶颈路问题（两点间路径的最大边权最小）

- **经典提问**：在一个连通图中，从点 $x$ 走到点 $y$，有无数条路径。每条路径上的最大边权视为该路径的“代价”。问所有路径中，**最小的代价**是多少？
    
- **重构树的解法**：
    
    在 Kruskal 重构树中，$x$ 和 $y$ 的**最近公共祖先（LCA）的节点权值**（即 `nodeKey[lca(x, y)]`），就是它们之间瓶颈路的最优解。
    
- **为什么？** 因为重构树是按照边权从小到大建出来的，两点第一次联通时所对应的新节点，其权值正好就是那条“让它们联通的、边权最小的边”。
    

### 2. 边权限制下的连通块问题（只走 $\le w$ 的边能到哪些点）

- **经典提问**：从点 $x$ 出发，在**只能走边权小于等于 $w$ 的边**的前提下，你能到达多少个节点？或者能到达的点中点权最大的是多少？
    
- **重构树的解法**：
    
    从重构树的叶子节点 $x$ 开始**向上倍增跳跃**，只要祖先节点的权值 `nodeKey[anc] <= w`，就一直往上跳。跳到最顶端的那个祖先节点 $anc$。
    
    此时，**以 $anc$ 为根的子树中所有的叶子节点**，就是 $x$ 在限制条件下能走到的所有点。
    
- **为什么？** 因为在重构树中，由于大边在上方，一个节点的子树内部所有节点之间的连通边，其权值都小于等于该节点的权值。
    

### 3. 多元路径性质查询

- 在原图中，如果你想知道“满足某种边权限制下，某一类点的集合性质（如第 $k$ 大、点权和等）”，在原图上需要频繁进行图的遍历或并查集撤销。
    
- **重构树的解法**：转换为子树后，就可以完美结合 **DFS 序、树状数组、线段树或者主席树**，把图上动态的限制问题，变成线性的**区间查询问题**。



- **普通最小生成树（MST）** 只能告诉你：“怎么用最低的总代价把所有房间串联起来”。
    
- **Kruskal 重构树** 则直接把这个迷宫重建成了一栋**行政大楼（树）**：
    
    - 原来的房间全部变成了**第一层的底层员工（叶子节点）**。
        
    - 原来的关卡变成了**各级领导（内部虚拟节点）**，领导的级别就是门槛的高度。
        
    - 两个员工想见面，必须汇报到能管辖他们俩的**最小的那级主管（LCA）**，这个主管的级别就是他们见面的最低门槛。



# 代码

以下面的为例
[P2245 星际导航 - 洛谷](https://www.luogu.com.cn/problem/P2245)

```c++
#include <bits/stdc++.h>  
using namespace std;  
#define int long long
#define endl '\n'
const int mod = 1e9 + 7;
const int MOD = 998244353;

//重构树的最大节点数量， 边的最大数量， 倍增算法（LCA）的最大跳跃高度（指数上限）
const int MAXK = 200001, MAXM = 300001, MAXH = 20;
int n, m, q;

//每条边有3个信息，节点u，节点v， 边权w
vector<array<int, 3>> edge(MAXM);//因为要写排序，所以要用vector(C++ 无法对原生数组进行“整行交换/赋值)

int fa[MAXK];

// Kruskal重构树的建图
int head[MAXK];
int nxt[MAXK];
int to[MAXK];
int cntg = 0;

// Kruskal重构树上，节点的权值
int nodeKey[MAXK];
// Kruskal重构树上，点的数量
int cntu;

// Kruskal重构树上，dfs过程建立的信息
int dep[MAXK];
int stjump[MAXK][MAXH];

int find(int i) {
    if (fa[i] != i) {
        fa[i] = find(fa[i]);
    }
    return fa[i];
}

//链式前向星
//向树中添加一条从 u 指向 v 的有向边
void addEdge(int u, int v) {
    nxt[++cntg] = head[u];
    to[cntg] = v;
    head[u] = cntg;
}

void kruskalRebuild() {
    for (int i = 1; i <= n; i++) {
        fa[i] = i;
    }
    sort(edge.begin() + 1, edge.begin() + m + 1, [](const array<int, 3>& a, const array<int, 3>& b) {
    return a[2] < b[2];
});
    
    cntu = n;
    for (int i = 1, fx, fy; i <= m; i++) {
        fx = find(edge[i][0]);
        fy = find(edge[i][1]);
        if (fx != fy) {
            fa[fx] = fa[fy] = ++cntu;
            fa[cntu] = cntu;
            
            nodeKey[cntu] = edge[i][2];
            addEdge(cntu, fx);//cntu -> fx
            addEdge(cntu, fy);
        }
    }
}

// dfs1是递归函数，需要改成迭代版，不然会爆栈，C++实现不需要
void dfs1(int u, int fa) {
    dep[u] = dep[fa] + 1;
    stjump[u][0] = fa;
    for (int p = 1; p < MAXH; p++) {
        stjump[u][p] = stjump[stjump[u][p - 1]][p - 1];
    }
    for (int e = head[u]; e > 0; e = nxt[e]) {
        dfs1(to[e], u);
    }
}

int lca(int a, int b) {
    if (dep[a] < dep[b]) {
        swap(a, b);
    }
    
    //使a,b在同一深度
    for (int p = MAXH - 1; p >= 0; p--) {
        if (dep[stjump[a][p]] >= dep[b]) {
            a = stjump[a][p];
        }
    }
    
    if (a == b) {
        return a;
    }
    
    //倍增找LCA - 相当于 < lca 的极限，最后再走一步
    for (int p = MAXH - 1; p >= 0; p--) {
        if (stjump[a][p] != stjump[b][p]) {
            a = stjump[a][p];
            b = stjump[b][p];
        }
    }
    return stjump[a][0];
}

void ap() {
	cin >> n >> m;

    for (int i = 1; i <= m; i++) {
        int u, v, w; cin >> u >> v >> w;
        edge[i][0] = u;
        edge[i][1] = v;
        edge[i][2] = w;
    }

    kruskalRebuild();
    for (int i = 1; i <= cntu; i++) {
        if (i == fa[i]) {
            dfs1(i, 0);
        }
    }

	cin >> q;
    for (int i = 1; i <= q; i++) {
        int x, y; cin >> x >> y;

        if (find(x) != find(y)) {
            cout << "impossible" << endl;
        } else {
            cout << nodeKey[lca(x, y)] << endl;
        }
        
    }
	return ;
}

signed main() {
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int T = 1;
//	cin >> T;
	while (T--) {
		ap();
	} 
    return 0;
}
```
