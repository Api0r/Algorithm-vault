
# 核心概念

最小生成树 Minimum Spanning Tree，简称 MST

- **树（Tree）：** 一个拥有 $n$ 个顶点和 $n-1$ 条边的连通无环图。
    
- **生成树（Spanning Tree）：** 包含原图中**全部 $n$ 个顶点**，但只有 **$n-1$ 条边**的子图。这意味着所有点都被连通了，且没有形成任何闭环（圈）。
    
- **最小生成树（Minimum Spanning Tree）：** 在所有可能的生成树中，**边的权值之和最小**的那棵树。

5555
💡 **核心特征：**

1. 顶点数和原图一模一样。
    
2. 边数严格等于 $V - 1$（$V$ 为顶点数）。
    
3. 绝对不能有环。
    
4. 权值之和最小（可能存在多棵不同的最小生成树，但它们的权值和一定相同）。


# 经典求解算法

在计算机科学中，最常用、最经典的算法有两个：

| **算法名称**               | **核心思想**                                                             | **适用场景**  |
| ---------------------- | -------------------------------------------------------------------- | --------- |
| **Kruskal 算法** (克鲁斯卡尔) | **加边法**：每次挑选权重最小的边，如果加入后不形成环，就并入树中。通常使用**并查集**（Disjoint-set）来判断是否成环。 | 稀疏图（边比较少） |
| **Prim 算法** (普里姆)      | **加点法**：从某一个起点开始，每次寻找距离当前已构建树“最近”的一个未加入顶点，将其拉入队中。                    | 稠密图（边非常多） |


# 代码

**Kruskal 算法**和 **Prim 算法**。

在算法竞赛和工程应用中，**Kruskal 算法**因为配合并查集（Disjoint Set Union, DSU）极好写且不易出错，是最常用的首选。

## 1. Kruskal 算法模板（推荐）

**核心思想：** 按照边权从小到大排序，每次贪心地选择最小的边，若边的两端点不在同一个连通块内（用并查集判断），则将这条边加入最小生成树中。


```c++
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// 定义边的结构体
struct Edge {
    int u, v, w;
    bool operator<(const Edge& other) const {
        return w < other.w; // 按边权从小到大排序
    }
};

// 并查集结构体
struct DSU {
    vector<int> parent;
    DSU(int n) {
        parent.resize(n + 1);
        for (int i = 0; i <= n; ++i) parent[i] = i;
    }
    int find(int i) {
        if (parent[i] == i)
            return i;
        return parent[i] = find(parent[i]); // 路径压缩
    }
    bool unite(int i, int j) {
        int root_i = find(i);
        int root_j = find(j);
        if (root_i != root_j) {
            parent[root_i] = root_j;
            return true;
        }
        return false; // 本就在同一连通块，说明有环
    }
};

/**
 * Kruskal 算法求最小生成树
 * @param n 点的数量
 * @param edges 边集
 * @return 最小生成树的权值和。如果图不连通，返回 -1
 */
int kruskal(int n, vector<Edge>& edges) {
    sort(edges.begin(), edges.end());
    DSU dsu(n);
    
    int mst_weight = 0;
    int edges_count = 0;

    for (const auto& edge : edges) {
        if (dsu.unite(edge.u, edge.v)) {
            mst_weight += edge.w;
            edges_count++;
            if (edges_count == n - 1) break; // 已经找够了 n-1 条边
        }
    }

    // 如果加入的边数不等于 n - 1，说明图不连通
    return (edges_count == n - 1) ? mst_weight : -1;
}

int main() {
    int n, m; // n个点，m条边
    if (!(cin >> n >> m)) return 0;

    vector<Edge> edges(m);
    for (int i = 0; i < m; ++i) {
        cin >> edges[i].u >> edges[i].v >> edges[i].w;
    }

    int ans = kruskal(n, edges);
    if (ans == -1) cout << "No MST (Graph is not connected)" << endl;
    else cout << ans << endl;

    return 0;
}
```

## 2. Prim 算法模板（堆优化版）

**核心思想：** 类似于 Dijkstra 算法。从任意一个点开始，每次把距离“当前已构建的 MST”最近的未访问节点加进来，并用新加入的点去更新其他点到 MST 的距离。这里使用 `std::priority_queue` 进行堆优化。


```c++
#include <iostream>
#include <vector>
#include <queue>

using namespace std;

const int INF = 0x3f3f3f3f;

// 邻接表边结构
struct Edge {
    int to, weight;
};

/**
 * Prim 算法求最小生成树（堆优化版）
 * @param n 点的数量
 * @param adj 邻接表
 * @return 最小生成树的权值和。如果图不连通，返回 -1
 */
int prim(int n, const vector<vector<Edge>>& adj) {
    // pair.first: 到当前MST的距离, pair.second: 节点编号
    priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> pq;
    
    vector<int> min_dist(n + 1, INF); // 记录每个点到当前MST的最小距离
    vector<bool> visited(n + 1, false); // 标记点是否已被并入MST
    
    int mst_weight = 0;
    int count = 0; // 记录并入MST的节点数

    // 从 1 号节点开始（可根据题意调整为 0）
    min_dist[1] = 0;
    pq.push({0, 1});

    while (!pq.empty()) {
        auto [dist, u] = pq.top();
        pq.pop();

        if (visited[u]) continue;
        
        // 将点 u 加入 MST
        visited[u] = true;
        mst_weight += dist;
        count++;

        // 遍历 u 的所有邻居
        for (const auto& edge : adj[u]) {
            int v = edge.to;
            int w = edge.weight;
            // 如果 v 不在 MST 中，且通过 u 连接 v 的代价更小
            if (!visited[v] && w < min_dist[v]) {
                min_dist[v] = w;
                pq.push({min_dist[v], v});
            }
        }
    }

    // 如果并入树的点数不等于总点数，说明图不连通
    return (count == n) ? mst_weight : -1;
}

int main() {
    int n, m;
    if (!(cin >> n >> m)) return 0;

    vector<vector<Edge>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
        adj[v].push_back({u, w}); // 无向图
    }

    int ans = prim(n, adj);
    if (ans == -1) cout << "No MST" << endl;
    else cout << ans << endl;

    return 0;
}
```

## 💡 怎么选？

- **看边数：** 如果是**稀疏图**（边数 $M$ 和点数 $N$ 差不多，例如 $M \approx N$），直接用 **Kruskal**，时间复杂度 $O(M \log M)$。
    
- **看稠密：** 如果是**稠密图**（边数接近完全图 $M \approx N^2$），堆优化 **Prim** 的复杂度为 $O(M \log N)$；如果是不带堆优化的朴素 Prim 复杂度为 $O(N^2)$，在极稠密图下有时甚至比 Kruskal 更快。
    
- **比赛经验：** 大部分题目都是稀疏图，且 Kruskal 代码结构清晰，自带并查集还能顺便解决一些**连通性**判定问题（如：第 $k$ 大边、断边重连等变体），**强烈建议熟练掌握 Kruskal 模板**。
