## 证明：1.引理 $\text{ans}_n \le \text{ans}_{n+1}$

这个题目很有意思
首先证明一个引理 $\text{ans}_n \le \text{ans}_{n+1}$

证：$\text{ans}_n \le \text{ans}_{n+1}$

对于 n，先手有两种选择
- 不将其变为 n，即变为`[n + 1, 2n - 1]` 范围内的数字
- 将其变为 n

我们一个个来讨论

1. n 变为`[n + 1, 2n - 1]` 范围内的数字
    那么对于 n + 1 来说，其可以变成`[n + 1, 2n]` 范围内的数字
    其选择权明显大于 n
- 如果 n + 1 变为`[n + 1, 2n - 1]` 内的数字，那么$\text{ans}_n = \text{ans}_{n+1}$
- 如果 n + 1 变为 2n，那么可能会有 $\text{ans}_n < \text{ans}_{n+1}$

2. n 变为 n
对 n 来考虑
- 数字为 $n$。
- 后手必须除以 $n$ 的最大质因数，设为 $P_{\max}(n)$。
- 这一轮结束后留下的数字为：

    $$n' = \frac{n}{P_{\max}(n)}$$

- 根据定义，此时能够继续进行的步数由 $\text{ans}\left(\frac{n}{P_{\max}(n)}\right)$ 决定。

对 n + 1 考虑，此时总是可以选择变为 2n
- 数字为 $2n$。
- 观察 $2n$ 的质因数集合：它就是 $n$ 的所有质因数加上一个质数 $2$。
    - 因为 $2$ 是最小的质数，只要 $n > 1$，乘上 2 **绝不可能增加更大的质因数**。
    - 因此 $2n$ 的最大质因数与 $n$ 完全相同：

        $$P_{\max}(2n) = P_{\max}(n)$$

        （若 $n=1$，最大质因数也是 2，结论同样成立）。

- 后手为了尽可能缩短轮数，依然必须除以这个最大质因数 $P_{\max}(n)$。
- 这一轮结束后留下的数字为：

    $$(n+1)' = \frac{2n}{P_{\max}(2n)} = \frac{2n}{P_{\max}(n)} = 2 \times \frac{n}{P_{\max}(n)} = 2n'$$

**数学归纳：**

对比两边一轮后留给下一轮的数字：

$$(n+1)' = 2n' > n'$$

由于在数学归纳法中，所有严格小于 $n$ 的数字都已满足引理（即数字越大，步数单调不减）：

因为 $(n+1)' > n'$，根据归纳假设立即得出：

$$\text{ans}((n+1)') \ge \text{ans}(n')$$

这表明：

即使面对 $n$ 时先手选了 $n$ 本身，面对 $n+1$ 时先手只要挑出 $2n$，**留给下一轮的数字大小直接翻倍**。根据归纳假设，更大的数字能撑下的轮数一定不会更少，因此：

$$\text{ans}_{n+1} \ge \text{ans}_n$$



## 证明：2.区间 $[n, 2n - 1]$ 中必定存在 2 的幂次

为了后续更好的理解与证明，先证明区间 $[n, 2n - 1]$ 中必定存在 2 的幂次这个性质

### 构造与证明

考虑**大于等于 $n$ 的最小的 2 的幂次**，设其为 $2^k$（即 $k = \lceil \log_2 n \rceil$）。

根据 $2^k$ 的最小性定义：

1. 因为 $2^k$ 是所有满足 $\ge n$ 的 2 的幂次中最小的一个，所以前一个 2 的幂次 $2^{k-1}$ 必定严格小于 $n$：

    $$2^{k-1} < n$$

2. 同样由定义，自然满足：

    $$n \le 2^k$$

现在，对不等式 $2^{k-1} < n$ 两边同时乘以 2：

$$2 \cdot 2^{k-1} < 2n \implies 2^k < 2n$$

因为 $2^k$ 和 $2n$ 都是正整数，满足严格小于 $2^k < 2n$ 的整数必然满足：

$$2^k \le 2n - 1$$

将上述两个方向的不等式结合：

$$n \le 2^k \le 2n - 1$$

这直接证明了：对于任意正整数 $n$，数 $2^k$ 必定落在闭区间 $[n, 2n - 1]$ 内。

### 直观理解（二进制视角）

从二进制最高位（最高有效位 MSB）来看同样非常直观：

- 设 $n$ 的最高有效位对应权重为 $2^m$（即 $2^m \le n < 2^{m+1}$）。
- **情况 1**：若 $n$ 本身就是 2 的幂次，即 $n = 2^m$，则 $2^m$ 就在区间 $[n, 2n-1]$ 内（恰为左端点）。
- **情况 2**：若 $n$ 不是 2 的幂次，则 $2^m < n < 2^{m+1}$。

    此时考察下一个 2 的幂次 $2^{m+1}$：

    - 因为 $n > 2^m$，两边乘 2 得到 $2n > 2^{m+1}$，即 $2^{m+1} \le 2n - 1$。
    - 同时由前提 $n < 2^{m+1}$。
    - 因此 $n < 2^{m+1} \le 2n - 1$，$2^{m+1}$ 恰好落在区间内。

综上，区间 $[n, 2n - 1]$ 中必定存在 2 的幂次，且该 2 的幂次恰好是**大于等于 $n$ 的最小 2 的幂次**。



## 证明：3.先手总能使 n 在一轮操作后至少为 `n / 2`

准确地说是：**先手总能采取一种策略，使得在一轮操作（先手增加数字、后手除以质因子）结束后，留下的数字 $n_{\text{next}} \ge \frac{n}{2}$**。

区间 $[n, 2n - 1]$ 内可能会存在更优的策略，但是由于引理 2 的得证，总会存在一个 2 的幂次，对于这个 2 的幂次，其最大的质因数为 2，因此总会存在一种策略，使得在一轮操作之后，留下的数字 $n_{\text{next}} \ge \frac{n}{2}$**。
- 如果有更优的呢，其 `>= n / 2`
- 更劣的呢，我们总有这种保底选择策略

以下是严格的构造与证明：

### 1. 构造先手的选择

在当前数字为 $n$ 时，先手的可选范围是闭区间 $[n, 2n - 1]$ 内的任意整数。

根据引理，区间 $[n, 2n - 1]$ 内**必然存在至少一个 2 的幂次**。

我们让先手选择**大于等于 $n$ 的最小 2 的幂次**，记为 $2^k$：

$$n \le 2^k \le 2n - 1$$

此时，先手将数字更新为 $m = 2^k$。

### 2. 分析后手的合法操作

后手必须选择当前数字 $m = 2^k$ 的一个质因子 $p$ 并将数字除以 $p$。

- 由于 $m = 2^k$ 是纯 2 的幂次，其唯一的质因子就是 **$2$**。
- 因此后手没有其他任何选择，**只能且必须选择质数 $p = 2$**。

### 3. 计算一轮结束后的数字

后手除完后，留给下一轮的数字为：

$$n_{\text{next}} = \frac{m}{p} = \frac{2^k}{2}$$

因为在第一步构造中已知 $2^k \ge n$，所以两边同时除以 2 可得：

$$n_{\text{next}} = \frac{2^k}{2} \ge \frac{n}{2}$$

**结论：** 先手只要每次选择区间 $[n, 2n - 1]$ 内的 2 的幂次 $2^k$，后手就只能除以 2，这样一轮结束后得到的数字必然满足：

$$n_{\text{next}} \ge \frac{n}{2}$$



## 证明：4.想找到更优，则先手必须保证其操作之后的数的最大质因数 `p <= 4`，即质因数只有 2 和 3

$$\frac{2n}{p} \ge \frac{n}{2} \implies p \le 4$$

这段话的核心逻辑可拆解如下：

- **保底基准（右边的 $\frac{n}{2}$）**：

    先手永远有一个平庸策略（Trivial Strategy）——选择区间 $[n, 2n - 1]$ 内的 2 的幂次 $2^k$。如果先手选 $2^k$，后手只能除以 2，留下的数字必定满足：

    $$\frac{2^k}{2} \ge \frac{n}{2}$$

    这意味着先手随时都能保证轮次结束后数字**不低于 $\frac{n}{2}$**。
	这是上述引理 3 详细证明过的

- **先手选择其他数（左边的 $\frac{2n}{p}$）**：

    假设先手选了一个整数 $m \in [n, 2n - 1]$，而后手除以质数 $p$。

    由于 $m < 2n$，后手除完后留下的数字至多为：

    $$\frac{m}{p} < \frac{2n}{p}$$

- **不等式推导**：

    先手要想让这个新决策**不劣于**直接选 2 的幂次的保底收益，必须保证除完后的结果有机会达到 $\frac{n}{2}$：

    $$\frac{2n}{p} > \frac{n}{2}$$

    两边消去正整数 $n$：

    $$\frac{2}{p} > \frac{1}{2} \implies p < 4$$

    因为 $p$ 是质数且为整数，所以：

    $$p \le 4 \implies p \in \{2, 3\}$$

**结论：**

一旦先手选的数含有任何大于等于 5 的质因数，后手就可以挑选该质因数进行除法，导致留下的数字严格小于 $\frac{2n}{5} = 0.4n < 0.5n = \frac{n}{2}$，比先手的保底收益更差。因此后手最终能除的质数 $p$ 只能是 2 或 3。



## 结论

由以上的证明，可以得到一些结论：

- $\text{ans}_n \le \text{ans}_{n+1}$ 数字越大，轮次越多
- 先手选择的数字的质因数只能包含 2 or 3

`n <= 1e18`，在这个范围内的 2 的幂次最多 62 个，同理 3 的幂次也不会超过 62
形如 $2^a$ $3^b$ 的数字的个数也不会超过 2000

$2^a 3^b \le 2.1 \times 10^{18}$，其中 $a \le 61, b \le 39$，总共仅有约 **1500** 个元素

因此，我们可以预处理出 $2^a$ $3^b$ 的数组 a，每次在区间 $[n, 2n - 1]$ 内暴力的遍历完数组 a 中的数字，将一轮操作结束后最大的数字记为结果进行下一轮

因为数组 a 很小，并且我们可以二分找到在区间范围内的数字，因此时间上合理



```c++
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define endl '\n'

void ap() {
    int n; cin >> n;

    if (n == 1) {
        cout << 0 << endl;
        return;
    }

    // 上限开到 2.1e18，保证能覆盖 2 * n - 1
    int mx = 2.1e18;

    vector<int> a;
    for (int i = 0; i <= 61; i++) {
        // 使用 __int128 防止带符号溢出
        __int128 x = ((__int128)1) << i;
        if (x > mx) break;

        for (int j = 0; ; j++) {
            a.push_back((int)x);
            if (x > mx / 3) break; // 防溢出检查
            x *= 3;
        }
    }

    sort(a.begin(), a.end());
    a.erase(unique(a.begin(), a.end()), a.end());

    int ans = 0;
    while (n > 1) {
        ans++;

        // 找到区间 [n, 2n - 1] 内的所有 3-光滑数
        // 先手要最大化后手除完之后的数字
        auto it = lower_bound(a.begin(), a.end(), n);

        int nxt_max = 0;
        while (it != a.end() && *it <= 2 * n - 1) {
            int cur = *it;
            int div_res;
            if (cur % 3 == 0) {
                div_res = cur / 3;
            } else {
                div_res = cur / 2;
            }
            nxt_max = max(nxt_max, div_res);
            it++;
        }

        n = nxt_max;
    }

    cout << ans << endl;
}

signed main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T = 1;
    // cin >> T;
    while (T--) {
        ap();
    }
    return 0;
}
```

## 代码详解

### 一、核心逻辑与博弈论依据

这份代码的成立依赖于三个经过严格数学证明的推论：

1. **引理保证单调性**：$\text{ans}_n \le \text{ans}_{n+1}$。这说明当前轮次结束后留给下一轮的数字越大，游戏能够持续的总轮数就单调不降。因此先手的最优贪心策略就是**最大化后手除完后留下的数字**。
2. **后手最优决策**：后手想要轮数尽可能少，面对先手挑选的数 $m$，必然会选择当前数的**最大质因数 $P_{\max}(m)$** 进行除法，留下 $\frac{m}{P_{\max}(m)}$。
3. **先手的候选池剪枝（仅限 3-光滑数）**：
    - 先手在区间 $[n, 2n - 1]$ 内永远能找到至少一个 2 的幂次 $2^k$，后手只能除以 2，留下 $\frac{2^k}{2} \ge \frac{n}{2}$（保底策略）。
    - 如果先手选了一个含有质因子 $p \ge 5$ 的数，后手除以 $p$ 得到的数为 $\frac{m}{p} \le \frac{2n - 1}{5} < \frac{n}{2}$，劣于保底策略。
    - 因此先手**绝不会选择含有 $\ge 5$ 质因子的数**。可选数字的质因子集合只能为 $\{2\}$ 或 $\{2, 3\}$（即形如 $2^a 3^b$ 的数）。

### 二、模块逐行详解

#### 1. 预处理部分（安全打表 3-光滑数）

```c++
int mx = 2.1e18;

vector<int> a;
for (int i = 0; i <= 61; i++) {
    __int128 x = ((__int128)1) << i;
    if (x > mx) break;

    for (int j = 0; ; j++) {
        a.push_back((int)x);
        if (x > mx / 3) break; // 防溢出除法检查
        x *= 3;
    }
}

sort(a.begin(), a.end());
a.erase(unique(a.begin(), a.end()), a.end());
```

- **为什么上限是 `2.1e18`？**

    输入 $n \le 10^{18}$，先手的挑选区间为 $[n, 2n - 1]$。当 $n = 10^{18}$ 时，先手最大可取到 $2 \times 10^{18} - 1$。必须将上限设定到略大于 $2 \times 10^{18}$，才能保证搜索不被截断。

- **为什么用 `__int128` 和 `x > mx / 3`？**

    `long long` 的最大值约为 $9.22 \times 10^{18}$。如果先乘 3 再做溢出判断，当 $x \approx 5 \times 10^{18}$ 时乘 3 会直接发生有符号整数溢出（UB），变成未知的负数或正数破坏数组。使用 `__int128` 计算结合除法预检，从物理层面上规避了溢出风险。

- **纯 2 幂次的存入**：

    在进入内层 `for` 循环时，第一次直接 `a.push_back(x)`（此时为 $2^i \times 3^0$），确保了所有纯 2 的幂次全部被无一遗漏地存入表中。

#### 2. 主循环模拟部分（博弈转移）

```c++
int ans = 0;
while (n > 1) {
    ans++;

    // 找到区间 [n, 2n - 1] 内的所有 3-光滑数
    auto it = lower_bound(a.begin(), a.end(), n);

    int nxt_max = 0;
    while (it != a.end() && *it <= 2 * n - 1) {
        int cur = *it;
        int div_res;
        if (cur % 3 == 0) {
            div_res = cur / 3;
        } else {
            div_res = cur / 2;
        }
        nxt_max = max(nxt_max, div_res);
        it++;
    }

    n = nxt_max;
}
```

- `auto it = lower_bound(a.begin(), a.end(), n);`：

    利用二分查找，快速定位大于等于当前 $n$ 的第一个候选数（即区间的左边界）。

- `while (it != a.end() && *it <= 2 * n - 1)`：

    **遍历区间内的所有数**，彻底解决了原代码中“只看最后两个数”导致的漏解缺陷。

- `if (cur % 3 == 0) div_res = cur / 3; else div_res = cur / 2;`：

    模拟后手的最优抉择：因为当前数只含因数 2 和 3，后手一定会优先除以最大的质因数 3；如果不含因数 3，后手只能除以 2。

- `nxt_max = max(nxt_max, div_res);`：

    先手权衡区间内的所有候选点，挑选能留下**最大数值**的操作。

- `n = nxt_max;`：

    单步迭代完成，更新下一轮数字。

| **维度** | **量级分析** | **结论** |
| --- | --- | --- |

| **外层轮数** | 每一轮先手选 $2^k$ 保底能使 $n \ge \frac{n}{2}$，同时每轮必至少减 1 | 最坏轮数约 $\log_2(10^{18}) \approx 60$ 轮 |
