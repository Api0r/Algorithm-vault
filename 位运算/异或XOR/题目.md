void ap() {

## 1. 为什么最大边权“不可能比 $2^k$ 更小”？（反证法）

我们看一条从 $l$ 到 $r$ 的任意路径：$l \to x_1 \to x_2 \to \dots \to x_m \to r$。

既然起点 $l$ 的第 $k$ 位和终点 $r$ 的第 $k$ 位不同，那么在这条路径上，**一定存在某一步（某条边），使得节点的第 $k$ 位发生了改变**。

假设是从节点 $u$ 到节点 $v$ 的这一步，第 $k$ 位由 `0` 变成了 `1`（或者由 `1` 变成 `0`）。

根据异或的性质：

- 因为 $u$ 和 $v$ 的第 $k$ 位不同，所以 $u \oplus v$ 的第 $k$ 位**必然是 `1`**。
    
- 一个二进制数如果第 $k$ 位是 `1`，那么这个数的值**至少**是 $2^k$（当且仅当更低位全是 `0` 时取到 $2^k$）。
    

因此，无论你走哪条路径，中间换多少个点，**都必须跨越第 $k$ 位不同这道坎**。只要跨过去，那条边的权值就必然 $\ge 2^k$。

既然每条路径都至少包含一条 $\ge 2^k$ 的边，那么整条路径的“最大边权”显然也**不可能小于 $2^k$**。

## 2. 为什么最大边权“恰好可以等于 $2^k$”？（构造法）

光证明下界是 $2^k$ 还不够，我们还要证明我们**真的能只用 $\le 2^k$ 的边**走到终点。

你的代码采用的“从高位到低位，发现不同就消去”的策略，其精妙之处就在于：**每一次改变，都只动一个比特位**。

我们来看看这个过程中，每一步产生的边权是多少：

- **第一步**：遇到第一个不同的位（第 $k$ 位）。我们把这一位取反。此时走过的边权是：
    
    $$w_1 = 2^k$$
    
- **第二步**：继续往低位走，遇到下一个不同的位（假设是第 $i$ 位，显然 $i < k$）。我们把第 $i$ 位取反。此时走过的边权是：
    
    $$w_2 = 2^i$$
    
- **后续每一步**：以此类推，修改更低的第 $j$ 位（$j < i < k$），产生的边权是：
    
    $$w_3 = 2^j$$
    

因为 $k > i > j \dots$，所以这些边权满足：

$$2^k > 2^i > 2^j \dots$$

在这条路径上，所有的边权里，**最大的一条边权恰好就是第一步产生的 $2^k$**。

## 总结

1. **下界限制**：由于起点和终点在第 $k$ 位不同，任何路径都必须跨过这个差异，这就决定了**最大边权至少是 $2^k$**。
    
2. **贪心实现**：我们的算法通过“一次只修一个位”的做法，让第一步的边权等于 $2^k$，后续每一步的边权都严格小于 $2^k$。

int n;

int f(vector<int> & t) {
    if (t.size() == 0) return 0;

要证明“**路径不相交是最优的**”，在数学和算法上，通常可以通过**反证法**或代数不等式（三角不等式）来推导。

我们可以把问题简化为：在一条线段或一个环上，有 4 个点按顺序排列。我们要把它们两两配对，证明“交叉配对”的代价一定大于或等于“不交叉配对”。

## 不交叉配对更优 - 证明
### 1. 轴线（单向）上的直观证明

假设在数轴上有 4 个点，坐标依次为 $A < B < C < D$。

我们要把它们两两配对（每个点和另一个点连成一条线段），总代价是两对点之间距离的和。

我们来看三种配对方案的总长度：

1. **方案一（相邻配对，不交叉）：** $A$ 配 $B$，$C$ 配 $D$。
    
    $$\text{Length}_1 = (B - A) + (D - C)$$
    
2. **方案二（包含配对，不交叉）：** $A$ 配 $D$，$B$ 配 $C$。
    
    $$\text{Length}_2 = (D - A) + (C - B)$$
    
3. **方案三（交叉配对）：** $A$ 配 $C$，$B$ 配 $D$。
    
    $$\text{Length}_3 = (C - A) + (D - B)$$
    

### 代数比较：

我们把其中的式子展开变形：

- $\text{Length}_2 = D - A + C - B = (D - C) + (B - A) + 2(C - B) = \text{Length}_1 + 2(C - B)$
    
    因为 $C > B$，所以 $\text{Length}_2 > \text{Length}_1$。
    
- $\text{Length}_3 = C - A + D - B = (D - C) + (B - A) + 2(C - B) = \text{Length}_1 + 2(C - B)$
    
    同理，$\text{Length}_3 > \text{Length}_1$。
    

**结论：** 无论是包含还是交叉，方案一（紧邻配对）的代价永远是最小的。交叉配对（方案三）多走了一段两倍的 $BC$ 距离（即重叠区域）。

### 2. 环形上的几何证明（为什么只有两种）

环形和直线的区别在于：环形没有固定的绝对边界，它的两端是连通的。

想象一个圆圈上有 4 个点 $A, B, C, D$ 按顺时针排列。

如果我们允许**路径交叉**（比如 $A$ 连接 $C$，$B$ 连接 $D$）：

在圆内，线段 $AC$ 和线段 $BD$ 必然会**相交于一点 $P$**。

根据三角形三边关系（两边之和大于第三边），在 $\triangle APB$ 和 $\triangle CPD$ 中：

- $AP + BP > AB$
    
- $CP + DP > CD$
    

我们将这两个不等式相加：

$$(AP + CP) + (BP + DP) > AB + CD$$

由于 $AP + CP = AC$ 且 $BP + DP = BD$，代入后得到：

$$AC + BD > AB + CD$$

- $AC + BD$ 正是**交叉配对**的代价。
    
- $AB + CD$ 正是**顺时针相邻配对**的代价。
    

这说明，只要路径在圆内交叉，我们总能把它“解开”成不交叉的相邻配对，并且**总代价一定会变小**。

### 3. 推广到 $m$ 个点（数学归纳法思想）

如果有 $m$ 个点（$m$ 为偶数），假设存在某种最优解包含了交叉的路径。

根据上面的证明，我们总能找到最先交叉的两条路径，并把它们“解开”成不交叉的邻近路径，且解开后的总代价**严格小于**原代价。

由于每次解开交叉都会让总代价变小，那么：

1. **只要有交叉，就不是最优解。**
    
2. 最终的**全局最优解**必然处于“完全没有交叉”的状态。
    

而在一个环上，要把所有点两两配对且互不交叉，在拓扑结构上**有且仅有**两种交替的选择（即你代码中的全奇偶配对 `ans1`，或错开一位的跨界配对 `ans2`）。因此，最优解必然在这两者之中。

void ap() {
	int n, k; cin >> n >> k;
    string s; cin >> s;

    map<int, int> cnt;
    for (int i = 0; i < s.size(); i++) {
        if (s[i] == '0') continue;

        cnt[i % k]++;

    }

    for (auto & [x, c] : cnt) {
        if (c & 1) {
            cout << "NO" << endl;
            return;
        }
    }

    cout << "YES" << endl;

# 四、互质 + & 

[C-小红的gcd位运算构造_牛客小白月赛131](https://ac.nowcoder.com/acm/contest/131416/C)

- 如果x是偶数，那么最低位为0， 且一定含有质因数2.
- 那么可以直接输出y = 1，因为1和任意数都互质，并且 1 & 0 = 0

- 如果x是奇数，那么最低位为1，且一定不含有质因数2
- 那么我们构造一个只含有质因数2的数y 不就可以了吗！
- 因此，从x的最低为开始，找到第一个0的位置i， 输出1 << i

```c++
void ap() {
	int x; cin >> x;
    
    if (x & 1) {
        bitset<32> bt(x);
        for (int i = 0; i <= 32; i++) {
            if (bt[i] == 0) {
                cout << (1 << i) << endl;
                return;
            }
        }
    } 
    
    cout << 1 << endl;
    
	return ;
}
```

# 五 、 异或的性质 - 两边同时异或同一个数 其任相等

[C-小橙的完美序列_牛客小白月赛129](https://ac.nowcoder.com/acm/contest/128675/C)

```c++
void ap() {
	int n; cin >> n;
    vector<int> a(n);
    for (int & i : a) cin >> i;
    
    map<int, int> cnt;
    int mx = 0;
    for (int i = 0; i < n; i++) {
        int x = a[i] ^ (i + 1);
        cnt[x]++;
        
        mx = max(mx, cnt[x]);
    }
    
    cout << n - mx;
	return ;
}
```
