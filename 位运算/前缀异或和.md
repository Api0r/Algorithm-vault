# 对于前缀异或和的证明

对于每个四元组 (4k, 4k+1, 4k+2, 4k+3) ，将其两两分组 (4k, 4k+1), (4k+2, 4k+3) ，组内两个数只差最后一位，所以每组的异或均为 1，所以四元组的异或和为 0 。

我们不妨将整个式子异或上 0 ，即序列为 0,1,2,⋯,n，设 n=4k+c ，前 k 个四元组（第一组为 (0,1,2,3）的异或和为 0 ，只需要考虑最后的 c+1 个元素即可。

- 当 c=0，答案为 n 。
- 当 c=1 ，答案为 n−1⊕ n = 1。
- 当 c=2 ，答案为 n ⊕ 1 ，由于 n 为偶数，所以 n ⊕ 1 = n+1。
- 当 c=3 ，恰好为 k+1 个四元组，答案为 0 。

虽然 n ⊕ 1 和 n+1 的性能几乎没有差别，但是写成 n+1 有利于部分题目的化简，故这里也使用 n+1 的写法。
