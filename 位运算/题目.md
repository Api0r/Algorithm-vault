
# 一、前缀异或和

[E-小红的异或和_牛客周赛 Round 150](https://ac.nowcoder.com/acm/contest/137073/E)

一个数如果是 $x$ 的倍数，在十进制中就像“如果是 100 的倍数，末尾一定是两个 0”。

在二进制中：

- $2^0 = 1 = (1)_2$
    
- $2^1 = 2 = (10)_2$
    
- $2^2 = 4 = (100)_2$
    
- $2^3 = 8 = (1000)_2$
    
- 以此类推，$x = 2^k$ 的二进制表示是一个 `1` 后面跟着 $k$ 个 `0`。
    

当一个数 $v$ 是 $2^k$ 的倍数时，它可以表示为 $v = i \times 2^k$（其中 $i$ 是一个整数）。

在二进制中，**乘以 $2^k$ 相当于将数字 $i$ 的二进制向左移动 $k$ 位，低位补 $k$ 个 0**。

因此，所有满足条件的好数，它们的二进制**最后 $k$ 位全部都是 0**。

从这个角度看，我们只需要先把有效位计算出来，然后再左移 k 位 ， 即可

(**如果 $x$ 不是 2 的幂次，乘法会破坏二进制位之间的独立性（产生进位，导致异或的结合律失效。**)

```c++
int sum(int n) {
    int rem = n % 4;
    if (rem == 0) return n;
    if (rem == 1) return 1;
    if (rem == 2) return n + 1;
    return 0;
    
}

void ap() {
	int l, r, x; cin >> l >> r >> x;
    int left = (l + x - 1) / x;
    int right = r / x;
    
    if (left > right) {
        cout << 0 << endl;
        return;
    }
    
    int ans = 0;
    
    ans = sum(right) ^ sum(left - 1); 
    
    cout << ans * x << endl;
    
	return ;
}
```

# 二、 按位拆分

[C-异或或配对计数_牛客周赛 Round 150](https://ac.nowcoder.com/acm/contest/137073/C)

**知识点：** 按位拆分、位运算、乘法原理

对每一位单独考虑 (pi,qi) 的取值：

- 若 y 的这一位是 0 ，则 pi=qi=0 ，所以 x 的这一位也必须是 0 ，否则无解。
- 若 y 的这一位是 1 ：
- xi=1 时，只能是 (1,1) ，只有 1 种；
- xi=0 时，只能是 (0,1) 或 (1,0) ，有 2 种。

由于每一位的情况独立，所以枚举每一位计算方案数即可。

时间复杂度 O(log⁡V)。

```c++
void ap() {
	int x, y; cin >> x >> y;
    
    if ((x | y) != y) {
        cout << 0 << endl;
        return;
    }
    
    bitset<32> b(x);
    int cnt = 0;
    for (int i = 32; i >= 0; i--) {
        if (b[i]) cnt++;
    }
    
    cout << (1LL << cnt) << endl;
	return ;
}
```
