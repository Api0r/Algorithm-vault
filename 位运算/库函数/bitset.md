在 C++ 中，`std::bitset` 是标准库提供的一种**专门用来处理二进制位（bit）的容器**。

你可以把它想象成一个只能存储 `0` 和 `1` 的数组，或者一个**超长、大小可控的整数**。相比于普通的布尔数组（`bool arr[N]`）或整数类型（`int`、`long long`），`bitset` 在空间和位运算效率上进行了极致的优化。

##  为什么需要 `bitset`？

1. **极致的空间优化**：在 C++ 中，一个 `bool` 变量其实要占用 **1 个字节（8 个比特）** 的内存。而 `bitset` 里的每一个元素真正只占用 **1 个比特（1 bit）**。这意味着它的内存消耗只有 `bool` 数组的 $\frac{1}{8}$。
    
2. **支持超长的二进制位**：原生的整数类型最大通常只有 64 位（`unsigned long long`），而 `bitset` 的大小在编译时指定，你可以定义 100 位、1000 位甚至上万位的二进制数。
    
3. **自带强大的位运算函数**：它不仅支持 `&`、`|`、`^`、`~` 等位运算符，还内置了统计 `1` 的个数、翻转特定位等高效操作。
    

##  `bitset` 的基础用法

使用 `bitset` 需要引入头文件 `#include <bitset>`。它的声明语法是：`bitset<大小> 变量名;`（注意：**大小必须是编译期常量**）。

### 1. 初始化与定义

`bitset` 可以通过整数、字符串或者直接默认初始化。

C++

```
#include <iostream>
#include <bitset>
#include <string>
using namespace std;

int main() {
    // 1. 默认初始化：所有位都为 0
    bitset<8> b1; // 00000000

    // 2. 用十进制整数初始化（自动转为二进制）
    bitset<8> b2(42); // 42 的二进制是 00101010

    // 3. 用二进制字符串初始化
    bitset<8> b3(string("1100")); // 注意：高位自动补0，结果为 00001100
    
    cout << "b2: " << b2 << endl;
    cout << "b3: " << b3 << endl;
}
```

### 2. 访问与修改（像数组一样）

`bitset` 的下标是从 **最低位（最右边）** 开始算的，即第 `0` 位代表二进制的最右侧。

C++

```
bitset<8> b(42); // 二进制：00101010
                 // 索引：76543210

cout << b[1] << endl; // 输出 1 （右数第二位）
cout << b[2] << endl; // 输出 0 （右数第三位）

b[2] = 1; // 修改第 2 位，b 变成 00101110
```

##  核心常用成员函数

`bitset` 提供了非常多实用且高效的内置函数，在算法竞赛（如 ACM/蓝桥杯/力扣）中经常能大显身手。

| **函数名**         | **作用**                     | **示例 (b = 00101110)**      |
| --------------- | -------------------------- | -------------------------- |
| `b.size()`      | 返回 bitset 的总位数（大小）         | `b.size()` $\to$ 8         |
| `b.count()`     | 返回二进制中 **`1` 的个数**（内置高效实现） | `b.count()` $\to$ 4        |
| `b.any()`       | 检查是否存在至少一个 `1`             | `b.any()` $\to$ true       |
| `b.none()`      | 检查是否**全为 `0`**             | `b.none()` $\to$ false     |
| `b.all()`       | 检查是否**全为 `1`**             | `b.all()` $\to$ false      |
| `b.flip()`      | **翻转**所有位（0变1，1变0）         | `b.flip()` $\to$ 11010001  |
| `b.flip(i)`     | 翻转第 `i` 位                  | `b.flip(0)` $\to$ 第0位取反    |
| `b.set()`       | 把所有位都设为 `1`                | `b.set()` $\to$ 11111111   |
| `b.set(i, val)` | 把第 `i` 位设为 `val`（默认1）      | `b.set(3, 0)` $\to$ 第3位设为0 |
| `b.reset()`     | 把所有位都清零（设为 `0`）            | `b.reset()` $\to$ 00000000 |
| `b.to_ulong()`  | 转换为 `unsigned long` 整数     | 转换为十进制数                    |
| `b.to_string()` | 转换为 `std::string` 字符串      | 转换为 "00101110"             |

##  运算操作

`bitset` 支持所有的位运算符，你可以像操作普通 `int` 一样操作两个**相同大小**的 `bitset`：

C++

```
bitset<4> foo("1010");
bitset<4> bar("0110");

cout << (foo & bar) << endl; // 按位与   -> 0010
cout << (foo | bar) << endl; // 按位或   -> 1110
cout << (foo ^ bar) << endl; // 按位异或 -> 1100
cout << (~foo) << endl;      // 按位取反 -> 0101
cout << (foo << 1) << endl;  // 左移     -> 0100
```

##  算法竞赛/实际开发中的高频应用场景

### 1. 状态压缩与集合运算

如果一个集合有 $N$ 个元素，我们可以用 `bitset<N>` 的第 $i$ 位是否为 `1` 来表示第 $i$ 个元素是否存在。

- **求并集**：`setA | setB`
    
- **求交集**：`setA & setB`
    
- **求补集**：`~setA`
    

### 2. 状态可达性统计（如：拓扑排序/有向图连通性）

在图论中，如果我们需要求一个点能到达的所有点的集合，普通的做法是用 `std::vector` 或 `std::set` 挨个合并，时间复杂度会很高。

如果改用 `bitset`：

$$\text{reachable}[u] |= \text{reachable}[v]$$

因为 `bitset` 的位运算在底层是**打包成 64 位整型（甚至利用流水线和 SIMD 指令）并行处理的**，其单次位运算的效率相当于带了一个 $\frac{1}{64}$ 的常数加速优化（相当于提速 64 倍），常常能把 $\mathcal{O}(N^2)$ 的算法生生压进时限内。

### 3. 埃氏筛法（素数筛）的空间优化

当我们需要筛出 $10^8$ 以内的质数时，普通的 `bool prime[100000000]` 会占用约 100MB 的内存。

如果写成 `bitset<100000000> prime;`，内存占用将直接暴降至约 **12.5MB**，极大地防止了内存超限（MLE）。
