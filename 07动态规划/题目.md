# 一、状态压缩 dp

[E-小红的矩阵计数_牛客周赛 Round 149](https://ac.nowcoder.com/acm/contest/136720/E)

## 状态定义与转移

设 $dp[i][s]$ 表示处理到第 $i$ 列时，且第 $i$ 列的状态为 $s$ ($s \in \{0, 1, 2, 3\}$) 的合法方案数。

当从第 $i-1$ 列的状态 $pre$ 转移到第 $i$ 列的状态 $cur$ 时，只有一种情况是非法的：

- 前一列是 `00` 且当前列也是 `00`（构成了全 `0` 的 $2 \times 2$ 矩阵）。
- 前一列是 `11` 且当前列也是 `11`（构成了全 `1` 的 $2 \times 2$ 矩阵）。

其余所有转移都是合法的。

## 算法步骤

1. **初始化**：

    根据第 1 列的字符限制（考虑 `?` 可以是 `0` 或 `1`），初始化 $dp[1][s]$。如果第 1 列的字符与状态 $s$ 冲突，则 $dp[1][s] = 0$，否则为 1。

2. **状态转移**：

    对于第 $i$ 列 ($2 \le i \le n$)，遍历当前列所有可能的状态 $cur$（需满足第 $i$ 列的字符限制）：

    $$dp[i][cur] = \sum_{pre} dp[i-1][pre]$$

    其中 $pre$ 满足：

    - $pre$ 与第 $i-1$ 列的字符限制不冲突。
    - $\neg (pre == 0 \text{ 且 } cur == 0)$
    - $\neg (pre == 3 \text{ 且 } cur == 3)$

3. **答案**：

    $\sum_{s=0}^3 dp[n][s] \pmod{998244353}$

```c++
const int MOD = 998244353;

//00
//01
//10
//11

bool check(int x, char c1, char c2) {//check是不是x这个状态
    int x1 = (x >> 1) & 1;
    int x2 = x & 1;

    if (c1 != '?' && c1 - '0' != x1) return false;
    if (c2 != '?' && c2 - '0' != x2) return false;

    return true;
}

void ap() {
	int n; cin >> n;
    vector<string> a(2);
    for (auto & i : a) cin >> i;

    vector<vector<int>> dp(n, vector<int>(4, 0));
    for (int x = 0; x < 4; x++) {
        if (check(x, a[0][0], a[1][0])) dp[0][x] = 1;
    }

    for (int i = 1; i < n; i++) {
        for (int x = 0; x < 4; x++) {
            if (!check(x, a[0][i], a[1][i])) continue;

            for (int j = 0; j < 4; j++) {
                if (x == 0 && j == 0) continue;
                if (x == 3 && j == 3) continue;

                dp[i][x] = (dp[i][x] + dp[i - 1][j]) % MOD;
            }
        }
    }

    int ans = 0;
    for (int x = 0; x < 4; x++) {
        ans = (ans + dp[n - 1][x]) % MOD;
    }

    cout << ans;

	return ;
}
```

# 二、背包

[E-小红打游戏_牛客小白月赛131](https://ac.nowcoder.com/acm/contest/131416/E)

```c++
void ap() {
	int n, k; cin >> n >> k;
    int x, y; cin >> x >> y;
    vector<array<int, 3>> a(n);
    for (int i = 0; i < n; i++) cin >> a[i][0] >> a[i][1] >> a[i][2];

    vector<vector<int>> dp(x + 1, vector<int> (y + 1, 1e18));
    dp[0][0] = 0;

    //01背包 - 逆序遍历 背包容量
    for (int i = 0; i < k; i++) {
        for (int j = x; j >= 0; j--) {
            for (int t = y; t >= 0; t--) {
                if (dp[j][t] == 1e18) continue;

                int nx = min(x, j + a[i][0]);
                int ny = min(y, t + a[i][1]);

                dp[nx][ny] = min(dp[nx][ny], dp[j][t] + a[i][2]);

            }
        }
    }

    //完全背包 - 正序遍历
    for (int i = k; i < n; i++) {
        for (int j = 0; j <= x; j++) {
            for (int t = 0; t <= y; t++) {
                if (dp[j][t] == 1e18) continue;

                int nx = min(x, j + a[i][0]);
                int ny = min(y, t + a[i][1]);

                dp[nx][ny] = min(dp[nx][ny], dp[j][t] + a[i][2]);
            }
        }
    }

    if (dp[x][y] == 1e18) {
        cout << -1 << endl;
    } else {
        cout << dp[x][y] << endl;
    }


	return ;
}
```

//a结尾，b结尾，b开头

int add(int x, int y) {
    return (y - x + 5) % 5;

                    int fb = j == 0 ? x : k;
                    ndp[i][x][fb] = max(ndp[i][x][fb], dp[i][j][k] + valb);

            }

            for (int j = 0; j < 6; j++)
                for (int k = 0; k < 6; k++)
                    dp[i][j][k] = ndp[i][j][k];

为了彻底理清这道题的动态规划解法，我们将从**物理过程建模**、**状态定义背后的直觉**以及**状态转移的详细推导**三个层次逐步拆解。

## 一、物理过程与数学转化

操作规则说明：

- 按照原本顺序遍历每个元素。
- 对每个元素有两种决策：**不扔**（保留在前面）或**扔到最后**（排到后面）。
- 每个元素最多被扔一次。

这等价于：我们将原序列拆分成两个子序列 $A$ 和 $B$：

- **序列 $A$**：所有“留在原地”的元素，保持原有的相对顺序。
- **序列 $B$**：所有“扔到最后”的元素，保持原有的相对顺序。

最终吃馍片的顺序为：**序列 $A$ 紧接着 序列 $B$**（即 $A + B$）。

```text
原序列:    x1 -> x2 -> x3 -> x4 -> x5
决策:      A     B     A     B     A
结果:      A = [x1, x3, x5],  B = [x2, x4]
最终序列:  x1 -> x3 -> x5 -> x2 -> x4
                      ^^^^^^
                  跨界连接处 (A尾 -> B头)
```

相邻味道产生的开心度分为三部分：

1. **序列 $A$ 内部**：相邻元素的绝对差 $\vert{}a_i - a_{i+1}\vert{}$。
2. **序列 $B$ 内部**：相邻元素的绝对差 $\vert{}b_j - b_{j+1}\vert{}$。
3. **序列交界处**：序列 $A$ 的最后一个元素与序列 $B$ 的第一个元素之间的差 $\vert{}last(A) - first(B)\vert{}$。

## 二、状态定义

在边遍历边决策的过程中，为了计算新加入元素的贡献，我们只需要知道当前两个序列的**末尾元素**；为了最终计算交界处的贡献，我们还需要知道 $B$ 的**首个元素**。

因此，最直观的三维状态定义为：

$$dp[la][lb][fb]$$

### 状态各维度的含义

- **$la \in [0, 5]$**：当前序列 $A$ **末尾元素的味道**。
    - 若 $la = 0$，表示序列 $A$ 当前为空。

- **$lb \in [0, 5]$**：当前序列 $B$ **末尾元素的味道**。
    - 若 $lb = 0$，表示序列 $B$ 当前为空。

- **$fb \in [0, 5]$**：序列 $B$ 的**首个元素的味道**。
    - 若 $fb = 0$，表示序列 $B$ 尚未放入任何元素。

- **$dp[la][lb][fb]$ 的值**：在当前状态下，序列 $A$ 和 $B$ 各自**内部已经累积的最大额外开心度**。

## 三、状态转移方程

假设当前遍历到一包味道为 $x$ 的馍片，已知前一步的状态为 $(la, lb, fb)$，当前累积值为 $V = dp[la][lb][fb]$。

针对这包馍片，我们只有两种决策：

### 决策 1：将 $x$ 放入序列 $A$（不扔到最后）

- **新增贡献计算**：
    - 如果序列 $A$ 原本为空（$la = 0$），$x$ 是 $A$ 的第一个元素，不产生相邻对，收益增加 $0$。
    - 如果序列 $A$ 非空（$la > 0$），$x$ 与前一个元素 $la$ 相邻，收益增加 $\vert{}la - x\vert{}$。
    - 增量公式：$\Delta = (la == 0 \ ?\ 0 : \vert{}la - x\vert{})$

- **转移后状态更新**：
    - $la$ 变为新的末尾 $x$。
    - $lb$ 保持不变。
    - $fb$ 保持不变。

- **转移方程**：

    $$dp_{next}[x][lb][fb] = \max\Big(dp_{next}[x][lb][fb],\; dp[la][lb][fb] + (la == 0 ? 0 : \vert{}la - x\vert{})\Big)$$

### 决策 2：将 $x$ 放入序列 $B$（扔到最后）

- **新增贡献计算**：
    - 如果序列 $B$ 原本为空（$lb = 0$），$x$ 是 $B$ 的第一个元素，不产生相邻对，收益增加 $0$。
    - 如果序列 $B$ 非空（$lb > 0$），$x$ 与前一个元素 $lb$ 相邻，收益增加 $\vert{}lb - x\vert{}$。
    - 增量公式：$\Delta = (lb == 0 \ ?\ 0 : \vert{}lb - x\vert{})$

- **转移后状态更新**：
    - $la$ 保持不变。
    - $lb$ 变为新的末尾 $x$。
    - **首元素更新**：如果 $lb == 0$（说明这是放进 $B$ 的首个元素），则 $fb$ 从 $0$ 更新为 $x$；若 $lb > 0$，则 $fb$ 保持原值不变。

- **转移方程**：

    $$dp_{next}[la][x][lb == 0 ? x : fb] = \max\Big(dp_{next}[\dots],\; dp[la][lb][fb] + (lb == 0 ? 0 : \vert{}lb - x\vert{})\Big)$$

## 四、最终结算与边界处理

遍历完所有 $n$ 包馍片后，需要结算跨序列拼接处：

1. **初始状态**：
    - 只有 $dp[0][0][0] = 0$，其余全部置为 $-\infty$。

2. **跨序列结算**：
    - 遍历所有合法状态 $(la, lb, fb)$：
        - 若 $la > 0$ 且 $lb > 0$：两段均非空，总额外收益为 $dp[la][lb][fb] + \vert{}la - fb\vert{}$。
        - 若 $la = 0$ 或 $lb = 0$：全在一个序列中，没有跨序列交界，总额外收益即为 $dp[la][lb][fb]$。

3. **最终开心度**：

    $$\text{Max Happiness} = \max(\text{总额外收益}) + n$$
