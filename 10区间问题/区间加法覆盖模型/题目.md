### 1. 建模：把「操作次数」化为「区间覆盖层数」

记每个位置 $i$ **被区间覆盖的次数**为高度 $h_i$。一次区间操作 $[l, r]$ 等价于把 $h_l \sim h_r$ 全部 $+1$。

于是问题变成：**用最少数量的区间，铺出一个满足约束的高度序列** —— 也就是 [基本模型及详解](基本模型及详解.md) 里的那套**区间加法覆盖模型**：

$$\text{Ans} = \sum_{i=1}^{n} \max(0,\ h_i - h_{i-1}), \qquad h_0 = 0$$

和标准模型唯一的不同，是本题每个位置对 $h_i$ 的约束分成两类：

| 约束类型 | 标记 | 高度取值 |
| --- | --- | --- |
| **精确约束**（exact） | `cnt[i][1] == -1` | $h_i = \text{cnt}[i][0]$，必须恰好覆盖这么多次 |
| **自由约束**（free） | `cnt[i][1] == +1` | $h_i \ge \text{cnt}[i][0]$，多铺不限 |

---

### 2. 预处理：合法性检查与 `cnt` 的构造

**第一步：合法性检查**（`ok`），任一条不满足就直接输出 `-1`：

1. `a[i] != 0 && b[i] == 0`：非 0 乘不出 0，非法。
2. `a[i] == 0 && b[i] != 0`：0 怎么乘都是 0，非法。
3. `a[i] == 0 && b[i] == 0`：恒成立，直接跳过（对应 `cnt = {0, +1}`）。
4. `b[i] < a[i]`：数值只会越乘越大，非法。
5. `b[i] > m`：超过上限 $m$，非法。
6. `b[i] % a[i] != 0 && b[i] != m`：除了 `b[i] == m` 的封顶情况，必须恰好是 $a_i$ 的整数倍。
7. `b[i] != m` 时，还要求 `b[i] / a[i]` **是 2 的幂**（`is2` 判断 `n > 0 && (n & (n - 1)) == 0`）。

**第二步：构造 `cnt[i]`**

- `a[i] == b[i]`：本身就不用动，最低要求 `0` 次。
    - `a[i] == m || a[i] == 0`：已经封顶 / 恒为 0，覆盖多少次都不影响结果 → `{0, +1}`；
    - 否则：多覆盖一次就会发生变化 → `{0, -1}`。
- `b[i] == m`（封顶情况）：从 `a[i]` 开始倍增，算出**最少几次才能碰到 $m$**，并记录为自由约束：

    ```c++
    int cur = a[i], c = 0;
    while (cur < m) { cur *= 2; c++; }
    cnt[i] = {c, 1}; // 只要达到 m，后续可做任意多次
    ```

- 其余情况（`b[i] < m`）：必须**精确**覆盖 $c = \log_2 \frac{b_i}{a_i}$ 次 → `{c, -1}`。
    因为 `b[i] / a[i]` 已经是 2 的幂，用 `__builtin_ctzll` 取二进制末尾 0 的个数就等于指数：

    ```c++
    int c = __builtin_ctzll(b[i] / a[i]);
    cnt[i] = {c, -1}; // 严格等于 < m 的某个值，只能精确做 c 次
    ```

### 3. 变量的具体含义

- `pre`：**从左边延伸过来的层数**，即处理完位置 $i-1$ 之后，仍然「还在继续、可以顺势穿过位置 $i$」的区间个数。
- `cnt[i][0]`：位置 $i$ 要求的最低覆盖层数。
- `cnt[i][1]`：约束类型标记，`+1` 自由、`-1` 精确。
- `ans`：到目前为止**新开的区间总数**，也就是最终答案。
- `cur`：只出现在「`b[i] == m` 封顶」的预处理分支里，是倍增打表用的临时变量。

---

### 4. 为什么不能直接去修改（垫高）`pre`？

如果在计算位置 $i$ 时去「回头垫高」 `pre`，逻辑就会自相矛盾：

1. `pre` 是**上一个位置已经确定好的客观层数**，代表左边有 `pre` 个区间正在延续。这个数字在位置 $i-1$ 处理完时就已经固定，不能再回头修改。
2. 位置 $i$ 自己要求的底线是 `cnt[i][0]`。真正要做的是**判断左边这 `pre` 层能不能顺势穿过位置 $i$**，而不是去改 `pre`：

    - **精确点（`cnt[i][1] == -1`）**：位置 $i$ 只允许恰好 `cnt[i][0]` 层，比它高的那些区间**必须在这里断掉**。所以无论左边带来多少层，穿过 $i$ 之后都只剩 `cnt[i][0]` 层：

        $$\text{pre} \gets \text{cnt}[i][0]$$

    - **自由点（`cnt[i][1] == +1`）**：位置 $i$ 允许多铺，左边那 `pre` 层区间**不需要截断**，直接顺势穿过；如果 `cnt[i][0]` 比 `pre` 还高，就再补开新的区间把它垫上去：

        $$\text{pre} \gets \max(\text{pre},\ \text{cnt}[i][0])$$

3. **计算当前位置的增量代价**：只需要看「需要在 $i$ 新开多少个区间」，也就是要求层数比左边现成的 `pre` 高出多少：

    $$\text{增量} = \max(0,\ \text{cnt}[i][0] - \text{pre})$$

    - 自由点：`pre` 被保留（甚至垫高），所以增量通常为 $0$ —— 完全是顺便蹭过来的，不用新开区间；
    - 精确点：`cnt[i][0] > pre` 时要新开 `cnt[i][0] - pre` 个；`cnt[i][0] < pre` 时增量为 $0$，只是把多出来的区间在这里截断。

4. **把更新后的 `pre` 交给下一个位置**。初值上，位置 $0$ 左边没有任何正在延续的区间，所以它需要的层数必须全部在 $0$ 处新开：

    ```c++
    int ans = cnt[0][0];
    int pre = cnt[0][0];
    for (int i = 1; i < n; i++) {
        ans += max(0LL, cnt[i][0] - pre);

        if (cnt[i][1] == -1) {
            pre = cnt[i][0];            // 精确点：强制降到最低要求
        } else {
            pre = max(pre, cnt[i][0]);  // 自由点：能顺延就顺延，不够再垫高
        }
    }
    ```

> **Note:** 自由点之所以「能高就高」（取 `max`），是因为 `pre` 越大，后面的增量 $\max(0, \text{cnt}[i][0] - \text{pre})$ 只会越小，绝不会让后面需要新开的区间变多；而精确点有上界约束，只能强制压低到 `cnt[i][0]`。
