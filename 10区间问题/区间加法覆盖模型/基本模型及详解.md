
**区间加法覆盖模型**（在竞赛中常被称为“积木大赛模型”或“铺设道路模型”）是一个极其经典的贪心与差分问题。

  

其核心问题定义为：给定一个长度为 $n$ 的目标非负整数序列 $h_1, h_2, \dots, h_n$，初始序列全为 0。每次操作可以选择一个任意连续子区间 $[l, r]$，使该区间内的所有数均 $+1$。求将全 0 序列变为目标序列的最少操作次数。

  

### 一、 核心数学公式与结论

最小操作次数公式为：

  

$$\text{Ans} = h_1 + \sum_{i=2}^n \max(0, h_i - h_{i-1})$$

若虚拟一个哨兵边界 $h_0 = 0$，公式可统一写为：

  

$$\text{Ans} = \sum_{i=1}^n \max(0, h_i - h_{i-1})$$

### 二、 核心思想推导与视角

可以通过三种不同的视角来深入理解为什么这个贪心策略是最优的：

  

**1. 差分与端点视角（最严格的数学证明）**

  

- 对区间 $[l, r]$ 进行全体 $+1$ 操作，在差分数组 $d_i = h_i - h_{i-1}$ 上的等价变化为：
    
      
    - $d_l$ 增加 1
        
          
        
    - $d_{r+1}$ 减少 1
        
          
        
- 初始时所有 $d_i = 0$。最终的目标差分数组中，所有正的差分值 $\sum_{i=1}^n \max(0, d_i)$ 必须由某些区间的左端点贡献。
    
      
    
- 每一个区间操作最多只能使某个位置的差分值增加 1。因此，要构造出目标差分数组中所有的正增量，**至少**需要 $\sum_{i=1}^n \max(0, d_i)$ 次操作。
    
      
    
- 既然总存在一种合法的区间闭合方案实现该下界，因此该下界即为最小操作数。
    
      
    

**2. “顺便覆盖”的贪心视角（直观物理理解）**

  

- 从左到右遍历序列：
    
      
    - 当处理到位置 $i$ 时，左侧位置 $i-1$ 已经铺设了 $h_{i-1}$ 层区间。
        
          
        
    - **情况 A ($h_i \le h_{i-1}$)：** 位置 $i$ 所需的高度小于等于前一个位置，因此覆盖 $i-1$ 的区间中有 $h_i$ 个区间可以向右自然延伸覆盖到 $i$，**无需开启新的操作区间**，额外增量代价为 $0$。
        
          
        
    - **情况 B ($h_i > h_{i-1}$)：** 即使把延伸到 $i-1$ 的全部 $h_{i-1}$ 个区间都延伸到 $i$，依然缺少 $h_i - h_{i-1}$ 层，因此必须以 $i$ 为左端点**新开** $h_i - h_{i-1}$ 个区间，产生 $h_i - h_{i-1}$ 的代价。
        
          
        

**3. 水平削减视角（递归分治）**

  

- 每次找到当前区间的全局最小值 $m = \min(h_l, \dots, h_r)$，用 $m$ 次全体操作铺满底层；
    
      
    
- 此时序列被所有等于 $m$ 的位置分割为若干个互不相连的独立子区间，递归处理每个子区间。这个递归求和展开后的结果与差分公式完全等价。
    

### 三、 常见变体与应用场景

|**变体场景**|**约束特征**|**解题核心策略**|
|---|---|---|
|**标准型（积木大赛）**|每个位置目标值 $h_i$ 严格固定|直接套用 $\text{Ans} = \sum \max(0, h_i - h_{i-1})$|
|**区间下界约束**|每个位置要求 $h_i \ge L_i$|贪心让 $h_i = \max(h_{i-1}, L_i)$，尽量顺延前驱高度|
|**区间双向约束**|每个位置要求 $L_i \le h_i \le R_i$|从右向左收紧上界 $R_{i-1} = \min(R_{i-1}, R_i)$，再从左向右贪心贴合|
|**带损耗/区间限制**|区间长度有限制或代价随长度变化|转化为动态规划（DP）或笛卡尔树上树形 DP|

### 四、 标准模板代码

C++

```
#include <bits/stdc++.h>
using namespace std;

long long solve(const vector<long long>& h) {
    int n = h.size();
    if (n == 0) return 0;
    
    long long ans = h[0];
    for (int i = 1; i < n; i++) {
        ans += max(0LL, h[i] - h[i - 1]);
    }
    return ans;
}
```
