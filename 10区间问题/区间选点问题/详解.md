
### 问题定义

给定数轴上的 $m$ 个闭区间 $[l_i, r_i]$，要求在数轴上选取**尽可能少**的点，使得**每个给定的区间内都至少包含一个选中的点**。


tips：和区间不相交数量一样的代码

```c++
bool cmp(const array<int, 2> & a, const array<int, 2> & b) {
    return a[1] < b[1];
}

void ap() {
	int n; cin >> n;

    vector<array<int, 2>> a(n);
    for (int i = 0; i < n; i++) cin >> a[i][0] >> a[i][1];

    sort(a.begin(), a.end(), cmp);

    int cnt = 0;
    int end = -1e18;
    for (int i = 0; i < n; i++) {
        if (a[i][0] > end) {
            cnt++;
            end = a[i][1];
        }
    }

	return ;
}
```

### 贪心策略

1. **排序**：将所有区间按**右端点 $r_i$ 从小到大**排序；若右端点相同，左端点顺序任意。
    
      
    
2. **扫描与选点**：从左往右依次检查每个区间：
    
      
    - 如果当前区间已经包含了上一个放置的点（即 $l_i \le \text{last\_pos}$），则跳过，不需要新放点；
        
          
        
    - 如果当前区间还没有包含任何点（即 $l_i > \text{last\_pos}$），则**在该区间的右端点 $r_i$ 处放置一个新点**，并更新 $\text{last\_pos} = r_i$。
        
          
        

### 为什么选在“右端点”？

核心直觉在于**最大化点的覆盖潜力**：

  

- 我们是按右端点从小到大处理区间的。当遇到一个尚未被覆盖的区间 $[l_i, r_i]$ 时，为了满足它，我们必须在 $[l_i, r_i]$ 范围内至少放一个点。
    
      
    
- 后续还未处理的所有区间，它们的右端点都大于等于当前的 $r_i$。
    
      
    
- 如果把点放在该区间内部靠左的位置，它能覆盖后续区间的概率较低；如果**尽可能靠右（即恰好落在 $r_i$）**，这个点最有可能伸进后续区间的左端点之内，顺带“白嫖”覆盖更多后面的区间。
    
      
    

### 贪心正确性证明（归纳 / 交换论证）

可以通过交换论证法（Exchange Argument）严格证明贪心策略选出的点数必定是最优解（最少点数）：

  

1. 设贪心算法按顺序选出的点集为 $G = \{g_1, g_2, \dots, g_k\}$（满足 $g_1 < g_2 < \dots < g_k$）。
    
      
    
2. 假设存在一个最优解 $O = \{o_1, o_2, \dots, o_m\}$（满足 $o_1 < o_2 < \dots < o_m$），显然必有 $m \le k$。
    
      
    
3. 对比第一个不相同的点：
    
      
    - 考虑第一个点 $g_1$，它是所有区间中最小右端点所在的位置。对于包含 $g_1$ 的区间，其右端点必有 $r \ge g_1$。
        
          
        
    - 最优解的第一个点 $o_1$ 必须覆盖这个最小右端点的区间，因此必然有 $o_1 \le g_1$。
        
          
        
    - 如果将最优解中的 $o_1$ 替换为更靠右的 $g_1$：
        
        任何原本被 $o_1$ 覆盖且原本没有被其它点覆盖的区间 $[l, r]$，满足 $l \le o_1 \le r$。因为 $o_1 \le g_1 \le r$（$g_1$ 是第一个区间的右端点，如果某个区间左端点 $l > g_1$，它一开始就不可能被 $o_1$ 覆盖，矛盾），所以替换成 $g_1$ 后，这些区间依然满足 $l \le g_1 \le r$。
        
          
        
    - 换言之，**把 $o_1$ 右移到 $g_1$，不会丢失任何区间的合法覆盖，甚至可能覆盖更多区间**。
        
          
        
4. 依此类推，我们可以把最优解中的每个 $o_i$ 逐步替换为贪心解中的 $g_i$，保持合法性不变，最终证明贪心点集的大小 $k$ 不会大于最优解大小 $m$。
    
      
    
5. 因为 $k \le m$ 且 $m \le k$，所以 $k = m$，贪心解即为最优解。
    
      
    

### 与其他区间问题的对偶关系

区间选点问题是区间贪心四大经典模型之一，与其他模型存在紧密联系：

  

- **与“最大不相交区间数量”等价**：
    
    贪心过程中，每一次被迫新增一个点，都对应着找出了一个必须与前面所有选定区间互不相交的独立区间。因此，**选出的最少点数 $k$ 严格等于数轴上能够选出的最大两两不相交区间的数量**。
    
      
    
- **与“区间覆盖问题”的区别**：
    
    区间覆盖是用已有的线段去铺满一整段目标大区间；而区间选点是用离散的“点”去穿透每一个给定的区间。
