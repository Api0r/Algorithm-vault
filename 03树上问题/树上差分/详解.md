
# 子树整体 +v

**子树整体差分就只需要在子树的根节点操作，最后先序遍历树**
**最后的d数组就是节点的值**

```c++
d[u] += v;

auto dfs = [&](auto&& dfs, int x, int fa) -> void {
	d[x] += d[fa];
	
	for (int & y : g[x]) if (y != fa) {
		dfs(dfs, y, x);
	}
};

dfs(dfs, 1, 0);
```


# 点差分 - 路径差分

点差分用于处理**树上两点简单路径上的所有点权批量修改**，最终离线一次性求出每个点的最终权值。

把节点 $u$ 到节点 $v$ 的简单路径上的所有点权值增加 $w$，设 $l = \text{lca}(u, v)$，$fa[l]$ 为 $l$ 的父节点，打标记规则如下：

```c++
d[u] += w;
d[v] += w;
d[l] -= w;
if (fa[l]) {
    d[fa[l]] -= w;
}
```


后序自底向上还原
```c++
auto dfs = [&](auto&& dfs, int x, int fa) -> void {
	for (int & y : g[x]) if (y != fa) {
		dfs(dfs, y, x);
		
		d[x] += d[fa];
	}
};

dfs(dfs, 1, 0);
```


自底向上（后序遍历）汇总时，每个节点的真实权值等于**其整棵子树内所有节点的 `diff` 之和**：

$$\text{val}[x] = \sum_{y \in \text{subtree}(x)} \text{diff}[y]$$

路径 $u \to v$ 可以拆分成两条从下往上的链：$u \to l$ 和 $v \to l$。

- **$u$ 和 $v$ 处分别 $+w$**：向上汇总时，整条链 $u \to l$ 和 $v \to l$ 都会接收到贡献。
    
- **在 $l$ 处 $-w$**：因为点 $l$ 既在 $u$ 的链上，又在 $v$ 的链上，被算了两次。在 $l$ 处减去一个 $w$，使其自身刚好净增加 $w + w - w = w$。
    
- **在 $fa[l]$ 处 $-w$**：当继续向上汇总超过 $l$ 到达 $fa[l]$ 时，节点必须不再受到本次修改的影响。加上 $fa[l]$ 处的 $-w$ 后，子树总和净贡献为 $(+w) + (+w) + (-w) + (-w) = 0$，彻底截断了向上的传递。


# 边差分

边差分用于处理**树上两点简单路径上所有边权的批量修改**，通常结合“化边为点”的思想实现。

在有根树中，除根节点外，每个节点与其父节点之间都恰好有一条边相连。 因此，通常将**边 $(u, fa[u])$ 的权值下放到深度更深的节点 $u$** 上进行维护。


若要将从节点 $u$ 到节点 $v$ 的简单路径上的所有边权增加 $w$，设 $l = \text{lca}(u, v)$：
```c++
d[u] += w;
d[v] += w;
d[l] -= 2 * w;
```


后序自底向上还原
```c++
auto dfs = [&](auto&& dfs, int x, int fa) -> void {
	for (int & y : g[x]) if (y != fa) {
		dfs(dfs, y, x);
		
		d[x] += d[fa];
	}
};

dfs(dfs, 1, 0);
```
