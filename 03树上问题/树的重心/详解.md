
# 定义

树的重心有如下三种定义，求出来的点是一样的

1. 以某个节点为根时，最大子树的节点数最少，那么这个节点是重心
    
2. 以某个节点为根时，每颗子树的节点数不超过**总节点数的一半(<= n / 2)**，那么这个节点是重心
    
3. 以某个节点为根时，所有节点都走向该节点的总边数最少，那么这个节点是重心
    


# 性质

**补充性质：** 
4. 一棵树**最多有两个重心，如果有两个重心，那么两个重心一定相邻
5. 如果树上增加或者删除一个叶节点，转移后的重心最多移动一条边 
6. 如果把两棵树连起来，那么新树的重心一定在原来两棵树重心的路径上 
7. 树上的边权如果都 >= 0，**不管边权怎么分布，所有节点都走向重心的总距离和最小**

https://www.luogu.com.cn/problem/U104609

```c++
//树的重心第一种求解方式
//最大子树的节点数最少，那么这个节点是重心
int n;
vector<vector<int>> g;
vector<int> sz, ans;

int mn = 1e9;

void dfs(int x, int fa) {
    sz[x] = 1;
    int mx = 0;
    for (int & y : g[x]) if (y != fa) {
        dfs(y, x);

        sz[x] += sz[y];
        mx = max(mx, sz[y]);
    }

    mx = max(mx, n - sz[x]);

    ans[x] = mx;
    mn = min(mn, mx);
}

void ap() {
	cin >> n;
    g.assign(n + 1, {});
    sz.assign(n + 1, 0);
    ans.assign(n + 1, 0);

    for (int i = 0; i < n - 1; i++) {
        int u, v; cin >> u >> v;

        g[u].push_back(v);
        g[v].push_back(u);
    }

    dfs(1, 0);

    for (int i = 1; i <= n; i++) if (ans[i] == mn) cout << i << ' ';
    
	return ;
}
```
